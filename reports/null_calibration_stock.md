# 个股 LPPLS 过滤集的零假设误报率标定（WP1；2026-11-02；`prereg_v1.7_v2.1`）

> 方案：`docs/research_plan_stock_math.md` WP1 / RQ1。复现：`export LPPLS_BOX=v2 PYTHONPATH=. AUDIT_OUT=/tmp/audit; python scripts/audit_stock_math/exp7_null_calibration.py 6 200 100 40`（8 核约 2.4 小时，43,800 次拟合）。汇总表：`reports/null_calibration_stock.csv`。
> 性质：**描述性**。只回答"无泡沫的随机序列有多大比例的窗口会被各过滤集判为合格"，不改任何预登记判据，不构成个股预测证据（个股仍为 `research_candidate`）。

## 0. 结论
1. **无趋势零假设**（GBM μ=0、GARCH-t、真实个股收益 20 日块重排）下，STANDARD 的窗口级误报率在 1–3m 至 12–24m 为 **2–12%**（块重排最高：6–12m 9.0%、12–24m 11.7%），与 JLS 2000 报告的 GARCH 替代序列 6.6% 同量级；`box` 1.4–3.0%；`lit2`（含 Lomb/误差条件）≤0.5%。
2. **有趋势但无振荡的零假设**（趋势+O-U、GBM 强漂移 0.3%/日、纯幂律）下，STANDARD/END/EARLY 误报率随尺度上升，12–24m 与 2–6y 达 **21–52%**；`box` 仍 ≤13%，`lit2` 在强漂移/幂律下也有 10–39%。说明 STANDARD 一类过滤集主要识别"超指数趋势"，对数周期振荡条件（osc≥2.5、D）在长窗口上约束不足——这是 Brée–Joseph / Geraskin–Fantazzini 识别性批评的量化版本。
3. **as-of 级**（同一条序列在该尺度有 ≥1 个 STANDARD 合格窗口的比例，即产品"有合格拟合"口径）：无趋势零假设 **12–27%**，强漂移/幂律 **53–93%**。因此个股页的"有合格拟合"在无任何信号的随机序列上也会有约 1/8–1/4 的出现率；而 `box` 置信度 ≥0.5 在所有零假设下 ≤12%（长档 ≤3%），是更保守的口径。
4. 2–4w 档（10–20 点拟合 7 参数）各过滤集误报率并不高（STANDARD 2%），但 `m>1` 占 20–26%、撞边界 53–60%、r² 中位 0.92–0.95——高 r² 是过参数化的结果，不是形态证据；支持 WP0 的 `display_only`。
5. 撞边界（`boundary_share.any`）在所有零假设下 **30–60%**，与真实个股（600519 stk_full 38%）同量级；撞边界不是"信号"也不是"异常"，只说明搜索域边界对无结构序列经常被触及，其 t_c 不应解读为情景分位。
6. 对照真实个股（审计 F10/exp6，as-of 2025-06-30）：600519/000858/300750/601318 在 6–12m、12–24m 的 STANDARD 合格率为 0，002594 为 0.08–0.30；均落在"无趋势零假设 + 强漂移零假设"的区间之内，**无法与零假设区分**，与开发段横截面"无预测信息"一致。

## 1. 设计
| 项 | 设定 |
|---|---|
| 生成过程（每类独立种子） | `gbm0`：对数价格随机游走 σ=2%/日；`garch`：GARCH(1,1)-t₅（α=0.08、β=0.90，无条件 σ=2%）；`block_boot`：5 只真实个股（600519/000858/300750/601318/002594，腾讯后复权，PIT）日对数收益按 20 日块重排后累加；`ou_trend`：0.1%/日线性趋势 + O-U 残差（θ=0.05、σ=2%）；`gbm_drift`：μ=0.3%/日（年化约 +110%）；`powerlaw`：`8 − 0.6((t_c−t)/t_c)^m`，m∈{0.3,0.5,0.7}，t_c = t₂ + 5% dt，无振荡，噪声 1% |
| 窗口 | 2–4w：XS 10..20 步 2（6 窗）；1–3m/3–6m：SHORT 30..120 步 5（19 窗）；6–12m/12–24m：`universe.WINDOWS` 127..502 步 25（16 窗，=stk_lite）；2–6y：XL 525..1500 步 25（40 窗） |
| 序列数 | lite 档 200 条/类，SHORT 100 条/类，XL 40 条/类 |
| 拟合 | `lppls_scan.fit_one`，v2 框（m∈[0.01,2]、ω∈[1,50]、t_c∈[t₂−0.2dt, t₂+0.2dt]、`ALLOW_INSIDE`），`tcgrid_lm`，含 F1 修复 |
| 过滤集 | `box`（B<0、m∈[0.1,0.9]、ω∈[6,13]、ahead∈[0,90]）、FCO `standard/early/end/pure`（`grid_rules`）、`lit2` |
| 区间 | 窗口级 95% Clopper–Pearson；as-of 级按序列聚合 |

注意：窗口级比例把同一序列的多个窗口当作独立观测，区间偏窄；as-of 级才是产品口径。

## 3. 撞边界、m>1、拟合优度（描述性）
见 `reports/null_calibration_stock.csv` 同目录的运行日志；关键量级：无趋势零假设下 `m>1` 占 35–43%（长档）、`B<0` 约 50%（符号随机）、撞边界 `any` 43–51%、r² 中位 0.85–0.89、`rel_err` 中位 0.33–0.39；纯幂律下 `B<0`=100%、m 几乎不撞界、r² 0.98–0.99。真实个股（exp6）r² 中位 0.62–0.89、`rel_err` 0.33–0.61，介于两者之间。

## 4. 对产品与后续工作的含义（均为建议，不改判据）
- 个股 JSON 的每尺度字段新增 `null_fpr`（本表的 `standard`/`box` 列，三类代表零假设：`gbm0`、`block_boot`、`gbm_drift`），文案："在无泡沫的随机序列中，该过滤集也有 x% 的窗口合格"。本 PR 已接入（`export_contract._null_fpr`，来源 `reports/null_calibration_stock.csv`，缺文件时为 `null`）。
- breadth 报表的"有合格拟合（standard>0）"应与 as-of 级零对照（无趋势 12–27%、强趋势 53–73%）并列；这解释了为什么沪深300 breadth 的该列在平静期也不为 0。
- Q-STK1（WP3）评价时，M1 相对 B1 的增量必须在"控制动量"后计算——本表已显示 STANDARD 对趋势本身高度敏感，不控制动量会把动量效应误记为 LPPLS 增量。
- 预登记建议（只记录）：若未来修订 STANDARD 类判据，优先加入振荡数/Lomb 条件（`lit2` 在无趋势零假设下 ≤0.5%），但其在强漂移下仍有 10–20%，不能完全解决识别性问题。
- 不做：用本表反推阈值、把零对照当显著性检验（生成过程参数是工作假设，不是估计量）。
