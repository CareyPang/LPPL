# Phase 0 精度尺子：逃顶/抄底时间与价格的基线（开发段，描述性，dev_only；2026-11-12）

> 目的：把"精准"变成可测的数，给 Phase 1–3 当尺子；**不改判据、不进产品**。计划见 `docs/plan_stock_engine_precision.md`。代码 `research/eval/precision_baseline.py`（Python 研究链）、`scripts/audit_stock_math/exp11_js_tape_eval.py` + `js_tape.mjs`/`js_topscan.mjs`（网页端引擎 `web/app/critical.js`，node 无头运行）。原始表 `reports/precision_baseline/*.csv`。
> 定义：报警 = 某尺度（FCO 6–12m / 12–24m）置信度（合格窗口比例）≥ q；首报 = 前 20 个交易日无报警的报警日；命中 = 首报后 120 日内出现合格顶（顶标签事件段末 +1 日）/ 有效底（三重障碍标签）。T-top = 提前量；P-top：卖早 = 顶价/报警价 − 1，躲掉 = 顶后 126 日最低收盘/报警价 − 1；P-bot：高于谷 = 报警价/谷价 − 1，后涨 = 谷后 126 日最高/报警价 − 1。零对照 = 报警序列整体循环平移（≥250 日）500 次的命中率均值。只报 q=0.10（成分股 lite 每尺度仅 3–5 窗，q=0.05/0.10/0.20 结果完全相同）。

## 0. 结论

1. **顶部时间信号几乎全部来自 2007/08 与 2014/15 两轮大顶**：指数 box 12–24m 首报命中 0.385（零对照 0.21）→ 剔除四年后 **0.042**（n=24）；成分股 STANDARD 12–24m 0.508（零对照 0.12）→ 剔除后 0.144，其中 2015 年 94 个首报命中 95%。网页端引擎同样：首报命中 0.307（零对照 0.23）→ 剔除后 **0.058**（n=52）。
2. **t_c 聚类中位不比随机更接近顶**：网页端引擎在 6 指数开发段 483 个有主聚类的截止日，顶区 ±5 日命中 0.111，随机重排对照 0.087（95 分位 0.115）；聚类窗（中位宽 8 日）覆盖顶 0.115；剔除两轮大顶后命中 0.043、误差中位 165 日。与研究链 `tc_cluster_dev.md` 结论一致（0.111 vs 0.100）。NDX 2026-10-06 的命中属于此类分布中的一个样本，其后四周的聚类全部后推 1–3 个月。
3. **逃顶价格**：命中样本中位"卖早" +12%～+33%（12–24m box 最小 +12%），"躲掉" −25%～−33%；即报警后到顶还要涨一到三成，躲掉的跌幅与卖早的涨幅同量级。首报后 120 日收益中位（含未命中）指数 −3%～+13%、成分股 −6%～0%，方向不稳——即"报警后立刻卖出"在中位意义上并不优于持有。
4. **抄底**：指数 −lnP 扫描 STANDARD 12–24m 首报命中 0.47（零对照 0.27），剔除大顶年后 **0.52**（n=31）——这是唯一在剔除极端年后仍高于零对照的组合，但 n 小、提前量中位 34–63 日、报警价高于谷 7–8%；成分股底部全部组合命中 0.11–0.17 **低于**零对照 0.23–0.25（LPPLS 抄底在个股上劣于随机，与 #43 抄底面板样本外结论一致）。
5. 对 Phase 1–3 的含义：时间层的"精度"问题首先是**只在系统性大泡沫中有信号、其余年份与随机无差**，不是优化器误差；Phase 1a/1b 的合成回收与聚合改进要以"剔除两轮大顶后的命中率"为主指标，否则会被 2007/2015 淹没。逃顶价格（Phase 2）的基线是"卖早 +12%～+33%"。个股 LPPLS 抄底建议在 Phase 3a 直接作为负面候选。
