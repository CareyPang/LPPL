# Phase 2 逃顶价格：报警后"剩余涨幅"能否预测（开发段，描述性，dev_only；2026-11-12，2026-11-15 修正重算）

> 问题：Phase 0 显示报警后到顶中位还要涨 +12%～+33%。能否在报警日估出这段剩余涨幅？脚本 `scripts/audit_stock_math/exp15_remaining_upside.py`；明细 `reports/precision_baseline/remaining_upside_panel.csv`、`remaining_upside_qreg.csv`。
> 样本：6 指数 `lppls_v2`（2000–2018）与 100 成分股 `lppls_v2_lite_stk100`（2010–2018），报警 = FCO 6–12m/12–24m box 置信度 ≥0.10 且合格窗 ≥3，且 as-of 后 250 日完整在开发段内（2026-11-15 修正：首版代码只检查了价格序列长度，73 行 2018 年下半年报警的目标窗伸入 2019 年校准段价格；现按 `cal[t+250] ≤ 2018-12-31` 剔除后重算，结论不变）。目标 y = 250 日内最大剩余涨幅 max P_s/P_t − 1。不重拟合。

## 结论
**2a 负面**：LPPLS 渐近值 A（合格窗口中位）隐含的顶价 exp(A) 与实际没有可用关系——隐含剩余涨幅 u_A 与实际 y 的 Spearman 在指数 12–24m 为 −0.027（剔极端年 −0.024），6–12m 0.24；有合格顶时 exp(A)/P_top 的 20/50/80 分位 0.69 / 1.19 / 1.55（指数 12–24m），即"理论顶价"中位高估 19%，且分散度 ±40%。A 是对数价格在 t_c 的渐近常数，受 B、m、t_c 共线影响，不是可用的价格目标。
**2b 负面**：以 [u_A, 尺度最短窗涨幅, m 中位, ω 中位, t_c 提前量中位] 做剩余涨幅条件分位（逐年扩展窗，训练 ≤Y−2），pinball 比值 vs 无条件分位：指数 τ=0.2 / 0.5 / 0.8 = 1.046 / 1.031 / 0.933，90% 区间上界 1.046 / 1.212 / 1.343，剔极端年 1.08 / 1.03 / 0.98 → 全部未达 "τ=0.5 上界 < 1"。成分股样本 OOS 只有 2017 年 41 行（lite 步长 20 日、2010 起），比值 1.03–1.27，不足以作结论。

含义：**"逃顶价格"目前没有可用的模型化路径**——LPPLS 参数（A、m、ω、t_c）在报警日对后续剩余涨幅几乎没有排序信息；现有的 P1 回撤情景表（顶后）仍是价格层唯一可呈现的描述性内容。若要继续，须换特征（估值分位、广度、两融）并重新登记，不在本计划内。
