## 1. F1 优化器漏找地图（`scripts/audit_stock_math/exp28_f1_miss_map.py`，原始 `reports/f1_miss_map/`）
- 窗口：Phase 1a `exp13` 的 2,182 个开发段真实窗口（6 指数）。参照 SSE = 6 种方法 + 密网格（60×30×40 网格 + top-10 L-BFGS-B）中的最小值；漏找 = SSE > 参照 × (1+1e-4)。参照来源：cmaes 861、dense 544、tcgrid_lm_r10 347、de_lbfgsb 273、ms_lm30 157——没有一种方法单独可当"真值"。
- 漏找率（全部 / 参照 t_c 窗外 / 窗内）：`tcgrid_lm_r10`（生产）0.205 / 0.014 / 0.326；`de_lbfgsb` 0.046 / 0.004 / 0.073；密网格 0.153 / 0.012 / 0.242；lite `_r3` 0.257 / 0.017 / 0.408。
- 生产解漏找集中在参照 t_c 窗内且 m 小：m ≤ 0.1 为 0.91、0.1–0.3 为 0.78、0.3–0.6 为 0.59、0.6–0.9 为 0.23、> 0.9 为 0.09；窗外各 m 箱 ≤ 0.05。窗口长度三档 0.19–0.21，无明显差异。
- 漏找的幅度小：生产解漏找时 SSE 差中位 0.65%、t_c 差中位 1.7 bar（谷底平坦，几乎同一解）；`de_lbfgsb` 漏找时 SSE 差中位 1.7%，但 t_c 差中位 68 bar（跳到另一个谷）。
- 对判定的影响：生产解与参照解的 box 合格判定只在 3/2182 个窗口不同（都是生产合格、参照不合格），不存在参照合格而生产漏掉的窗口。
- 读法（§25.1 事先写定）：窗内漏找率 0.326 > 10%，但翻转率 0.14% < 2% → 不重提 `_g3`，只登记。与 §20/§22.3.2 的 `_g3` 结论一致：数值漏找真实存在，但几乎不改变合格判定。

## 2. F2 t_c 剖面范围（`exp29_f2_profile.py`，原始 `reports/f2_profile/`）
- S-A 标定：c = 0.002/0.005/0.01/0.02/0.05/0.1 的覆盖率 0.34/0.46/0.58/0.73/0.89/0.95 → 冻结 c = 0.05。
- S-B：合并覆盖率 0.909（门 [0.80,0.95] 满足）；分残差 iid/GARCH/AR(1) 0.5 均 1.00，**AR(1) φ=0.9 只有 0.635**（门 ≥0.70 不满足）。
- N：剖面范围相对宽度中位 0.425（门 ≥0.5 不满足）；gbm 0.46/0.28（n=227/477）、garch 0.28/0.27、nonnormal 0.21/0.28、ar1 0.40/0.36、power_only 0.58/0.55。
- 含义：同一个 c 下，合成泡沫的范围宽度中位 0.21–0.38 × 搜索域，零假设 0.21–0.58，两者大幅重叠——"剖面范围窄"不能把真泡沫和零假设分开；强自相关残差下范围又过窄、覆盖不足。SSE 相对阈值不随残差自相关调整是直接原因。
- 处置：不跑开发段，不调 c，不加字段。

## 3. F3 残差 AR(1) 可行 GLS（`exp30_f3_gls.py`，原始 `reports/f3_gls/raw.csv`）
- 中位绝对误差 GLS/OLS（t_c, m, ω）：AR(1) 0.5 为 1.15 / 1.20 / 1.06；AR(1) 0.9 为 0.87 / 0.70 / 1.05；iid 1.00 / 1.05 / 1.00；GARCH 1.00 / 1.00 / 1.02。ρ 估计中位 0.50 / 0.85 / 0.01 / 0.03，估计本身是对的。
- 零假设 box 合格率：OLS 0.015，GLS 0.030（gbm、garch、nonnormal 各多 1 条/40）。
- 含义：Prais–Winsten 差分把低频信息（LPPLS 的幂律曲率主要在低频）压掉了，t_c 只有在 φ=0.9 时略好；同时零假设误报上升。
- 处置：不跑开发段，不调参。

## 4. F4 Lagrange 正则选窗口起点（`exp31_f4_lagrange.py`，原始 `reports/f4_lagrange/raw.csv`）
- 起点误差 |n* − L_b| / L_b 中位：L_b=477 四类残差均 0.038；**L_b=227 为 0.41–0.45**（短泡沫段上选出的窗口约长出 40%）；合并 0.059（门 <0.20 满足）。未正则的 χ²_np 最小对照为 0.449，正则确实有用。
- 零假设（n=800，五类 × 20 条）：F4 所选窗口 box 合格率 0.040（4/100），现行置信度均值 0.0383 → 门"F4 ≤ 现行"差 1 条序列不满足。100 条序列下这个比较的抽样误差约 ±2pp，门本身功效不足——这是登记时没算到的，如实记录，不放宽门、不加序列重跑。
- 处置：按 §25.0 判未通过，不跑开发段。

## 5. 合起来
- 四层里，F1 说明优化器漏找真实存在但几乎不改合格判定；F2/F3/F4 都没过各自的合成门，按登记不进开发段、不调参。
- 唯一有正面迹象的是 F4 对长泡沫段起点的估计（误差 4%），但它在短泡沫段失效、零假设侧也不比现行更干净。
- 下一步若继续，需要重新设计而不是调参：F2 的阈值要随残差自相关（有效样本量）调整；F3 要用 AR(1) 精确似然联合估计或只在低频上加权；F4 的零假设门要按功效重算样本量。这三项都是数学设计问题，需重新登记。
