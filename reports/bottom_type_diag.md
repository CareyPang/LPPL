# Phase 3a 按底部类型分层诊断 LPPLS −lnP 抄底（开发段，描述性，dev_only；2026-11-12）

> 问题：Phase 0 显示 LPPLS 负泡沫（−lnP 扫描）抄底在成分股上劣于随机、指数仅 STANDARD 12–24m 稳健。文献（Johansen–Sornette 1999 反泡沫；Yan–Woodard–Sornette 2010 负泡沫）的适用对象是**阴跌减速**型下跌，不是恐慌 V 底。本步按底部类型分层看命中到底来自哪一类。脚本 `scripts/audit_stock_math/exp16_bottom_type_diag.py`；明细 `reports/precision_baseline/bottom_types.csv`、`bottom_type_diag.csv`。
> 定义：底 = 有效底标签（三重障碍）事件段末 +1 日；类型按"前 250 日最高收盘到底的交易日数" d_fall：panic ≤60、mid 61–120、slow >120。报警 = FCO 6–12m/12–24m 尺度 −lnP 扫描 box/STANDARD 置信度 ≥0.10 的首报（前 20 日无报警）。召回 A2 = 底前 120 日内有首报；零对照 = 报警序列循环平移 300 次。样本：6 指数 2000–2018（底 68 个）、100 成分股 2010–2018（底 525 个）。

## 结论
1. **恐慌底占多数且 LPPLS 完全抓不到**：指数 68 个底中 panic 37（d_fall 中位 6 日、回撤中位 −9%）、slow 26、mid 5；成分股 525 个中 panic 300、slow 174、mid 51。panic 底的召回 0.03–0.11（指数）/ 0.01–0.07（成分股），**全部低于**循环平移零对照（0.19–0.46）。
2. **阴跌底 LPPLS 有信号**：slow 底召回指数 0.58–0.77（零对照 0.17–0.40），成分股 0.29–0.47（零对照 0.17–0.34），四个尺度×规则组合全部高于零对照。首报命中的底几乎全是 slow 型（指数 STANDARD 12–24m：命中 0.47，其中 slow 0.47、panic 0.00）。
3. Phase 0 里"成分股 LPPLS 抄底低于随机"的根因是把 300 个恐慌底算进分母；在 slow 底子集上成分股并不差。**不建议整体放弃 LPPLS 抄底，但必须改为"只对阴跌型下跌给出负泡沫信号"**：恐慌底需另一套工具（Omori 余震衰减、成交额枯竭、新低广度；Phase 3b），LPPLS 不参与。
4. 这是分层诊断（底类型用了底本身的信息，非 PIT），只用于决定 3b 的方向；产品层若要用"阴跌/恐慌"区分，须用 as-of 可知的代理（如过去 60 日跌幅/过去 250 日跌幅的比值）并另行登记。

## 对 Phase 3b/3c 的建议（需登记）
- 3b 底部时间：阴跌型 → 现行 −lnP LPPLS（STANDARD 12–24m 为主）；恐慌型 → Omori 余震衰减率 + 成交额枯竭 + 新低广度，加入 B1→B2→B3 保留链做 CPCV ΔBrier。体制判别用 as-of 可知代理，不用底类型本身。
- 3c 底部价格：分型后再做谷价条件分位；恐慌型的"高于谷"预期更大（反弹快），阴跌型更小。
