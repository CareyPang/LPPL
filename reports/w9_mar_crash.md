# §24.5 W9：MAR(r,1) 崩盘概率——开发段结果（2026-11-15；6 指数 2000–2018；`scripts/audit_stock_math/exp23_mar_crash.py`；明细 `reports/w9_mar_crash/`）

**裁决：未通过（G1/G2/G3 三条在 H=20、H=60 都不成立）。不进产品，不调 r/s/窗长/M/阈值。** 判据、基线、门写在结果之前（§24.5），运行前只改了一处：ψ 接近 1 时 N=100 截断偏差过大，运行前把截断期改为 N=300 并注明。

## 设置
滚动 500 日对数收盘线性去趋势；MAR(r,1)、r∈{0,1} 按窗内对数似然选；Student-t 误差近似 ML；LLS(2012) 样本加权预测（M=2000，截断 300）；目标 \(Y_H=1\{\min_{i\le H}P_{t+i}/P_t\le0.90\}\)，H∈{20,60}；采样步长 5 日，n=3769；基线 (a) 气候概率、(b) 逻辑回归（HAR 三项 + 250 日涨幅/回撤）；CPCV 6 块 k=2 gap 80（15 条路径）；250 交易日块 bootstrap 1000 次 90% 区间。

## 拟合形态
- r=1 占 20.8%；ψ 中位 0.984（10 分位 0.12、90 分位 0.994）——去趋势后的对数价格几乎总被拟成接近单位根的非因果 AR(1)；ν 中位 4.2；重要性权重有效样本 ESS 中位 204/2000（10 分位 7.7）。
- 基准事件率：20 日内跌 ≥10% 为 0.134，60 日为 0.348。MAR 概率均值 0.172 / 0.379，与基准率量级接近但分布极宽（p60 的 90 分位 0.90）。

- 原始 MAR 概率比"永远报基准率"**差得多**（Brier 高 42–57%），且方向反了：H=60 时 MAR 概率最低一箱（p̄=0.035，n=772）的实际崩盘率 **0.52**，最高一箱（p̄=0.98，n=375）只有 0.29；p60 与 Y60 的相关 −0.15。原因可读：MAR 的非因果成分把"接近 250 日高点的加速上涨"读成即将破裂（p60 与 250 日回撤相关 −0.29），而开发段 10% 回撤更多发生在已经下跌的延续段；A 股普通年份的下跌不是"泡沫破裂"形态。
- 逻辑回归基线本身对气候概率只有 +4.3%（H=20）/ −0.2%（H=60）的技巧分；加入 logit(p_H) 后改善为 −0.3% / −0.8%，区间含 0，剔极端年同样 ≈0。MAR 概率在控制涨幅/回撤后没有增量。
- ECE 0.16 / 0.31，远超 0.05："校准过的概率"的字面检验不成立。

## 结论
Hecq–Voisin 式 MAR 崩盘概率在 A 股日频指数上既不校准也无排序信息，比气候概率差；文献证据（商品、油价、比特币）都是事后单案例，这里是第一次按预登记门在面板上检验。连同 W8/W7、§22 Q3 与 Phase 0–3，文献补查中三条"有外部实证"的路在 A 股开发段均为负面。个股维持 research_candidate；不进确认样本。
