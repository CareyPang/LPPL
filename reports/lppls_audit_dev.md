目的：回答"原版 LPPLS 以顶部预警见长，本实现为何未复现"。不是样本外结论；不改变顶部产品定位。

## 1. 搜索域偏离原版（实现问题）
| 项 | 原型 engine.js / Filimonov–Sornette 2013 | 本仓库 v1 扫描（预登记 v1.1） |
|---|---|---|
| m | [0.01, 0.99] | [0.01, 2.0] |
| ω | [2, 25] | [1, 50] |
| t_c − t₂ | ≤ ~0.1–0.2·dt | ≤ 0.2·dt |

上证全部窗口（n=115,920）：m>1 占 50.3%，m 顶在 2.0 边界 24.0%，ω 顶在 1.0 边界 8.7%，m 顶在 0.01 边界 13.2%。即一半窗口的最小二乘解不是泡沫形态，真正的对数周期解被退化解挤掉；这是实现选择，不是方法失效。

## 3. R4d LIT 条件 1 恒为 0 的直接原因
框内窗口的阻尼 D = m|B|/(ωC) 分位数：P10 0.15、P50 0.31、P90 0.98；D≥1.2 仅 4%，D≥1.0 9%，D≥0.8 14%。振荡数条件 (ω/2)ln(…)≥2.5 全部满足。叠加相对误差 ≤3.5% 后 v1 上三档阻尼阈值合格比例均为 0（`s_lit1`、`s_lit1_d10`、`s_lit1_d08` 全 0），即误差条件在宽搜索域下同样是约束。

## 4. 判定
- "零合格窗口 / R4 无增量"目前不能归因于 LPPLS 方法，首先要排除搜索域（§1）；纠正方案与阈值变体已登记为预登记 v1.7 §17，待用户确认后重扫。
- 原版的"准"是实时预警 + 逐案复盘标准；本项目是事件级 CPCV Brier 标准，两者可并存；v2 扫描后若仍无增量，按 §17.3 表述。
