# 观时 · 贵州茅台行情更新与历史回放验收

2026-11-18 收盘后，使用上交所股票 600519 验收。桌面与 390px 页面均从归档的 11 月 17 日收盘 1,457.70 元更新到 11 月 18 日收盘 1,442.66 元。模型截止日仍为 11 月 17 日。两次成功请求均经过本机运行的仓库 Worker 和真实腾讯行情服务。线上 Worker 在本轮最后一次复核时只提供上一日缓存。

## 403 在哪一层发生

| 发起页面与目的地 | 实际响应 | 可复核的解释 |
|---|---|---|
| 本机页面 → 已部署 Worker | HTTP 403，`ORIGIN_FORBIDDEN`。浏览器网络层记录缺少 `Access-Control-Allow-Origin`，页面脚本收到 `TypeError: Failed to fetch` | VERIFIED。Worker 对浏览器发送的 Origin 作精确匹配，线上配置允许 `https://careypang.github.io`。本机地址在请求行情前即被拒绝。 |
| 正式 GitHub Pages 页面 → 同一已部署 Worker | HTTP 200，响应允许该 Pages 来源；640 根日线，截止 11 月 17 日，`cache=stale`，`stale_reason=MARKET_UNAVAILABLE` | VERIFIED。正式站读得到旧行情。北京时间 16:12 再读公网接口，仍是相同截止日和原因。线上上游具体失败原因属于 NOT_ESTABLISHED。 |
| 本机观时页面 → 本机 Worker → 腾讯日线 | HTTP 200，640 根完整日线，截止 11 月 18 日，`stale=false`。桌面请求触发实际抓取，390px 请求命中刚生成的 Worker 缓存 | VERIFIED。通过浏览器点击实际按钮发出 GET。Worker 使用仓库原本的行情代码与本地 Durable Objects。另读腾讯原始日线，末日 OHLCV 五个字段逐项相符。 |

来源限制在 [Worker 配置](../../workers/stock-query/wrangler.toml) 和 [请求入口与缓存处理](../../workers/stock-query/src/index.js)。本地预览在独立配置中配对两个回环地址，页面使用既有的 `LPPL_QUERY_API`。启动与停止见[本机复验指南](../../tools/guanshi_preview.md)。

## 两处影响用户操作的修复

1. 冷缓存时，Worker 在用户点击后才生成行情。旧页面以点击时刻检查 `generated_at`，可能把正常返回的数据误判为“未来”。现在等响应抵达后再校验。生成时间晚于接收时间的异常响应仍会被拒绝。
2. “选得到日期”和“有该日行情原档”是两件事。若某日只有模型记录、缺少该日行情和回放原档，日期选择器现在能还原用户刚读到的真实日线。有行情原档、回放帧或封存的日期继续从对应版本读取。新收盘只更新本标签页的当前行情，模型、历史文案和历史数据维持各自的日期与来源。

返回过期缓存时，页面显示缓存日期。请求失败时，页面提示当前实际保留的行情截止日，图表仍可操作，按钮可重试。已打开页面内的断网恢复与关闭浏览器后的持久化属于不同测试场景。本次只验收前者。

## 回归及复验

- 前端与 Worker 的 Node 测试 386 项通过。离线 Python 测试 527 项通过，2 项跳过。
- 常规浏览器回归 45 项通过，2 个需要更新交易日及真实上游的用例默认跳过。另在真实预览环境打开开关运行「观时」专项，8 项全部通过，其中包含上述两个视口的真实更新。两组计数有重叠。
- 自动化另覆盖请求返回 503、未来时间戳、日期与模型记录重合、用户切换历史日期后刷新才返回。真实设备 Safari、大陆蜂窝网络、生产上游故障子类型及生产恢复时间未核验。

启动[本机预览](../../tools/guanshi_preview.md)后，在仓库根目录执行以下 PowerShell 命令。运行需保有指定历史原档，并且上游已有晚于行情原档的交易日。若没有更新日，真实验收会指出这一条件。设置 `GUANSHI_CAPTURE_DIR` 可保存本轮截图及响应摘要。

```powershell
$env:E2E_BASE_URL = 'http://127.0.0.1:8797'
$env:E2E_CHROMIUM_CHANNEL = 'chrome'
$env:GUANSHI_LIVE_QUOTE = '1'
$env:GUANSHI_REAL_ARCHIVE = '1'
python -m pytest -m e2e tests/e2e/test_guanshi.py
```
