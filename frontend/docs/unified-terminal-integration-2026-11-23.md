## 2. 页面如何帮助用户完成研究

### 首页

首页仍负责扫览和选择，不堆入完整回测控件。点击上证等卡片后进入 `chart.html?code=sh000001&kind=index&from=home.html`。返回入口保留原页面信息；已有图表与原版完整诊断入口继续可用。

### 诊断

先固定资产身份、行情日期和模型日期，再展示所选尺度的候选顶部区间。图表旁放解释与证据；模型尚未就绪时，已读到的行情仍可缩放和画线。没有合格拟合、没有可展示区间、未提供证据及数据读取失败不能合并成同一个“没有风险”。

蓝色用于模型时间区间，涨跌继续使用原有红绿语义。展示的是日期区间，不把区间中点写成确定顶部日期；没有添加价格目标或预测胜率。当前页面不展示仓位建议。

### 回放

回放模式提供截止日输入、前一条/后一条已存记录、历史区间列表和“查看后来走势”。切换标的时保持所选尺度和精确截止日；如果新标的没有这一天的记录，就显示缺档，不悄悄改为最新或相邻日期。

“查看后来走势”是观察历史判断之后发生了什么。它只替换传给图表的行情序列副本，不替换当时的模型、区间、证据、模型版本或截止日。取消开关恢复截止日以前的行情。导出含后来走势的截图另行写明该状态，避免截图被误认为当时已知全部走势。

### 桌面与 390px

桌面把主要图表与证据组织在相邻区域；390px 将控件重新换行，证据通过已有抽屉打开，图表保留全屏。控件状态、日期和选中尺度应一致，不依赖用户理解后端术语。

## 4. 历史与证据的约束

1. **精确日期，只读加载。** `LPPL.load(sym, arbitraryAsOf)` 原有路径可能自动 POST 回放作业。本页使用 `Reader.historical`：显式允许的静态原档、只读 `replay.result`、或精确匹配的已存 `history.frames`。找不到时不自动启动 104 周历史或任何新计算。
2. **模型原档与行情原档分开。** 部分历史帧只封存模型字段，没有独立 OHLC。本页可用当前已发布版本行情截断到所选日期配合展示，并标明它不是当时封存的 OHLC。美股返回 `priceHistoryOrigin=current_published_version`；当前复权数据不冒充不可修订的历史原始行情。
3. **后来走势不改变当时判断。** 区间、尺度、证据等级、模型版本、首次可见时间保持来自所选记录。打开后来走势不重算拟合，不更新旧模型结论。
4. **当前与旧提醒分开。** 区间结束日早于当前参考日期时显示“区间已过”；行情已更新而模型较旧时显示“待更新核对”。未用历史列表的最后一个非空区间冒充最新有效提醒。
5. **近端区间不被五日条件隐藏。** 至少提前五个交易日仍是评价维度，不是本次 UI 的显示门槛。当天或很近的候选区间按原数据展示。
6. **首次可见不补造。** 缺少 `first_visible_at` 就显示未记录，不能以计算时间、文件生成时间或本机首次读取代替真实提前发布。
7. **证据不升级。** 复用既有证据显示策略和统一徽章；界面更集中不意味着失败结果、描述性字段或研究候选获得了校准概率、正式交易提醒或样本外有效性。
8. **跨市场日历诚实。** US 结果未建立完整节假日覆盖时，保留日历缺口提示，不因界面显示了日期就宣称未来交易日已精确核验。
