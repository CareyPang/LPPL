## 1. 用户目标与本次交付

核心用户是关注 A 股、通常持有 1–6 个月的普通投资者。他们需要发现值得重新研究的标的、查看潜在顶部时间区间、保存关注理由，并在下次访问时继续。本站不以随后下跌 10% 定义所有成功，也不把任意提前 5 天门槛作为前端隐藏已有观察区间的依据。

新增入口 `research-workspace.html`，首页“我的自选”提供入口。现有首页主视觉、拟合参数、结果、API 和图表保持各自维护边界。用户在原有自选入口添加的指数和股票在工作台继续可见。

本次建立可运行的浏览器本地闭环：

1. 添加上证指数、贵州茅台或其他支持标的。
2. 使用分组、当前清单内搜索、状态筛选和排序。
3. 查看真实已发布结果的日期、模型身份、计算覆盖、可显示的区间与证据状态。
4. 比较少量标的的结构化摘要，明确不同日期与口径。
5. 保存绑定当时结果的笔记，查看版本与本机观察变化。
6. 打开既有分析页，返回工作台后保留清单与研究状态。

本地工作台不是账户系统、全市场选股器、通知投递服务或服务器预测封存账本。本次不放置声称这些能力已实现的按钮。

## 2. 视觉系统

方向：浅色、安静、以研究清单为中心的专业工作区。页面标题使用“我的研究”，不另起一个未经确认的产品品牌。不恢复旧海洋首页，不覆盖现有首页主视觉。

| 层级 | 规范 | 原因 |
|---|---|---|
| 页面底色 | 浅灰白 `#F6F7F9` | 长时间阅读，突出内容面 |
| 内容面 | 白色，细边框 | 减少多层卡片和阴影 |
| 正文 | 深蓝灰 `#172033` | 保持对比度 |
| 辅助信息 | 灰蓝 `#586579` | 日期、来源、解释清晰但不抢主层级 |
| 主要操作 | 蓝色 `#3155D9` | 与价格红绿分工 |
| 数字 | 等宽数字，右对齐 | 便于纵向比较 |
| 交互 | 44px 触控、可见焦点、160–220ms 微动效 | 支持键盘与触屏 |
| 动态偏好 | `prefers-reduced-motion` 降级 | 操作不依赖动画 |

这里不使用生成图片：清单、证据与交互已经承担视觉表达，装饰图片会挤占研究空间。未来教程封面若需要图像，单独使用图片生成工具，标记为插画，不把合成图当作真实行情或回测证据。

### 桌面

顶部保持简单站点入口和当前位置。标题旁放“添加标的”“刷新已发布结果”。摘要仅显示真实清单计数、已读结果变化等可核实信息，不制造风险总分。

主体以研究清单为主，选中标的摘要为辅；比较、笔记和变化记录按任务组织。AI 不在本页强制展开。刷新不得清空正在编辑的笔记，不得把阅读位置推走。

### 390px

采用单列；股票列表可读名称、代码、截止日、状态和区间。分组可以局部横向滚动，比较表只允许自身滚动。主要操作可换行，关闭与返回均有文字名称。正文不能横向溢出，不能靠缩小字体模拟桌面布局。

## 3. 数据与证据约束

- 所有业务读取经过现有 `app/lppl-data.js`；本次不修改该文件。
- 工作台不直接 fetch 数据文件，不调用 `stock.request`、`replay.request`、AI 或计算端点。
- 指数只读最新已发布结果；个股只读已发布结果，失败时保留已有本机记录并注明状态。
- `stock.latest()` 在当前适配层中可能将不同失败归并为 null；页面只能说“未取得已发布结果”，不能断言一定是 404、没有信号或不存在该股票。
- 不把“未计算”当成“没有区间”；区分覆盖不足、证据不可显示、尚无可展示区间与读取失败。
- 不显示 `none`、`fail*`、`dev_only`、`dev_failed` 等被契约禁止的模型数值；尺度证据按现有契约独立处理，未知等级默认不展示数值。
- 不增加泡沫总分、见顶概率、目标价、前端模型、趋势/动量指标或新的过滤规则。
- 不把窗口长度与预测提前量混淆，不把簇内占比表述为预测命中率。
- 价格如果展示，使用原始已发布行情及对应日期；不能把已保存收盘价称为实时价。
- 过期状态依据明确的后端状态或时间对应关系；不自行用星期几猜交易所节假日。

## 4. 保存与时间语义

| 时间/身份 | 含义 |
|---|---|
| `asof` | 数据或分析截止日 |
| `generated_at` | 结果生成时间，如源中存在 |
| `prediction_id` | 源提供的预测身份，不自行拼造 |
| 本机记录时间 | 此浏览器实际读到摘要的时间，依赖客户端时钟 |
| 首次公开发布时间 | 需要服务端可信记录；本次不推断 |
| 通知送达时间 | 需要通知系统回执；本次未实现 |

原有自选代码仍保存于现有两个存储键。新工作台只保存自己的分组、视图、笔记、近期研究和有限摘要观察记录，不创建独立自选名单。

变化记录从用户开始使用本页时建立：第一次读取建立基线，之后实际读到有效变化才追加。无变化刷新不创造新提醒。历史记录不会用最新结果覆盖；记录有容量限制，页面与文档不宣称永久、完整或跨设备。

笔记保存内容、标的、截止日、模型版本和可用预测身份；编辑保留版本。缺少源字段时保持缺失。存储异常必须显示保存失败，不能出现假成功。移除自选与清除研究记录不是同一个动作。

浏览器本地存储可被清除，也不具备服务端不可篡改证明。多标签页并发编辑需要明确处理；任何尚未实现的冲突合并不得宣称为云同步。

## 5. 页面间衔接

本页通过显式 `from=research-workspace` 进入原有指数/个股分析页，后者显示固定同源的返回链接，不接受任意 return URL，防止开放重定向。

本页内可以恢复当时保存的研究摘要；进入原有分析页的入口明确指向当前分析。当前指数历史路由可能在缺少缓存时触发计算，因此本工作台不为了恢复笔记而自动请求任意历史日期。未来接通跨页历史上下文时，必须采用只读解析，区分“查看封存结果”和“请求重放”。

PR #142 正在处理 Full chart 的 asof、行情独立显示与 AI 布局；本次不复制该实现。PR #143 正在统一口径和空状态文案；合并时保留其业务文案，再接本次轻量入口。

本次与 #143 的潜在文件重叠仅涉及已有首页/分析页的入口或返回脚本。新工作台模块独立维护；不应把整个旧 HTML 覆盖回主线。

## 7. 设计验收方法

按真实任务验收，而不是统计按钮数量：

- 空白浏览器无假自选；添加上证与茅台后两种旧自选入口也能读取。
- 分组/筛选/排序、选中项与笔记在刷新和返回后保留。
- 结果缺失、读取失败、部分尺度、无区间分别显示。
- 证据失败字段与未知字段不会变成数字卡。
- 快速切换标的时旧请求不覆盖新选择。
- 实际摘要变化显示前后记录；首次读取不伪造历史修订。
- 存储失败不会显示保存成功。
- 桌面/390px、键盘、reduced-motion 和空数据都完成操作。
- 请求日志证明工作台没有模型/AI/历史 POST。
