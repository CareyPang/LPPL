# 观时第一版 · 从自选回到当时

2026-11-18。研究入口为站点首页的「观时 · 自选回看」或 `guanshi.html`。本版为普通投资者提供一条完整路径，先看持有资产的顶部时间窗，再核对判断的出处，最后回到同一份自选。PR 基线为 `main@958594c`，本机发布链路构建采用 `stock-results@7dd3d586` 的真实归档。

## 从哪里开始

1. 打开「研究标的」，分别点星收藏上证指数、贵州茅台、振华重工。切到「我的自选」。首次访问不会自动写入三只资产，站内已有的指数和股票自选沿用原存储。
2. 在自选内筛选「茅台」，打开资产。身份、行情截止日、模型截止日和研究判断在首屏，先出现的行情可以直接阅读。11 月 17 日的茅台记录完成了六个尺度中的两个，均无合格拟合，其余四个标记为未计算。
3. 选研究日期 2025-05-23 或进入有候选区间的历史记录。首屏标出日期范围，下方时间轴用水平括线表示模型关注的日期。红绿保留给日 K 与量柱。读者可以用鼠标、触控或左右方向键读某一根日线。
4. 打开证据，核对记录性质、研究截止日、模型版本、日期区间的证据等级及原始资料。点击「查看后来走势」揭开交易日行情，再收起。两个视图共用时间轴，原始区间的位置、模型输入截止日和证据不随切换改变。
5. 点击「返回原列表」或浏览器后退，恢复原自选页签、筛选词、滚动位置与刚才的资产行。下次可从「继续上次研究」打开上次阅读日期。

6–12 月指模型使用的拟合尺度。它不能单独确认阶段顶，区间的宽度也没有转换为命中概率。本版沿用已归档的输出；没有引入新的最低提前天数或随后跌幅要求。

## 行情、来源和可见时间

- 上证完整行情和模型通过现有 `LPPL.fetchResult` 接入站点构建的指数结果。截止日至少有真实收盘价才能画图。缺 OHLC 的早期原档用收盘线。缺成交量保持空缺，保留原生单位。
- 贵州茅台的可复核行情底本来自已有的 Worker `GET /market?code=600519` 原始响应。640 根未复权日线从 2024-03-27 到 2026-11-17，末日收 1,457.70 元。测试和产品共用一份原始文件。当前研究页提供手动检查更新，模型和行情的截止日独立显示。历史视图使用固定日期版本。
- 构建从 Git 原始 blob 和前瞻账本生成最多 12 个上证收盘后同日封存的节选，每个最多 100 根原版日线。核对证券身份、交易日、上海当地封存日、版本与 SHA-256。当前通过的是 10-29、10-30、11-16、11-17 四日，前两份只有收盘价。每份附原档固定提交链接。封存只证明该版本存在。
- 对比不同版本时，11 月重编的上证行情曾把同一交易日的原生量值缩小为另一份的百分之一。原版行情保持原值；若后续资料与原档共同日期的量不一致，后续量柱留空，并提示原因。查看后来走势不替换原日收盘。
- 研究页只读行情、模型及封存文件。选历史日期不会排队计算 104 周历史。异步返回会校验当前资产和阅读位置。空归档、读失败、部分尺度未计算和没有候选区间各有文案。

## 视觉和验收

桌面把价格图和研究证据并排。390px 将结论和图表提到证据前面，证据可折叠，保留原始日期与行情来源。暖白底和墨色正文支持长时间阅读。海蓝用于选择、截止线和时间窗，线型和文字提供颜色以外的识别方式。时间窗位于价格坐标之外，不暗示目标价。

在本机用站点构建脚本装配上述版本的完整数据，于 Chrome 157、1440×900 和 390×844 运行端到端测试。真实路径涵盖从首页加自选、在筛选结果中打开、证据展开、日期切换、事后揭示、收起、原列表与焦点恢复、真实缺档以及横向溢出检查。封存测试还逐项断言揭示前没有下一日 K 线，揭示后原证据保持相同。针对网络故障、不同口径和后续数据修订另有回归用例。测试代码在 `tests/e2e/test_guanshi.py`、`tests/test_guanshi_seals.py` 和 `frontend/tests/guanshi-*.test.cjs`。

复验时先取得 `stock-results` 本地引用并运行 `bash scripts/build_site.sh`，用本地 HTTP 服务提供 `_site`。将 `E2E_BASE_URL` 指向该服务，然后运行 `pytest -m e2e tests/e2e/test_guanshi.py`。复验本次固定分支的真实无覆盖场景设置 `GUANSHI_REAL_ARCHIVE=1`；常规 CI 对无覆盖案例固定缺档响应，以适应未来新增资产。截图可通过 `GUANSHI_CAPTURE_DIR` 存到仓库外。

本机回归运行了 385 项前端与 Worker Node 测试、43 项浏览器测试，全部通过。离线 Python 测试 526 项通过、2 项跳过。另用受控响应在两种宽度验证了主动刷新行情的成功、无变化、失败和切换日期后才返回四种情况。本环境直接读取 Worker 的茅台行情接口返回 HTTP 403，本次未验证当日在线刷新成功。

真实手机、Safari、大陆蜂窝网络性能和真实用户任务成功率属于 NOT_INSPECTED。候选窗的预测能力和用户当时是否收到某条历史提醒属于 NOT_ESTABLISHED。
