## 交付行为

**VERIFIED**：`lppl-data.js` 是页面唯一数据入口。进入国际标的详情先读已有行情与研究，再由用户点击“运行回测”。留空日期使用交易所时区下最新完整日线；填写日期只计算这一个精确截止日。不是104周批量历史回测，也不是策略收益回测。

新增历史截止日自动加入历史目录。已有同日静态原档优先，不覆盖；另行重算的版本以内容哈希封存。勾选“后来走势”只展开行情，不替换当时模型或研究结论。

## 三张卡的研究边界

**VERIFIED**：IXIC/NDX于2026-11-20的独立研究归档，经过核心文件与该资产输入文件哈希检查，并逐值比较6763个共同日线收盘。符合资产、截止日、输入与训练截止边界才复用。归档不匹配会明确记录原因，改用独立标识的日线研究，不把分钟结果移给别的资产。

- Omori分钟研究的起点是10月6日回顾性价格高点，不能称为11月20日新主震的事前估计。两者的衰减参数 p 均在0边界；最新主震之后尚无完整交易日。这不是“风险已经消失”。
- Båth归档使用11月5日起点，至11月20日只观察11个后续交易日，幅度差仍受未完成观察期影响。
- Productivity成熟历史样本为IXIC 52次、NDX 47次，训练截至2025年。斜率约0.633与0.451，两者估计区间均包含0。条件次数均值不是涨跌概率或抄底价格。
- 其他资产及较早截止日采用 `daily_aftershock_v1`：收益按此前63日收益的标准差标准化；负向冲击阈值、20交易日观察期、成熟事件训练均显式保存。日线与分钟口径独立展示。
- 参数估计、历史重建与真实预警效果分开。`first_visible_at` 没有被事后填写为历史日期。未运行新的预测效果检验，不能据此次接线声称抄底或逃顶更准。

原有 LPPLS 优化器、原 box 结果和完整周期1.5研究对照均保留。此前独立长窗口研究仍只在资产、截止日和数据版本一致时附加；本次按钮不自动重跑6600日多seed研究。

## 资讯与时间边界

**VERIFIED**：真实接入新闻标题、来源、时间、链接、hash，以及已有原始行情中的股息/拆股记录。当前资讯与模型截止日分开；模型日期之后取得的当前资讯明确标识，不画成当时已知事件，也不喂入 LPPLS。
