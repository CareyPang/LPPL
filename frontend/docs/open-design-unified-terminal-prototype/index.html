什么是 PIT（Point-in-Time）无前视偏差回测？

零未来函数 · 实盘可复现
PIT（Point-in-Time，时点快照回测）是指：站在历史某一天 as-of = T 的收盘时刻，严格只允许使用 T 日及之前当时真正已经披露并冻结的数据做拟合与打分，绝对禁止偷看 T+1 及之后的任何信息。
[误区 1] 全样本极值归一化：用 2015–2026 全历史最高/最低点算估值或筹码分位，相当于在 2018 年就提前知道了 2024 年的地板价。严重虚高
[PIT 做法 1] 滚动历史截断窗：所有 Z-Score、250日 VWAP 势阱 well_F、60日波动率 σ₆₀ 均严格截断在 date ≤ asof。严格截断
[误区 2] 盘中跨时区泄漏 + 事后标签：美股未收盘就混入当日残缺 K 线，或用事后确认的“最高点”回测买点。信号漂移
[PIT 做法 2] 分时区收盘锁 + 哈希封存：stock.py 按各交易所收盘时刻自动剔除盘中 bar，并用 SHA256 冻结每日快照与 forward_log。哈希防篡改
