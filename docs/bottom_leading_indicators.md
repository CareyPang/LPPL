# 抄底前瞻指标评估方案（v1.5 配套，2026-10-24）

目的：回答"哪些指标能提前预测底、现在上证是否接近底部"。原则：每个指标一张证据卡（文献 → A 股数据实测 → 开发段能否验证 → 怎么进模型 → 失败怎么说）。证据等级同 `docs/bottom_and_price_layer_design.md`（**[全文]** / **[摘要]** / **[出处已核]**）。数据覆盖期全部为本日 AkShare 实测（接口名、首末日期见 §6）。开发段 = 2000–2018。

---

## 0. 结论先行

| 问题 | 结论 |
|---|---|
| 哪些指标对"底"有可验证的证据 | 价格/波动自身的状态变量最强：**回撤深度 + 熊市久期**（开发段已验：B1 ΔBrier −0.0091 [−0.0131, −0.0053]）、**成交额萎缩后回升**（B2 已验：−0.0008 [−0.0012, −0.0005]，小但稳）；Omori 余震、熊市×高波动状态、融资去化正在验/待验。见 `reports/ladder_bottom_dev.md` |
| 哪些流传甚广但不能验证 | 北向资金（2014-11 起）、新增开户（2015-04 起）、新高/新低家数接口（2024 起）、社融（2015 起）：开发段几乎无覆盖，**不能进阶梯**，只能描述性展示 |
| 宏观/库存周期能不能用 | PMI 2008 起、PPI 2006 起、M1/M2 2008 起、工业增加值 1990 起：月频、开发段只覆盖约两轮库存周期（事件 <10），**不能做统计验证**；且 Goyal–Welch 2008 **[全文]** 的结论是宏观变量对股市的样本外预测"for all practical purposes…not been predictable"。只作背景面板 |
| 估值 | 全市场 PE/PB 中位数与破净比例 2005 起可取；Campbell–Shiller **[全文]** 支持估值预测**长期（数年）**收益，不预测 60 日止跌。作背景面板，不进阶梯 |
| "现在上证接近底部"怎么回答 | 产品输出三件事：止跌状态概率等级（来自保留链逻辑回归 + 固定 Platt）、见底时间区间（久期风险率 + 余震衰减）、该等级历史假底率与横盘率。**不输出日期**。在模型锁定并过校准段之前，不对 2026 年给任何判断 |
| Ising | 不进名单（不可标定，无样本外记录） |

## 1. 评估框架（固定）

- 标签：三重障碍有效底（`research/labels/bottom.py`）；开发段事件：指数 75 段、个股 1536 段；候选底结局 78% 横盘 / 14% 有效 / 8% 半山腰（`reports/bottom_label_events.md`）。
- 进阶梯条件：日频或可日频化、PIT、开发段覆盖 ≥ 10 年、事件 ≥ 30；相对前一保留级 ΔBrier 90% 块 bootstrap 区间不含 0（主链）/ 点估计 < −0.001（次要链）。
- 描述性层：不满足覆盖条件的指标只在产品里作"背景面板"，不参与概率，不参与淘汰。
- 必报：假底率（报警后先触下障碍）与横盘率（报警后到期未触），因为开发段 78% 的候选底是横盘。

## 2. 证据卡

### 2.1 价格与波动（可全期验证）

| 指标 | 定义 | 文献 | 开发段 | 阶梯位置 / 结果 |
|---|---|---|---|---|
| 回撤深度 | ln P − 250 日最高 | Johansen–Sornette 2001 **[摘要]**：回撤分布拉伸指数，极端为离群；De Bondt–Thaler 1985 **[摘要]**：输家 3–5 年反转 | 2000 起 | **B1 已验，保留**（dd_nodur_z：Brier 0.0888→0.0797） |
| 熊市久期 | 自 250 日高点天数 | Lunde–Timmermann 2004 **[摘要]**："the longer a bear market has lasted, the higher is its termination probability" | 2000 起 | B1 的 dd 变体（含久期）Brier 略差于不含久期版（0.0908 vs 0.0909 原始尺度；z 版选中不含久期）→ **久期在 A 股增量不明显**，待分时期检验 |
| 熊市反弹次数 | 60 日内 ≥5% 反弹次数 | Maheu–McCurdy–Song 2012 **[摘要]**：熊市反弹是独立状态 | 2000 起 | 待加入 B1 变体（下一版） |
| 熊市×高波动 | 500 日收益<0 × rv20 五年分位 | Cooper–Gutierrez–Hameed 2004 **[摘要]**：1929–95 下跌市后动量为负（输家反弹）；Moreira–Muir 2017 **[摘要]** | 2000 起 | **B4**，运行中 |
| Omori 余震衰减 | 主震（60 日回撤首破 10%）后 20 日 |r|>2σ 次数 / 基准率；Omori 指数 | Lillo–Mantegna 2003 **[全文]** p=0.85；Petersen 等 2010 **[全文]** Ω_a=0.32（市场级，1 分钟） | 2000 起 | **B3**，运行中；日频有效性文献无直接证据 |
| 波动率峰值回落 | rv20 距 60 日峰值 | 隐含于 Moreira–Muir；Guttal 2016 **[全文]**：崩盘前方差上升 | 2000 起 | 并入 B4（rv20 分位） |

### 2.6 情绪
Baker–Wurgler 2004/2006 **[全文]**：低情绪后小盘/高波动/亏损股收益高（横截面）；Huang–Jiang–Tu–Zhou 2015 **[摘要]**：对齐情绪指数样本外显著。A 股情绪代理（新开户、换手、封闭基金折价、IPO 首日收益）开发段覆盖不全，暂作描述性。

## 3. 合成方案：底部状态模型

1. **概率**：保留链逻辑回归（B0→…→B8 淘汰后），输出未来 20 日出现有效底的概率；校准段固定 Platt；产品映射为低/中/高三档，每档附历史假底率与横盘率。
2. **区间**：B-INT——以久期风险率（B1）和余震衰减预测时刻（B3）给中心与宽度，校准段保形缩放到 80% 覆盖；基线 = 无条件熊市久期分位。
3. **背景面板**（不影响概率）：估值分位、破净比例、融资余额 20 日变化、PMI/PPI 最新值与方向、北向 20 日净流入。每项标注"覆盖期不足以验证"。
4. **决策层 D-BOT**：基线为波动率目标（波动回落自动加仓）与"收复 60 日高点 10% 后加仓"的反向跟踪止损；候选为状态概率分批。候选不胜过基线不进产品（顶部 D-TOP 的教训）。

## 4. 验证顺序
1. 完成 B0–B8 开发段阶梯（运行中）→ 分时期（2001–09 / 2010–14 / 2015 / 2016–18）与指数/个股分组报告 → PBO/SPA。
2. B5 融资子样本阶梯（2010 起）。
3. 下一版候选（需登记）：熊市反弹次数、换手率、自算宽度、破净比例（2010 起子样本）。
4. B-INT 与 D-BOT 在保留链上跑。
5. 校准段只做 Platt/保形；最终测试段锁定后一次。

## 5. 失败表达
若保留链只剩 B1/B2：产品只说"当前回撤深度与成交额萎缩处于历史 X% 分位，这种状态下历史上 20 日内出现有效底的比例为 Y%，假底 Z%、横盘 W%"，不给任何"接近底部"的定性结论。
