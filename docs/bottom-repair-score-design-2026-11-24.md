## 1. 要解决的问题与不变边界

当前四维评分把估值和回撤深度直接加到买入分；旧入口还把满 50 分映射到 30% 仓位。科创50归档的趋势修复为零，仍可由旧函数得到买入动作。**V2 的目标是衡量修复过程，并另行验证交易价值，不能只是换一组主观权重。**

对普通用户分别回答：

1. **现在是什么环境？** 跌了多少、跌了多久、估值和长期宽度如何。
2. **有没有开始修复？** 低点、下跌冲击、价格趋势、成分股参与分别有没有改善。
3. **什么时候可能出现底部区间？** 独立的时间定位任务；不能由修复总分反推出日期。
4. **这时买入通常会经历什么？** 对应期限的费后收益、再创新低、途中浮亏和等待时间。

完整周期 1.5 的 LPPLS 研究基线保持不变；不重新设定优化器，不全量重跑。已有 B1/B2/B3、H1/H2/H3、Q2、MPL、Ising、Q-DD2、PPE 等失败/未验证结果保留。`docs/evidence_table.md` 中 B1/B2/B3 的校准/检验失败不能被旧开发段文档的正结果覆盖。

## 3. 数据与时钟契约

- `t` 是所属交易所的完整交易日，所有窗口按交易日而非 JSON 帧计数。盘中数据不冒充完整日线。
- `known_at` 为原始数据已可获得时刻，`computed_at` 为算完时刻，`first_visible_at` 为服务器首次可见时刻；客户端实际展示另记 `client_rendered_at`。历史重放的 `hypothetical_known_at` 不能填入真实首次发布字段。
- 特征只使用 `known_at <= cutoff_at` 的输入；行业成分、财务和估值按发布时间/修订版本做 as-of join，不能仅凭财务报告期或表内 date 声称 PIT。
- 保存 `asset_id/exchange/currency/calendar/price_basis/source/asof/fetched_at/status/stale_reason/input_hash/universe_hash/score_version`。指数与可交易 ETF 使用不同资产 ID。
- OHLC 的复权口径一致；实际成交账本使用真实未复权成交价格，分红/拆分另记现金和份额。最新复权因子不得悄悄改写封存历史输入。
- 停牌/缺失/无成交不向前填值后伪造低波动；返回缺失原因。真实零值保留。指数供应商没有可靠 high/low 时不能伪造 ATR，可另登记 close-only 版本，本版不自动替代。
- EMA 以输入前缀最初 n 个有效交易日 SMA 为种子，再按 `alpha=2/(n+1)` 递推；保存输入起点及初始化版本，增量与完整重放须一致。价格评分至少有连续 120 个有效交易日；252 日背景不足则该背景缺失，不借短样本冒充一年。
- 后续日线新增不能改变旧截止日评分与锁定时间；原始数据修订生成新 vintage，旧版本仍可回放。

## 4. 背景层：不直接加买入分

1. `DD252 = C_t / max(C[t-251:t]) - 1`，固定称“距252交易日最高收盘的回撤”。另显示距最近该高点的交易日数，不称精确熊市起点。
2. 截至 `t-1` 的 5/20/60 日收益、相对 EMA20/EMA60 的位置，用于分层；当天异常用 `t` 的数据。不得使用事后阶段顶底作为当时阶段输入。
3. `P250`：同一指数当时成分中站上250日均线的比例，展示原值和20日变化；它是慢背景，不设“P250先超过50%才允许短反弹”的闸门。
4. 估值：先提供来源、发布时间和历史位置；ERP 必须说明盈利收益率、对应债券期限和口径。全 A 估值只能作全 A 背景，不冒充科创50的估值。估值与短期止跌的增益另测。

第一轮分层用前一日的简单互斥标签：`C>=EMA60 且 EMA60斜率>=0` 为中期上行；`C<EMA60 且斜率<0` 为中期下行；其余为过渡。中期下行中 `R5>0` 标记短反弹，仍保留原阶段。下跌早/中/后段暂按回撤/距高点天数的开发段分位分层，不能把长跌机械命名为即将见底。所有阶段都报告。

分层的EMA60斜率固定为20交易日变化，全部滞后到`t-1`。学习基线的`RV20=sqrt(252)*std(r[t-19:t],ddof=1)`；不把年化波动率与ATR混为一个字段。M0—M3共同样本要求DD252及全部该候选特征可计算，价格展示分的120日暖机不能替代学习基线的252日数据要求。

## 5. 七项核心候选：原始值、含义、缺失规则

以下切片端点均包含。`clip(x)=min(1,max(0,x))`。`r_i=ln(C_i/C_{i-1})`。`TR_i=max(H_i-L_i,abs(H_i-C_{i-1}),abs(L_i-C_{i-1}))`。`a_t=mean(TR[t-20:t-1])`，即前一日可知的20日平均真实波幅，不与 Wilder 平滑 ATR 混用。

`DV_n=sqrt(mean(min(r_i,0)^2, i=t-n+1..t))`，均值包括非负日的零项。若分母、价格不合法或 `a_t<=0` 则依赖指标缺失；不把无交易的平线评为极佳修复。

| ID | 原始特征 x | 映射 f（0–1） | 投资者语言 |
|---|---|---|---|
| F1 | `(min(L[t-4:t])-min(L[t-24:t-5]))/a_t` | `clip(0.5+x/2)` | 最近5日低点，是否高于此前20日低点 |
| F2 | `(C_t-EMA20_t)/a_t` | `clip(0.5+x/4)` | 是否收复短线趋势 |
| F3 | `(EMA60_t-EMA60[t-20])/a_t` | `clip(0.5+x/4)` | 中期趋势是否转好 |
| F4 | `ln(DV20/DV5)` | `clip(0.5+x/(2*ln(2)))` | 下跌冲击是否减弱；不单独预测上涨 |
| F5 | `P20_t-P20[t-5]` | `clip(0.5+x/0.40)` | 站回20日线的成分股是否增加 |
| F6 | `P60_t-P60[t-20]` | `clip(0.5+x/0.30)` | 中期修复是否扩散 |
| F7 | `mean(v_i-u_i, i=t-4..t)` | `clip(0.5+x/0.40)` | 上涨组是否获得相对更多成交额 |

这里 P 是 0–1 比例，0.20 指20个百分点，不是相对增加20%。映射宽度、等权和几何均值都是**低自由度工程基线**，没有文献或本轮回测证明其最优；50分也不是买入阈值。全部原始值保留，以便后来检验，不在初次8个事件上挑最佳宽度。

F4 特例：`DV20>0 且 DV5=0`，记录原值 `positive_infinity` 状态并将 f4 置1（JSON数值保持 null，单独记录边界标签）；`DV20=DV5=0` 为没有可识别下跌冲击，f4 缺失，不置1。价格新低告警独立保留，不能被低波动掩盖。

### 5.1 宽度与成交集合

- P20/P60/P250 都是站上对应均线的股票比例，**不是未来20/60/250日涨跌概率**。
- 科创50使用当天已生效的科创50历史成分；全 A、沪深300、创业板分别有自己的 `universe_id`。缺历史成分就显示缺失，全 A 只作旁边的背景卡。
- Pn 分母为该集合中有足够历史、当日可比较价格的成员；展示有效数/应有数/缺失数、成员变动和价格覆盖。暂停交易从交易参与分母剔除并单列，不能把暂停当作平盘交易。
- 差分 F5/F6 用两端共同有效的成员交集重新计算两个时点 Pn，避免成分更换/IPO把宽度差分伪造成修复。分别保存两端原生 Pn 与共同集合差分。每端`有效数/该端应有成分数≥90%`，且`共同有效数/max(两端应有成分数)≥90%`才生成本版差分；不可用交集自身作分母。记录加入/退出/缺历史成员。90%是预登记数据质量约定，不是预测门槛。
- `A,D` 按同一时点、同一集合与一致复权后的前收盘比较，平盘单列。`u=A/(A+D)`；`v=上涨组成交额/(上涨组成交额+下跌组成交额)`，平盘组两边均排除。F7的5天每天都需上下两组存在、各组数据完整；任一天缺失则F7缺失。保留各天覆盖和上/下组金额，金额不是净流入。

### 5.2 TRIN、MCL、P250与期货怎样使用

标准量版 `TRIN_volume=(A/D)/(V_up/V_down)`；额版必须命名 `TRIN_amount`，不能混成同一个时间序列。由于 `log(TRIN_amount)=logit(u)-logit(v)`，它与F7来自同组信息，不再额外加一票。只有A、D、上/下组量都正时计算，零分母返回缺失，不补中性1。

MCL先明确是 McClellan oscillator 还是 summation index；如采用比例调整振荡器，登记 `RANA=1000*(A-D)/(A+D)`、`EMA19(RANA)-EMA39(RANA)` 与初始化方式。它与红盘率/宽度共享输入，作为F5/F6的替代实验，不把三者当独立确认。历史分位只能用此前已知数据，不能拿整段2021–2026的分位评2022。

TRIN定义可对照 [TradeStation官方文档](https://help.tradestation.com/10_00/eng/tsdevhelp/elword/function/armsindex_function_.htm)，MCL计算可对照 [作者网站](https://www.mcoscillator.com/learning_center/kb/mcclellan_oscillator/Calculating_the_McClellan_Oscillator/)。这些是定义来源，不证明在 A 股的预测有效性。

逐合约期货升贴水、融资、ETF申赎、LPPLS、真实Omori/Båth/productivity放后续独立实验。期货需统一现货时间、到期日、分红融资成本和换月；升水/贴水不能直接等同看涨/看跌。Omori描述冲击衰减，不自动提供价格方向概率。

## 6. 第一版如何给分：不把缺数据重新分权

研究候选 `bottom-repair-price-v2-draft`：

```text
s = (f1 + f4) / 2                 # 低点与冲击
r_short = f2                     # 短线收复
r_medium = (f2 + f3) / 2          # 短中期价格修复

low_shock_condition_score = 100*s # 低点与冲击条件分，不命名“已经止跌”
short_repair_score = 100*sqrt(s*r_short)
medium_repair_score = 100*sqrt(s*r_medium)

breadth_score = 100*(f5+f6)/2     # 单独证据卡，不加到价格总分
participation_score = 100*f7     # 单独证据卡，不加到价格总分
```

几何均值仅用于减少一项强、另一项弱被简单加法掩盖；不是独立概率相乘。F1/F4、F2/F3仍可能相关，必须做消融。不强求所有指标同向，也不以中期斜率阻止短线反弹观察。

s内部仍允许低点很弱与波动回落部分相互补偿，不能据此生成“已经止跌”。创新低标记与F1原值始终可见；低波动单独转好时，文案只说冲击减弱。

依赖缺失时对应分数为 null，列出 `missing_features`，不把其余权重拉满。缺宽度不会改变价格分；宽度/成交卡分别缺失，不能伪装成完整七因子模型。价格因子齐全不代表预测证据充分，单列 `evidence_status`。

新增字段放 `bottom_repair_v2` 下，绝不覆盖现有 `fco_neg_intensity` 或四维 `bottom_factors`，避免旧50分买入分支把新50分误当触发。现有50.6分保留原名和日期。版本不同的分数不能直接连成一个“分数上升”曲线。

“还在创新低”“数据过期”“有有效顶部区间”以解释标记并排呈现，不悄悄把原始分数归零。第一版只显示改善/减弱及原因，不设置新的买入门槛或仓位。

## 7. 三张成绩单：定位、后续表现、可执行交易

### 7.1 底部日期定位

先登记两个纯价格标签：局部低点为前后各20个交易日的最低日线 low；阶段低点为前后各60个交易日的最低日线 low。同价平台取邻域内最早日。它们是未来信息参与的评分标签，禁止进入实时特征；不以以后必须涨10%定义成功。对窗口敏感性后续另登记，不能挑最好标签。

若将来预测未来20日内的低点，则局部任务标签最迟在 `t+40` 成熟，阶段任务在 `t+80` 成熟。数据不足为 pending，不是失败或成功。重合低点在两个任务各列但不当作两份独立样本。报告覆盖、漏报、误报、区间宽度、提醒提前/滞后；一天多版本和同一事件重复提醒去重，保留修订链。至少提前5日只作分层统计，不过滤较近的候选。

本版修复分**不生成日期区间**。已有LPPLS候选单独冻结比较；缺合格候选就显示“暂无模型区间”，不能用分数大小生成日期。

### 7.2 买入后表现（首个预测目标）

首轮主目标为**信号可见后买入，持有20交易日的ETF费后收益**。另外完整报告5/10/60/120交易日，不能只挑长期好看的50帧。

`entry_session=e` 是信号首次可见且可下单之后的首个正常可执行交易日；标准研究情景要求信号在e日开盘前已可见，买价 `O_e` 加滑点。如果直到开盘后才可见，不能使用已发生的开盘价，顺延至下一合格开盘并记录延迟。持有H个交易日统一在 `e+H` 的开盘按预先排定订单退出，持有区间日线为e..e+H-1。不可成交时不硬填成交，保留未成交与偏移。

目标 `Y_H=1{R_net,H>0}` 仅能命名“持有H交易日费后上涨”，不能命名“抄底命中”。同步报告：

- 每条信号及各期限的可用样本分母；均值、中位数、分位数与净收益。
- 日线high/low口径MFE/MAE、期间再创新低、首个收盘恢复费后盈亏平衡的天数、未解套的删失状态。
- MAE是相对入场价最大不利变动；路径最大回撤另算，不把未来最低周收盘当MDD。
- 实际退出开盘的隔夜跳空和成交滑点仍属于持仓损益；MAE/MFE与资金曲线必须纳入实际退出成交价。延迟退出时，持仓日线区间延伸至真正退出前一日，再加退出成交价，不在计划退出日提前截断风险。
- 阈值划分事件时首报、观察、修订与新提醒分开；不能每周重复计胜率。

中期反转结构另给60日辅助标签：固定从信号日t之后计算，`min(L[t+41:t+60]) > min(L[t+1:t+20])`，且`t+41..t+60`中至少10日收盘在当日MA60之上，`label_end=t+60`。这里起点是t，不是ETF实际入场e；两个任务分别记录时间轴。该定义是待验证约定，不称“永久反转”；未来MA仅在标签里计算。先不为它另调一套模型。

### 7.3 真实可交易ETF

科创50信号 `SSE:000688` 的首个固定载体为 `SSE:588000`（华夏上证科创板50成份ETF），身份已对照 [上交所基金信息](https://www.sse.com.cn/assortment/fund/list/etfinfo/basic/index.shtml?FUNDID=588000) 和 [基金公司](https://www.chinaamc.com.cn/fund/588000/index.shtml)。身份核验不等于策略有效。

## 8. 怎样检验指标与权重，而不是调到好看

### 8.1 有限候选与强基线

先运行审计用的小样本提取，不重跑LPPL：科创50现有9次首报（8成熟、1待成熟）及匹配对照日期；再扩展7指数日频覆盖审计。9次事件只用于发现口径错误和展示交易路径，**不用于训练7参数模型或宣布胜率提升**。

当前只登记科创50→588000。其余6指数先做数据与事件覆盖审计；未另行冻结各指数对应的当时可交易ETF、成本和数据版本前，不得加入ETF费后目标的M0—M3训练/校准样本，不能拿指数收盘收益补ETF标签。科创单一市场样本不足时就停在描述与事件回放，不能为了训练而把相关日线行数当成独立事件数。

比较顺序：

1. 旧四维规则原封不动；仅跌深的简单基线；固定止跌价格基线；本版两个价格修复分。
2. 简单正则逻辑回归候选：M0仅背景 `DD252、距高点天数、RV20`；M1=M0+F1–F4原值；M2=M1+F5–F6；M3=M2+F7。背景项作为条件变量不强制单调加分；所有阶段均保留。
3. 只有M2覆盖充分时才在**同一完整样本交集**与M1比较；不能拿不同数据区间宣称宽度有增益。MCL/TRIN作为后续同组替代，第一轮不增加候选数。

预测主目标只用20日费后上涨；采用L2、固定 `C=1`、不做类别重权重或超参网格。数值截尾/标准化只在每个训练折拟合并封存，逻辑回归输出初期仍为 `raw_model_score`，不先宣传概率。稀疏事件、全一类或分离不稳定时停止该候选并报告，不用重采样制造新市场事件。

学习预处理约定：F4原值先限于`[-ln(4),ln(4)]`，其正无穷边界映射到`ln(4)`并保留状态标记；其他非法值不进入学习样本。随后各特征按训练段1%/99%线性插值分位截尾、用训练均值和标准差（ddof=0）标准化，常量特征固定为0并记录。变换器在下一预测段不更新；不得用测试数据算分位。概率校准时不复用训练样本，数据不足直接缺失。这些同样是待冻结候选参数，变更须新版本。

### 8.2 时间分割与真正独立的检验

- 在运行前登记数据已被查看的范围、输入hash、候选表和排除规则。本次设计已受到科创8次历史案例影响；不能把这些案例重新标成盲测。
- 已查看历史采用扩展窗口训练、后续时间段评价，称“历史走步重放”；最后至少一个未触碰时间段或未来封存预测另作前瞻验证。2025–2026旧数据即使原帧写test也不能自动变成新规则的独立检验。
- 每条标签记录 `label_start/label_end`，训练/校准样本的label_end必须早于下一段预测起点；先按日期划分所有资产，再剔除跨界路径。单用随机K折或未经标签检查的TimeSeriesSplit不够。
- 同期指数共同波动，采用按日期对所有资产联合取块的bootstrap；交易期120日时块长至少覆盖该期限；同时按下跌事件聚类做敏感性分析。不能把7个相关指数当7份独立熊市。
- 完整记录所有候选和调参尝试；主比较采用同阶段、同提醒数量/持仓暴露。等提醒预算只作离线匹配评价；线上阈值只能在开发/校准段冻结，不用未来测试段排名决定当天是否提醒。

反复挑最好历史参数的风险见 [Bailey等，The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。它解释验证必要性，并未验证本设计任何指标。

### 8.3 概率与验收门槛

独立校准段使用固定逻辑校准（Platt），不能默认随机折校准；若样本不足，不输出校准概率。看分箱可靠性、Brier、log loss、基率、置信区间，同时看交易收益与过程风险。Brier降低不单独证明校准良好，见 [scikit-learn官方说明](https://scikit-learn.org/stable/modules/calibration.html)。[TimeSeriesSplit文档](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)是实现参考，不能替代label_end去重叠。

第一版只作工程排程门槛：校准与评价各不足30个独立事件簇、任一类不足10簇时，不发布概率；即使超过也不自动通过，需报告置信区间宽度与跨时期稳定性。30/10不是统计充分性定理。8次成熟事件显然不满足。

候选升级要同时满足：相同样本上优于简单基线、各时期/留一指数结果不由单次行情支配、概率可靠性不过度偏离、费后表现和MAE没有不合理恶化。登记主指标及95%联合日期块区间；区间跨0或样本不足写NOT_ESTABLISHED。发现结果后修改任何权重、阈值或标签都新开版本，旧结果保留。
