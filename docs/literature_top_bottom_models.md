# 顶部 / 底部模型文献再查：哪些"准"、哪些有独立复验、哪些我们已测（2026-10-29）

目的：回答"有没有对顶部、底部准确的金融 / 金融物理模型，对本项目有效"。口径：每个模型只记 (a) 原作者证据，(b) 有无**独立团队**复验及结论，(c) 能否在 A 股预登记复验，(d) 与本项目已测项是否重复。评级：`replicated_oos` / `single_oos` / `in_sample` / `contested` / `tested_here_fail`。

**总结论**：
1. 文献里**没有**能给出顶部或底部**日期**、且经独立复验的模型。所有"准"的宣称要么是事后拟合（LPPLS 早期、Hurst、CSD），要么被独立复验否定或削弱（Hawkes 临界、CSD、GSADF 实时、估值择时）。
2. 经独立复验仍成立的只有三类**条件概率**结论：① 信贷扩张 + 资产价格三年快涨 → 未来三年危机概率 7%→40%（Greenwood–Hanson–Shleifer–Sørensen 2022，42 国；Baron–Xiong 2017，20 国）；② 大涨之后崩盘概率上升但平均收益并不低（Greenwood–Shleifer–You 2019；Goetzmann 2016：翻倍后回吐概率仅约 10%）；③ 熊市体制识别 + 降仓能降回撤（见 `literature_regime_models.md`）。三者都是**年级 / 季级**概率，不是日期。
3. 本项目开发段已把文献里能日频实现的顶 / 底候选**基本测过一遍**（R1 涨幅波动、R2 GSADF、R3/R4 LPPLS、R7 统计物理、R8 广度、B1 回撤久期、B2 量能、B3 Omori、B4 高波动状态、B5 杠杆、B6/B7 负泡沫反泡沫、B8 统计物理）。结果与文献一致：少数在开发段有弱信号，校准 / 测试段不稳。
4. 对本项目**真正没测过、且有独立证据**的只有：(i) 信贷 / 融资 + 价格的**年级**泡沫风险面板（描述性，不作报警）；(ii) JM 熊市体制（已登记 M1）。其余不建议再追加。

## 3. 为什么"准"的模型找不到（与本项目结果一致的三点）
- 事件太少：A 股 2000 年以来有统计意义的顶 3 个、底 3–4 个；任何日频模型在这个样本上"命中"都可以靠 3 次事件凑出，所以 Round 1 才要求随机对照、Holm、LOCO——而加了这些之后没有模块通过，这不是实现问题。
- 文献中经独立复验的结论全是**条件概率且时间尺度为年**（信贷 / 涨幅 → 三年危机概率），本项目产品定位是月级区间；两者可以并存：年级面板做背景，不做报警。
- 所有被否定的模型都有同一个失败模式——事后看很清楚、实时看滞后或误报（GSADF 实时、CSD、Hurst、Hawkes n）。

## 4. 建议（待用户裁定）
1. **新增描述性"年级泡沫风险面板"**（不报警、不评分）：近 3 年指数涨幅、全市场换手率分位、A 股融资余额 / 流通市值、社融 / 信贷增速（2010 起）——按 GHSS 2022 / GSY 2019 的"快涨 + 信贷 + 换手"三要素并列显示，标 `replicated_oos（跨国年级）/ A 股未检验`。这是文献里唯一经独立复验的顶部结论，我们还没有。
2. **R8 横截面广度**进 Round 2 候选：开发段有证据但没进校准 / 测试；Round 1 校准 / 测试段已关闭，只能在外部市场或前瞻日志上评价。
3. **不再追加**：Hawkes 临界、Hurst、CSD/EWS、Ising、估值择时、负泡沫、Omori 预测版。
4. 底部：维持"便宜 ≠ 要涨"的描述性输出；文献里没有可用的底部日期模型，JM/HMM 只能告诉"熊市是否仍在"。
