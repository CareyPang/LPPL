# 价格层金融物理与微观结构深度研究：势阱 × OBV × 信息熵 × 订单流实证检验

> **研究目标**：在不引入未来函数（严格 Point-in-Time）的前提下，系统检验**自由能筹码势阱、250 日筹码均价折价、OBV 量价底背离、日线订单流代理（CMF/CLV）、Amihud 流动性冲击、排列信息熵（PE）与 DFA 标度指数**在 A 股下跌区间对“价格是否跌到位”的真实增量价值，明确**保留项与剔除项**。

---

## 一、实验设计与严格 PIT 口径

- **样本池**：A 股核心宽基历史冻结日线（`sh000001` 上证综指 1990–2026、`sh000300` 沪深 300 2005–2026、`sz399001` 深证成指、`sz399006` 创业板指 2010–2026）。
- **条件子集**：每周（每 5 个交易日）严格 PIT 抽样，仅考察处于显著回撤区（距 252 日高点回撤 `<= -12%`）的观测，共 **`2,060` 个回撤周**。
- **目标变量**：
  - `ret120`：未来 120 个交易日（约半年）收益；
  - `mdd120`：未来 120 个交易日内最大再回撤。
- **基线表现（全部回撤周）**：120 日上涨胜率 **`49.6%`**，收益中位数 **`-0.2%`**，后续最大再回撤中位数 **`-11.2%`**。
- **样本外稳定性检验**：将全样本一分为二，对比 **2019 年前（历史牛熊段）** 与 **2019 年后（注册制/量化结构市）** 的 Spearman IC 是否同向稳健。

## 三、四个关键金融物理洞察

### 1. 反直觉核心发现：半山腰的“筹码密集势阱”是套牢阻力，跌穿势阱进入高自由能真空区才是真出清
传统技术分析常把“成交密集区（筹码峰）”当作支撑位，但自由能 $F(x) = -\ln \rho(x)$ 的严格 PIT 实证给出了相反答案：
- **处于旧筹码主势阱内部（`well_F` 低、`well_depth` 深）**：120 日胜率仅 **`41.2%`**，中位收益 `-4.1%`，后续再回撤 `-13.5%`。物理原因是大量套牢盘集中在该能级，稍有反弹即触发解套抛压；
- **跌穿旧筹码主势阱进入高自由能区（`well_F >= 1.25` 且下方无更深旧势阱）**：120 日胜率跃升至 **`60.8%`**（较势阱内高 **+19.6 个百分点**），且 **2019 年前（IC `+0.180`）与 2019 年后（IC `+0.130`）高度一致**。此时筹码远离均衡态，市场已完成恐慌割肉出清，自由能梯度产生的均值回归回复力最强。

### 2. OBV 底背离在 2019 年后反而更有效
2019 年后机构与量化占比提升，直接拉升价格容易暴露意图，资金往往在低位震荡中**借阴线/十字星温和承接**，表现为 20 日标准化 OBV 显著强于价格变化（`obv_div` 2019 前 IC `+0.048` → 2019 后升至 **`+0.084`**）。

### 3. 日线订单流（CMF/CLV）的“双面性”与真实订单流边界
- 日线 OHLC 构造的 `CMF-20` 对控制后续 120 日最大再回撤有效（`IC_mdd = +0.112`），但在 2019 年后对半年收益翻负（`IC = -0.209`），说明**日线假阳线/脉冲反弹常是死猫跳或量化 T+0 对倒**；
- 真正具备强预测力的订单流（OFI / VPIN / 主动买卖盘不平衡）依赖 **Level-2 逐笔成交或高频盘口**，在日频开源数据体系中不应将日线 CMF 直接塞入抄底权重。

### 4. 为什么剔除信息熵（`pe60`）与 DFA（`dfa60`）？
日频 60 根 K 线的样本长度不足以稳定估计高阶熵与分形标度指数，2019 年前后微弱或翻号。遵循项目**防过拟合红线**，不将无样本外增益的物理炫技指标纳入打分权重。
