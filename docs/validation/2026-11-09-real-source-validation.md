## 5. 用户与东财/同花顺如何连接

推荐产品链路是 **用户浏览器 → LPPL 只读接口 → 腾讯后端私有缓存/采集服务 → 已获准供应商接口**。同一批日终数据共享抓取；不同用户开页面不增加上游采集次数。行情、资讯和 LPPL 计算使用独立任务，原始响应保存在私有存储，只有许可允许的字段进入公开页面。

用户浏览供应商官网、登录自己的客户端，是独立产品路径；不把用户 cookie、登录令牌或代理转交给 LPPL。浏览器直连第三方 API 还依赖 CORS、频率和接口稳定性，不能借此消除数据授权条件。涉及原文跳转时也按来源链接使用条款核验。

目前不改代理，不购买腾讯资源，不开每日定时。以后在获准的目标腾讯地域做独立后端路径验证，再在代表性大陆用户网络验证 LPPL 页面；这两项不能互相代替。

## 6. 放行后的有限样本验收

1. 记录具体端点/主体/用途/期限；自动访问、原始保存、衍生统计、公开展示分别确认。批准的账户或 token 只进私有配置，不入 Git 或前端。
2. 在明确 CN 出口路径上做受控 HTTP 连接验证，保留状态、延迟和错误；不以 DNS/TLS 成功替代 HTTP 或地理位置证明。
3. 取得供应商认可的调用限制，收紧本地串行预算。预先固定两日与市场范围，不临时扩展为全历史下载。
4. 保存 HTTP 原始字节后解析；核总数/分页/重复代码/返回日期/失败状态；原因/题材记录原文与适用市场。
5. 两日池按验证交易日历相邻；晋级分子按代码交集与连板一致性检查，分母和缺失可复核。历史补取标 later-acquired，不计当时已知或真实提前预测。
6. 生成 append-only 研究快照与失败回执，再复核封存/恢复。通过后才积累连续 5 日；公开投影和部署仍另行授权。
