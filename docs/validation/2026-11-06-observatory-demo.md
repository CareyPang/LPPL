# 海洋观测台：原首页、K线工作站与本地演示验收

日期：2026-11-06。交付范围：PR #50、可携带本地演示包；没有合并、部署或发布站点。

**VERIFIED：本轮直接修改 `frontend/home.html` 与 `frontend/stock.html`。** 用户选定海洋观测台方向，并要求先进入工作站再输入资产代码；这覆盖此前设计文档中首屏放查询框的建议。没有新建脱离原home.html的概念页。

## 1. 已实现的浏览路径

1. 首页海面：原海面视频和日落构图，暖白大字与局部阅读遮罩；首屏没有股票输入框。
2. 可选下潜：原入水/水下素材，原生滚动及可逆镜头，两级尺度说明可切换；不要求完成下潜才能进入工作站。
3. 进入工作站：统一去 `stock.html`。演示参数 `demo=1` 在所有工作站及返回首页入口保留。
4. 工作站欢迎：先看到资产输入和样本入口；无代码时不启动查询。选择资产后行情与任务状态独立展示。
5. K线与成交量：真实OHLC蜡烛及上下影、涨红跌绿与空心/实心区别、独立成交量面板、共用日期轴、十字线、日期滑块和20/60/120/250观测日范围。

首页移除了指数数据请求，以及模型Combo值对海况/色温/粒子的控制。海面只表达品牌与用户操作，不暗示风险大小。动画可关闭，默认静音；file协议与减少动效设置有poster回退。首页不会给出虚构的预测卡或已验证准确率。

工作站色彩沿用深海蓝、暖白与少量金色。涨跌色只用于行情，尽量避免品牌墨绿与下跌K线混淆。缺OHLC时不伪造开高低，而用已有收盘位置标记；成交量0与缺失分别用短线和×表达。没有可发布的研究窗口时保留空白，不展示假数值。

## 2. 演示数据及任务边界

离线演示仅含贵州茅台600519的250条既有冻结日线，截止2026-10-23，来源为仓库v20261104快照，价格前复权。原parquet的SHA256和样本文件字节SHA见 `frontend/assets/demo/manifest.json`。成交量保留原值，单位标为“源单位未核验”，没有擅自标成手或股。

演示任务可以排队、计算状态切换和完成，但结果明确写“演示已完成 · 未运行模型”。它不生成局部/阶段顶部区间，不把真实行情配上虚构预测，也不调用生产Worker、线上行情或计算接口。演示与真实任务使用不同存储键。

只包含一个真实样本：输入其他代码会持续说明演示范围，以及当前仍显示的资产。输入错误有独立alert区域，不被上一只股票的异步状态覆盖；下一次合法选择才清除。没有把指数000001冒充平安银行，也没有从网上补取第二只股票。

这里的“离线”指业务数据和模拟任务可离线运行；原首页字体链接可能尝试加载Google Fonts，离线时使用系统字体，不影响入口或图表。真实模式继续经现有 `LPPL.stock` 数据适配接口；本轮未修改 `frontend/app/lppl-data.js`，未改Worker、Actions或生产计算策略。

## 3. 本地演示包

使用 `frontend/demo-tools/package_demo.py --out <一个不存在的目录>` 构建，拒绝覆盖既有演示包。包含真实首页、工作站、app脚本、全部海洋视频/poster/图片回退素材、冻结样本、说明、文件哈希清单及Windows启动器；不依赖开发机上的Python环境。

Windows使用方式：解压整个ZIP，双击 `Start-Demo.cmd`。系统自带PowerShell启动只监听127.0.0.1的静态服务，浏览器自动打开 `home.html?demo=1`。关闭启动窗口即停止。无需安装Node/Python、不需要账户、不要求管理员、不产生云端发布；不能只把home.html单独发给别人。

启动器支持MP4范围读取，避免视频seek失效；只支持GET/HEAD，限定在演示目录内。端口默认自动选择。`index.html`另提供文件直开入口，源码按file协议切换静态画面；文件直开在本轮浏览器工具中未实测，推荐Windows启动器路径。

## 5. 研究与演示不相互冒充

本轮另有[逐日历史重放研究](../research/2026-11-06-top-time-replay-results.md)：旧六指数、每5观测日扫描的缓存，与本演示的个股OHLC快照不同。423,360行逐日账本不等于每日新拟合，真实发布账本为0行。阶段91事件上的联合TP0–3也不是本演示页面的可用预测结果。

后续产品接入应继续保持：行情先可用；当前计算与历史回放分开；真实首次可见时间与回放生成时间分开；两级提醒只有在上游具备对应证据后才显示。首页视觉升级不会改变任何模型失败裁定。

## 6. 同日 v2 修复：题句、叠字与工作站徽章

用户指出首屏题句遗漏、入水/水下文字重叠，以及工作站缺少闪耀徽章。本轮恢复题句（后按用户纠字为“启于青萍之末，满于狂澜之巅。”），保留两句分行与首屏工作站入口。前版被产品说明替换的题句属于视觉回归，不应再因改版丢失。

文字重叠原因是两个固定章节的淡入淡出区间重叠；原固定故事结束位置也晚于正文进入视口。现在各段先完全退出再进入下一段，镜头故事在正文进入视口前结束，实际正文位置另设快速滚动保护。手机保留足够下潜滚动距离。新增正向/反向连续位置互斥和正文交接回归检查。

工作站新增金属海洋品牌徽章和9秒周期的轻扫光，提供动效开关，沿用首页偏好，并响应减少动态效果与节省流量设置。徽章与研究证据、风险分数或预测成绩无关。查验当前代码、可见Git历史、旧前端和选定概念稿未找到原闪耀徽章，因此这是补回所需装饰效果，不声称原样复刻。
