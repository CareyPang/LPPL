# 腾讯云起步配置与采购边界

核查日期：2026-11-06。当前阶段是开发和小规模试用，尚无真实线上负载基准。以下是采购建议，不是已实测容量或延迟承诺；本次没有购买或部署云资源。

## 建议购买

优先查看腾讯云轻量应用服务器 Lighthouse 的 **中国大陆上海地域、4 vCPU、8GB 内存、Linux 系统镜像 Ubuntu 24.04 LTS**。同档南京地域可作备选；地域选择是工程判断，没有本项目跨运营商网络实测来证明哪一个更快。若当前可选镜像没有24.04，选仍受支持的22.04 LTS。

普通起步套餐：120GB SSD、10Mbps、每月1500GB流量。官方公开刊例是210元/月；通用4核8GB、180GB SSD、12Mbps、2000GB为230元/月。官方大陆普通时长折扣为半年88折、一年85折，活动另计。[官方价格总览](https://cloud.tencent.com/document/product/1207/73452/)

先查 [官方活动页](https://cloud.tencent.com/act/pro/lhsale) 和 [试用资格](https://cloud.tencent.com/act/pro/free)。本次能直接读取到活动页的4核4GB、3Mbps新用户首年109元；4核8GB的账号结算价及续费价没有读取到，不能拿社区宣传价格替代订单。若4核8GB一年活动总价低于普通三个月630元，且没有捆绑、确认长期开发，可优先考虑一年；630元是比较阈值，不是活动报价。若无合适活动，先买一个月验证，暂不以刊例锁三年。

## 不同方案的用途

| 方案 | 建议用途 | 当前判断 |
|---|---|---|
| 轻量4核8GB | 网页/API、缓存、受控的当前分析队列 | 首选起步；先只允许运行一个重任务，计算进程暂限制为2，给API留余量，再实测调节 |
| 轻量4核4GB活动机 | 廉价开发机或纯网页/API | 可用，但当前查询、夜间批量、研究实验不要同时跑；不是首选一体配置 |
| 锐驰4核8GB | 流量较大或突发网络需求 | 不因200Mbps而认定CPU更强；大陆公开刊例230元/月 |
| 香港轻量4核8GB | 没有备案时的公开测试备选 | 锐驰刊例280元/月；大陆跨境体验需实测，不能直接认定优于大陆部署 |
| CVM标准型8核16GB、按量 | 独立批量研究、并发计算压测 | 先选SA5/S8或同预算可选新代实例实测，再决定长期规格；总价需包含磁盘和网络 |

套餐价格来自[官方价格总览](https://cloud.tencent.com/document/product/1207/73452/)。轻量CPU型号无法指定，官方定位中低负载；没有核实到固定的“持续满载N分钟必限速”规则，不作该断言。锐驰带宽是峰值，不是保证指标，也不会自动提高LPPL拟合性能。[官方FAQ](https://cloud.tencent.com/document/product/1207/44569/)、[实例套餐](https://cloud.tencent.com/document/product/1207/44755)

CVM使用[实例规格](https://cloud.tencent.com/document/product/213/11518)与[价格计算器](https://buy.cloud.tencent.com/pricing/cvm)确认具体代次、地域和总费用。当前没有可核实的账号订单价，不能声称某CVM系列已经胜过轻量。按量实例关机不一定免计算费用，需要符合并选用对应计费模式；磁盘等资源仍可能收费。[关机计费说明](https://cloud.tencent.com/document/product/213/19918)

## 无域名、无备案时如何安排

购买大陆机器可先做私有开发测试，公众网站上线另行办理域名与备案。腾讯云备案资源要求实际包月购买至少3个月（含续费），备案期间剩余至少1个月；按量和试用资源不能直接满足该要求。若准备马上备案，购买时长应覆盖要求；主体及研究/收费业务范围另行确定。[官方备案说明](https://cloud.tencent.com/document/product/243/73180)

香港不要求ICP备案，但腾讯云同时提示大陆与港澳台等地域的跨境访问可能出现延迟和丢包；这不是当前大陆用户体验的保证。[官方价格与网络说明](https://cloud.tencent.com/document/product/1207/73452/)

## 买完后仍需实施的迁移

PR #50 改善了查询链路，但科学计算目前仍由GitHub Actions执行，云服务器购买后不会自动接管。迁移需要独立完成：持久任务队列、Python计算进程、只读行情/结果API、任务去重与额度、定时更新、日志监控及备份。先用同一固定输入测冷/热缓存和两档并发，再决定迁移和扩容。

初期不必为本模型购买GPU、云桌面、HAI、Kubernetes或托管数据库。模型服务CPU与网页应有资源限制，104周历史和研究实验排在低优先级队列。更换服务器改善访问与排队能力，不能当作预测准确率改善。

## 下单前逐项核对

- 地域、核数、8GB内存、Linux系统镜像及磁盘容量。
- 首期总额、时长、优惠适用资格、续费价和套餐流量规则。
- 是否附带不需要的收费产品、是否开启自动续费。
- 若现在就要备案，购买时长及主体是否满足要求。
- 不通过聊天传递控制台密码、SSH私钥或云API密钥。
