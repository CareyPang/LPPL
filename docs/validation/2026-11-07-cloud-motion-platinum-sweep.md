# 首页云层与白金光带修复

日期：2026-11-07。范围仅为 PR #50 的首页与独立演示站；未改变模型、评价器、研究结果、正式 Pages 或生产 Worker。

## 需求与实现

- VERIFIED：查回用户原话及最终独立版后，首屏只保留“进入工作站”。删除旧太阳 SVG、“下潜了解”（原“开始下潜”的同一入口）及对应事件绑定；“观察价格结构，研究市场临界性。”原本已不在当前页面。
- VERIFIED：按钮采用最终独立版的暖象牙配色与斜向白金光带，4.8 秒自动循环、首次延迟 0.8 秒，光带位于文字下方。右上普通深海导航不变。“启于青萍之末，满于狂澜之巅。”保留。
- VERIFIED（代码/调度）：云由 WebGL 噪声实时绘制，原来每秒只漂移源画面宽度约 0.083%，1280px 源画面约 1px/s；页面静止时仍排帧，不是定时器停止。原 Canvas 回退速度单位也未与 WebGL 对齐。
- VERIFIED（实现）：现在云噪声以约每秒 0.45%–0.6% 源画面宽度分层右移，并缓慢形变；太阳、天空渐变、海平线固定。Canvas 方向和速度对应；连续时钟避免每小时重置云场。
- VERIFIED：保留逐来源天空遮罩、原海报隔离、海水视频、滚动下潜、文字变色与错开显示。页面动效关闭或系统要求减少动效时停止装饰动画。

## 本地验收

- VERIFIED：前端 Node 检查 126/126 通过。新增检查覆盖静止页面继续绘制、关闭动效不排帧、Canvas 五秒位移和太阳固定、跨小时连续性。已有逐来源天空遮罩与视频/文字切换检查通过。
- VERIFIED：独立只读复核无阻断问题。光带 CSS 与原最终独立版对应段一致；删除按钮后无遗留 DOM 事件空引用。
- VERIFIED（浏览器）：1280×720 实际画面在两个观察时刻云形与位置改变，太阳位置固定；截图见到斜向光带，页面无控制台警告或错误。滚动至约 504px，水下视频与第一段白字可见，未同时叠加首屏文字。
- VERIFIED（浏览器）：实际 390×844 视口，文档宽与可见内容宽均为 375px，无横向溢出；主按钮 140×50px，首屏文字和两个入口排布正常。关闭动效后为 home-static，光带 animation-name 为 none。

NOT_INSPECTED：低端真机、所有浏览器及所有素材帧逐帧验收；Canvas 实机回退仅有代码测试，未强制浏览器禁用 WebGL。云速是画面设计参数，不是模型信息。
