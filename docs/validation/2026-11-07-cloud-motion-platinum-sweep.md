## 需求与实现

- VERIFIED：查回用户原话及最终独立版后，首屏只保留“进入工作站”。删除旧太阳 SVG、“下潜了解”（原“开始下潜”的同一入口）及对应事件绑定；“观察价格结构，研究市场临界性。”原本已不在当前页面。
- VERIFIED：按钮采用最终独立版的暖象牙配色与斜向白金光带，4.8 秒自动循环、首次延迟 0.8 秒，光带位于文字下方。右上普通深海导航不变。“启于青萍之末，满于狂澜之巅。”保留。
- VERIFIED（代码/调度）：云由 WebGL 噪声实时绘制，原来每秒只漂移源画面宽度约 0.083%，1280px 源画面约 1px/s；页面静止时仍排帧，不是定时器停止。原 Canvas 回退速度单位也未与 WebGL 对齐。
- VERIFIED（实现）：现在云噪声以约每秒 0.45%–0.6% 源画面宽度分层右移，并缓慢形变；太阳、天空渐变、海平线固定。Canvas 方向和速度对应；连续时钟避免每小时重置云场。
- VERIFIED：保留逐来源天空遮罩、原海报隔离、海水视频、滚动下潜、文字变色与错开显示。页面动效关闭或系统要求减少动效时停止装饰动画。
