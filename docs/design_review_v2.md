# 临界点 2.0 整体设计复盘与 v2 架构（2026-10-24）

> 目的：站在总规划师角度，复盘阶段 0–4 已经得到的证据，指出原设计里被证据推翻或暴露缺口的假设，给出优化后的整体架构。本文不改动已冻结的预登记 v1.1 规则；凡需要改动的，都列为 v1.2 草案条款（第 5 节），在看最终测试段结果之前登记。

## 1. 产品目标回看
用户输入 A 股代码或指数，得到白话结论：什么时候见顶、顶部区间、怎么分批逃顶；泡沫破裂后跌到哪、什么时候抄底；二波能涨到哪、何时退出。

这 6 个问题对应 4 类输出：
| 输出 | 类型 | 目前研究层的对应物 | 缺口 |
|---|---|---|---|
| 见顶风险 | 概率 | Y_top(t)：未来 20 日内出现合格顶的概率（阶段 4 主目标） | 无 |
| 顶部区间 | 日期分布 | 多窗口 LPPLS 的 t_c 聚类（已存每个窗口的 t_c，未做成输出） | **未定义评分与校准** |
| 分批逃顶 / 抄底 / 二波退出 | 决策规则 | 无 | **完全缺失** |
| 跌到哪 / 涨到哪 | 价位区间 | 旧原型"支撑井"、反泡沫拟合；研究层未登记 | 未登记 |

结论：研究层现在只覆盖第一行。这是整体设计最大的缺口，不是某个模型的问题。

## 2. 阶段 0–4 的证据复盘
### 2.1 被证据支持的设计
- **PIT 数据 + 当期成分股**：577 只历史成分股，28 只退市/长停股靠腾讯补齐；后复权自算，无负价格。幸存者偏差已被结构性排除。
- **C 定位 + B 过滤的顶部标签**：事件率被钉在 5–10%；共识门槛 30%/70% 对事件数影响 ±10–30%，说明顶部位置对参数不敏感；开发段 74+1389 个事件段，统计效力门槛（30）轻松通过。
- **"单窗口报警不能当信号"**（阶段 3b）：纯幂律序列让原型三套规则误报 20–37%；这直接支持多窗口比例 + 校准概率的做法。
- **冻结优化器 tcgrid_lm**：合成数据 96% 全局极小；网格阶段批量 SVD 后速度翻倍且结果逐项相同。

### 2.2 被证据推翻或削弱的假设
| 原假设 | 证据 | 影响 |
|---|---|---|
| "高波动 → 快见顶"，波动率是最基本的有效特征 | R1 开发段 CPCV Brier 0.0654 **差于**基率 0.0613；原因是波动率水平跨时间块漂移（2007/2015 vs 其他年份） | 任何未做跨时期标准化的特征都有同样风险；阶梯里应允许"按标的滚动标准化"的特征版本（见 §4.2） |
| GSADF 爆炸性检验能捕捉 A 股顶部 | R2 ΔBrier −0.0007，90% 区间含 0 | 单靠爆炸性不够；它可能作为 LPPLS 的前置门槛更有用 |
| 临界慢化/统计物理特征是"锦上添花" | R7 是目前唯一通过的级别（ΔBrier −0.0023，上界 −0.0001） | 效应很弱但方向明确；60 日窗口优于 120/250 |
| LPPLS 类候选可以逐日全样本计算 | 单窗口 0.13–0.3 s，逐日需 1.3 亿次拟合 | 已改 v1.1 稀疏时点；**生产环境也必须按增量设计** |
| 文献版 LIT-DS 条件 1 是严格但可用的对照 | 3% 噪声下真泡沫零命中 | 条件 2 必须同时进阶梯（已在网格） |
| 剖面似然区间可直接用 | 未校正覆盖率 76%（名义 90%） | 阶段 4 用块 bootstrap；MPL 校正待做 |

### 2.3 还没有被检验的关键假设（风险最高）
1. **LPPLS 多窗口置信度对 R7 有增量**——这是整个产品的核心卖点，尚无 A 股样本外证据。扫描完成后第一时间检验。
2. **t_c 聚类能给出有用的顶部区间**——合成数据上 t_c 距末端 >60 日时误差中位 28 日、P90 >85 日；真实数据只会更差。顶部区间很可能只在"临近"时才可用。
3. **概率能转化为少跌的钱**——没有决策层回测，无法回答。

## 3. 原设计的结构性问题
1. **目标层缺失**：Brier 是中间评分，不是产品价值。没有"分批规则 + A 股成本"的回测，最终就算 Brier 胜出也不知道能不能用。
2. **顶部区间无评分**：t_c 区间的"命中率"在预登记里是辅助评分，但没有定义怎么从 126 个窗口的 t_c 聚合成一个区间、怎么校准。
3. **二元标签浪费信息**：同步算出的连续标签 dd_ahead（未来 60 日最大回撤）还没有用；它的统计效力远高于二元标签。
4. **算力无门控**：阶梯是顺序的，但计算最贵的候选（Trust：每时点 1.26 万次拟合）证据最弱。
5. **底部引擎与顶部引擎串行**：基础设施（标签器、特征库、CPCV、评分）已通用，底部的设计可以并行。
6. **前端表达预设了"日期"**：产品目标里的"什么时候见顶"若被做成一个日期，会与研究结论（只能给概率和区间）冲突。

## 4. v2 整体架构
```
数据层(PIT)  →  特征库(逐日 + 稀疏 LPPLS 扫描)  →  顶部概率模型(阶梯保留链)
                                                 →  顶部区间模型(t_c 聚类 + 校准)
                                                 →  底部引擎(三重障碍 + 共振 + 反泡沫候选)
                                                 →  决策层(仓位规则 + A 股成本回测)
                                                 →  服务层(FastAPI：夜间批处理 + 按需拟合)
                                                 →  APP(Capacitor：概率/区间/分批表达)
```
### 4.1 研究层（保持预登记 v1.1）
- 阶梯继续：R3/R4/R5 在稀疏时点上与 R7 配对比较（`research.eval.ladder_lppls`）。
- **算力门**：指数扫描完成后先只用指数 + 已完成个股跑一次 R3/R4；若最优 LPPLS 候选的 ΔBrier 90% 区间含 0 且点估计 > −0.001，则个股扫描只补到 2010 快照的开发段（不跑校准/测试段个股），Trust 不做。门槛写进 v1.2。
- **特征的跨期标准化版本**：对每个特征增加"按标的过去 5 年滚动 z 分数"版本（PIT），作为同一级的配置之一，不新增级别。

### 4.2 顶部区间模型（新增，v1.2 登记）
- 输入：某时点所有合格窗口（按保留下来的过滤规则）的 t_c。
- 输出：t_c 的加权经验分布（权重 = 窗口合格数或 1），报告中位数与 10–90% 分位区间。
- 评分：只在 Y_top=1 的事件上评。区间命中率（真实顶是否落在 10–90% 区间内，目标 ≈80%）、区间宽度中位数、提前量中位数。基线：固定"未来 1–20 日"均匀区间。
- 校准：校准段上做保形（conformal）调整——按校准段事件的经验覆盖率缩放区间宽度，使命中率达到名义值。最终测试段只跑一次。
- 预先承认：若命中率不能以区间不含 0 的幅度胜过均匀基线，则产品里不显示日期区间，只显示风险等级。

### 4.3 决策层（新增，v1.2 登记）
- 规则族（最多 6 个配置，网格固定）：概率阈值 (p₁, p₂) ∈ {(0.15,0.30), (0.20,0.40), (0.25,0.50)} × 退出速度（一次减到 1/3 或分两步 2/3→1/3）。概率来自校准段 Platt 校准后的保留链模型。
- 成本：佣金万 2.5 双边、印花税千 1 卖出、滑点 0.1%、T+1、涨跌停日不能成交（按次日开盘处理）。
- 基线：买入持有；波动率目标仓位（目标年化 20%）；每月末随机减仓（安慰剂）。
- 评分：事件后 60 日最大回撤的减少量（主）、年化收益、换手、Calmar；用块 bootstrap 给区间。
- 预先承认：若主评分的区间不含 0 的改善不存在，产品只展示风险等级，不给仓位建议。

### 4.4 连续次要目标（新增，v1.2 登记）
- 目标：dd_ahead = 未来 60 日最大回撤（已在标签文件中）。
- 模型：同一阶梯特征集的分位数回归（τ = 0.9），评分 pinball loss，基线为训练段无条件 90% 分位。
- 用途：提高统计效力、为"跌到哪"提供第一版答案；**不**替代主目标，不参与淘汰决策。

### 4.5 底部引擎（阶段 5，可先设计）
- 标签：三重障碍（上障碍 +X%、下障碍 −Y%、时间 T 日）定义"有效底"；X、Y 用与顶部对称的 PIT 分位数法，不拍数字。
- 候选（固定名单）：B0 基率；B1 回撤深度/持续时间；B2 Yan 等 2012 的负泡沫（−ln P 的 LPPLS）反弹信号；B3 原型"反泡沫结构"；B4 统计物理（与 R7 同一特征集）；B5 支撑井密度（旧原型的 KDE 思路，PIT 化）。
- 评分与淘汰：与顶部同一套（Brier、CPCV、块 bootstrap）。
- "二波能涨到哪"：先作为连续次要目标（未来 120 日最大涨幅的分位数回归），不做二元。

### 4.6 服务层与 APP
- 夜间批处理：7 个指数 ×126 窗口 ≈ 2 分钟；逐日特征增量更新；写特征库与概率表。
- 按需：个股 26 窗口 ≈ 6 秒，带缓存；LPPLS 扫描结果按 (标的, 日期) 落盘，天然可审计。
- FastAPI 只读表 + 按需拟合；APP 不做本地计算。
- 表达：三档风险等级 + 概率条 + （若通过 4.2）日期区间 + （若通过 4.3）分批规则；每一条结论旁边放"基于 N 个样本外事件，命中率 X%"。
