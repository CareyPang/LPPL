## 4. 通过/失败判据（事先登记；用于校准段"是否可进入最终测试"与最终测试"证据等级"）
对每个进入模块，在相应段上同时满足以下三条记"通过"：
- (i) 概率模块：ΔBrier(模块 − BASE) 块 bootstrap 90% 区间上界 < 0；
- (ii) 报警模块（LPPLS 置信度）：≥4/6 指数 A1 循环平移 p ≤ 0.05 **且** A2 ≥ 0.5（H=120）；
- (iii) 稳健性：留出任一指数 / 任一年后 (i) 或 (ii) 不翻转。
结果处理：通过 → badge 升级（cal → test）；任一不满足 → badge 固定为"未通过（开发段）"，产品只保留描述性显示，不得改评分或换标签重讲。最终测试段只跑一次，2026 年案例不入。
