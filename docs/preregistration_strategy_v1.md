# 策略回测 v1 预登记

规则与参数网格于 2026-11-19 登记，先于策略代码和首轮回测结果。计算阶段只读取本地数据与缓存；本次复算按审阅要求限速刷新四指数行情后离线计算。

## 数据与时间段

- 标的：上证指数 `sh000001`、沪深300 `sh000300`、中证1000 `sh000852`、科创50 `sh000688`。科创50从本地价格历史的首个可用日期开始。
- 按审阅授权，四指数 OHLC 使用 `research/data/sources.py` 的 AkShare CSIndex 来源限速更新至 `2026-11-18`；回测仅读取下载后的本地 Parquet，并排除 `2026-11-19` 盘中行。
- R-TR1 开发段：上证指数、沪深300和科创50为 `2014-01-01` 至 `2022-12-31`；中证1000从 `2014-10-17` 起至 `2022-12-31`。检验段为 `2023-01-01` 至本地价格历史的最新可用日期（本次行情截至 `2026-11-18`）。不设校准段。
- R-LC1 使用 `web/mock/data/<sym>_history.json` 的 `frames`。每个标的检验段截至其历史文件最后一帧：上证指数、沪深300、科创50均为 `2025-08-25`。中证1000没有对应 history 文件，因此跳过该标的的 R-LC1，并在输出 `rules` 中说明原因。
- 每日 n_on 历史使用 `research/data/top_risk.py` 的同一组规则函数，输入为已有本地历史缓存；融资历史按 `DIM_DATE < asof` 过滤。集中度为前100占比五日均值达到 30%；融资余额为 252 日分位达到 80%；指数位置为 252 日分位达到 80% 且较 250 日低点上涨达到 15%。n_on 是这三项触发数；宽度回落仅为辅助项，不计入 n_on。
- 信号质量标签只依据价格，不读取 `top_risk_episodes.json` 的时段或 verdict。对可判定日 d，检查其后 120 个交易日的收盘价：最高收盘不超过 `close_d × 1.05`，且最低收盘不高于 `close_d × 0.90`，则 d 为顶部日。可用价格序列最后 120 个交易日没有完整前瞻窗口，不计入样本。顶部日之间相隔不超过 20 个交易日的合并为一个顶部区间。

## 交易执行与指标

- 收盘时产生信号，最早在下一交易日开盘成交；全仓或空仓，现金收益为零。所有标的均执行 T+1。
- 若设置涨跌停比例，买入开盘价达到 `prev_close × (1 + limit_pct) − 0.001` 时不能成交；卖出开盘价达到 `prev_close × (1 − limit_pct) + 0.001` 时不能成交。未成交订单顺延至下一开盘。指数的 `limit_pct` 为 `None`。
- 每边佣金 2.5 bp、滑点 5 bp；卖出另收 5 bp 印花税。
- 按段报告交易数、胜率、总收益、买入持有收益、CAGR、最大回撤、买入持有最大回撤、profit factor、每笔均值、平均持有日、exposure、turnover，以及 precision、recall、baseline、n_signals。Precision 为可判定的出场信号日中落在顶部日的比例；baseline 为可判定样本日中顶部日的比例；recall 为与该段重叠且至少含一个可判定出场信号的顶部区间比例。不可判定尾部的出场信号不计入 n_signals 或 precision 分母。比例字段使用小数。

## 预登记规则

### R-TR1：顶部风险区退出

- 初始持有指数；收盘时若 `n_on >= K` 则发出退出信号。空仓时，仅当 `n_on == 0` 连续 `M` 个交易日后发出重新进入信号。
- 开发段唯一参数网格为 `K ∈ {2, 3}`、`M ∈ {5, 20}`，共四个变体。只用开发段按 Calmar（`CAGR / |最大回撤|`）选取；平局时选交易数较少者。选定后，检验段仅运行一次该变体，不在检验段调参。
- 开发段证据为 `dev_only`。检验段为描述性结果，注明：“规则阈值来自用户经验与 2014–2026 全样本时段表，检验段不是严格样本外”。

### R-LC1：LPPLS 周度聚类区间退出

- 日期 `t` 使用 `asof <= t` 的最近一帧。`asof` 当天收盘后才可得知该帧信号，最早下一交易日开盘成交。
- 使用 `6-12m` 尺度，即回测页面默认选中的尺度。最近一帧 `clusters["6-12m"]` 中只要存在顶部泡沫簇且其 `q80_date >= t`，收盘时发出退出信号；连续 20 个交易日均不存在该类簇时，发出重新进入信号。按已登记规则使用区间结束日判断，不要求区间开始日早于 `t`。
- 历史字段不单独存储 `sign` 或 `kind`。依据 `docs/od_field_mapping.md`，`frames[].clusters[scale][]` 与 `top.scale_clusters[scale][]` 语义相同；导出代码先用 `r.box` 筛选拟合，而该规则要求 `B < 0`。因此这些 frame cluster 是顶部泡沫簇；负泡沫另列为 `negative_bubble`，不纳入本规则。
- 不调参。证据为 `descriptive`，展示说明：“事后重算，不是样本外，周度更新”。
