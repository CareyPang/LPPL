# 海水首页原页艺术指导：把视线带到时间窗口

日期：2026-11-06。对象：现有 `frontend/home.html` 及其海水媒体、场景控制与可读性样式。阶段：**方案，尚未实施**。本轮只新增本文，不修改生产前端，不安装依赖，不生成新媒体，不部署。本轮用户授权的标签与评分研究由独立任务处理，不能据此扩大为首页改站授权。

本文收敛为一个可实施方向：**沿用真实海水画面，以海平线组织空间，以观察框连接查股与分析，用剪辑和排版形成节奏。** 不再交付与原页无关的第三套概念布局。当前代码事实标为 **VERIFIED（源码）**；计划、时长和验收阈值均是 **待实现/待测目标**。

## 1. 对上一轮概念的纠正

用户指出“没有用 home.html”“只是 demo”“没有 MotionSites/Awwwards 的特点”，这个问题成立于交付方式：上一轮独立概念展示了布局和色彩选择，没有在原页海面、入水、水下素材上完成镜头、文字、操作和页面转场的共同编排。它不能被称为海水首页改版，也不能证明手机和真实页面可用。

上一轮最缺的是四件事：

1. **真实场景。** 没有把现有的日落海平线、近景浪面、入水瞬间和水下循环放进同一个可审查原页。抽象背景不能替代本项目已有的影像资产。
2. **镜头和剪辑。** 没有规定海平线在哪一帧消失、标题在哪个位置让位、停下滚动如何接回循环、倒滚如何恢复，漂亮卡片之间缺少空间连续性。
3. **排版节奏。** 没有让大字、留白、短句和实际操作共享构图；所有信息只是依次出现，缺少停顿、移交和关键画面。
4. **操作联动。** 输入代码与进入分析仍像跳到另一套网站；搜索框、资产身份、图表和海平线没有对应关系。

用户要的视觉水平在这里转化为可验收的特征：满幅且有明确主体的真实场景、独特的大字构图、可逆的滚动分镜、少而准确的形变、从品牌空间走入产品空间的连续操作。不能以“加粒子、加渐变、加悬浮卡片”代替这些工作。本文不宣称复刻任何参考网站，也不引用未运行或未取得使用权的模板。

### 一个需要先解耦的现有关系

**VERIFIED（源码）：**`home.html`约637行把首个指数的`Combo p0.1`转换成`s0`和`TINT`，约851行传入shader的`uStr`，约892行影响粒子速度。这样会让装饰海况受模型值影响，容易被理解成“海越急，风险越高”。

后续授权实施时，应将品牌海面、色温、粒子和声音从市场值中解耦；它们只依赖用户交互、场景进度与设备能力。真实数据在带日期、证据和单位的明确组件里表达。即使以后模型通过验证，也不能默默用背景海况编码风险。

## 3. 唯一视觉叙事：从海平线进入观察框

海平线负责建立空间；观察框负责把注意力引向一只股票和它的时间轴。进入研究页面时，画面从宽阔海面收束到一个可读的观察界面。**真实价格线从实际数据出现，绝不由海浪轮廓“变成”某只股票的走势。** 形变发生在框、边界、标题位置和背景，数据几何保持真实。

三个记忆点必须在同一原页连续出现：

- **日落海面上的大字与一个可操作入口。** 保留“浪成于 / 微澜之间”，采用左对齐错行构图；右侧日落留出空间，不再放一张悬空的假预测卡。标题下面放一句具体用途和查询表单，首帧就可输入。
- **水线经过观察框，文字完成移交。** 用户选择探索时，背景镜头下潜；内容框始终稳定。大标题离开，资产/时间尺度的短句在同一对齐线上接力出现。水线只擦过装饰性边缘，不遮住正在输入的文字。
- **水下的两条时间轨道。** 稀疏排版讲清短期局部高点与阶段性高点的区别；用户选股时，观察框的边界延续为分析页的资产栏和时间轴，而不是再来一屏开场。

首屏推荐短文案：

> 浪成于微澜之间。
> 研究短期与阶段性高点可能出现的时间窗口。
> 研究版 · 识别能力仍在验证。

主按钮“查看股票”；次动作“下潜了解方法”。输入提示先准确写“六位A股代码”，因为当前代码只支持代码输入。名称搜索需要数据适配层提供正式候选、交易所和名称，具备后才能改为“代码或名称”，不能让视觉承诺领先接口能力。

### 波纹和潮汐如何使用

“短期如局部波纹，阶段如更长的潮汐”只是一种教学类比：短期看局部起伏，阶段看更长的结构。两条线使用固定、公开标为“尺度示意”的非行情样例；在切换讲解时改变横向展开长度和注释密度，不把波峰位置当作预测日期。

严格区分：模型回看窗口长度、未来预测距离、事后顶部层级。不能因为某次拟合用了长窗口，就把图形自动放入“阶段性顶部”轨道。两类高点可能重合，也可能暂不能区分；“尺度待判”应有独立位置。未来实际区间只能由已审定的后端结果提供。

“提前至少5个交易日、窗口宽度不超过10个交易日”是待验证目标；不得印成首页能力徽章。“顶部区间”不附带“随后下跌10%”或其他跌幅承诺。价格与抄底研究另设后续入口。

## 4. 两条路径：直接查股与可选探索

两条路径共用首屏和真实资产。任何人都能直接查询，不需要先滚动下潜、解锁章节或等视频加载。

### A. 直接查股：提交即进入分析

第一阶段先使用正常的`stock.html?code=XXXXXX`导航，保留现有直达URL和返回行为；首页不预先自动提交模型计算。表单使用真实label、可见按钮和回车提交。前端初始化失败时，合法代码仍应能通过表单导航到个股页。

以下是后续渐进增强的视觉目标，不是本轮实现。时长是单次交互的上限意图，真实导航和数据请求不得等待动画结束。

| 提交后时间 | 视觉事件 | 业务与可访问性事件 |
|---|---|---|
| 0ms | 输入边界给一次明确按下反馈；保留用户所选代码 | 立即校验并开始正常导航。非法输入留在原位报错，不播放“进入成功”动画 |
| 0–120ms | 若浏览器允许连续页面转场，源页面观察框的外边界开始收束 | 不等待`animationend`、媒体ready或字体ready；目标页面一旦可用即显示 |
| 120–260ms | 代码与框边界在目标页资产栏位置接续；海平线作为装饰直线淡出 | 目标页建立当前资产身份，独立请求行情、已有结果和任务状态；没有名称时保留代码 |
| 260–360ms | 背景海面淡出，分析面板成为实色；图表按真实返回数据显示 | 当前没有数据就显示清楚的加载/缓存/失败状态；不填假走势、假区间或完成百分比 |
| 完成或无转场能力 | 页面直接稳定在分析布局 | 键盘焦点进入资产标题或明确状态位置；不要把用户困在不可点击的截图层 |

跨页连续效果只作为渐进增强：先核对浏览器能力、同源页面约束及生命周期，再实现共享元素；不可为此把原多页站强行改成新SPA。能力不支持、返回缓存恢复、媒体失败、减少动效时直接切换页面。**功能一致、空间关系大致连续即可，不能以黑屏等待交换完整动画。**

搜索框内的代码可以延续成资产栏代码；预测窗口不能预先参与形变，因为提交时它可能根本不存在。结果返回较早也不压到海水层下等待展示，返回较晚则保留可用行情。

使用浏览器原生滚动。`p`沿用入水镜头的归一化进度0–1，不表示预测概率或计算完成度。下面的帧号按241帧镜头的0起始编号近似换算，最终以视频实际解码画面审查为准。建议将桌面探索段从420svh试调到约220–260svh，390px约140–180svh；这些是待测起点，不是必须占满的时长。

| 分镜 | p / 近似帧 | 镜头与构图 | 字体与交互节拍 |
|---|---|---|---|
| 01 海面停留 | 0 / 0 | 开场先poster，再接实际海面循环；太阳留在右侧，保留水平线 | 标题、用途和查询首帧完整可读。仅装饰线允许100–180ms轻入场；不做逐字模糊解锁 |
| 02 视线靠近 | .12 / 29 | 使用原入水素材缓慢接近水面，不添加与素材运动相反的鼠标视差 | 品牌大字开始向上移约16–24px，查询框留在稳定阅读层；小注释出现“从价格起伏，观察结构变化” |
| 03 水线前停顿 | .26 / 62 | 接近现有`.30`水线阈值；构图留出约四分之一屏的静默区域 | 两行大字让位给一句短问题“局部起伏，还是阶段转折？”文字只移动/淡入，不挤压表单 |
| 04 入水 | .30–.42 / 72–101 | 完整使用现有入水镜头，保持天空与实测海平线同步；水线消失后不重绘天空 | 仅装饰性细线随镜头收束为观察框上边界。正在聚焦的输入不改变几何位置、不被遮罩切掉 |
| 05 水下建立 | .42–.58 / 101–139 | 接入水下源，镜头稳定后才展开下一组文字；不叠加假海底物体 | 标题移交到“同一段上涨，可以有不同层级的高点”。出现两条“尺度示意”轨道，先文字、后固定样例 |
| 06 两种时间 | .58–.78 / 139–187 | 保持画面宁静，素材提供微动；内容有一处主视觉，不同时漂浮多张卡片 | 用户切换“短期局部 / 阶段性 / 尺度待判”，只改变讲解和示意长度。手机纵向两行，不能用横向拖动绑架页面滚动 |
| 07 回到研究 | .78–1 / 187–240 | 与现有under/deep同源循环平滑接续；逐渐加强阅读背景，结束镜头展示 | 出现“先记录判断，再检查结果”与方法/记录入口。仅真实已存在的记录可链接；缺数据直接写“记录尚未建立” |

滚动停下时继续沿用当前`IDLE_MS=300`后的循环接续思想，先确认该场景真实帧已解码再淡入；回滚按同一映射恢复，不重新播放固定开场。若seek落后，保留最近完整帧，继续响应页面输入，不能排队补播所有中间帧。

首屏查询可在离开首屏后成为一个紧凑的“查股票”入口，但用户正在输入时不得把表单换父节点、复制带相同ID的可编辑控件或丢失焦点。先用同一表单的稳定布局实现；缩略入口仅在未聚焦且原表单离屏时出现。手机软键盘打开时停止场景几何重排，以免地址栏/键盘高度变化反复改变进度。

## 5. 排版、颜色、声音必须协同

### 排版不靠卡片堆满画面

- 桌面采用左侧约5列的标题/查询区，右侧保留海面和太阳；主内容最大宽度约560–640px。具体宽度根据原视频太阳、浪峰和标题截图复核。
- 大标题保留中文衬线，建议64–96px随视口调整；用途正文16–18px；输入不低于16px。数字、代码和日期使用等宽或表格数字，研究正文使用清楚的中文无衬线。
- 首屏以标题、用途、输入三个层级形成构图，不再同时放引语、预测示意卡、多个宣传数字。原蝴蝶效应引语可移到方法段次级说明，不能挤占查询。
- 字幕按分镜移交，每一时刻只有一句主叙述。关键文字保持原生DOM，不画进视频或Canvas，不用光晕掩盖低对比。
- `home-readability.css`的局部阅读遮罩随内容范围调整，不用整屏黑幕把海面压暗。输入区采用稳定实色或接近实色底，明确焦点边框。

### 四套语义不要混色

| 用途 | 颜色/形状方向 | 约束 |
|---|---|---|
| 海洋品牌 | 深海蓝、暖白、少量日落金 | 只在背景、标题与品牌细节使用；不映射模型强弱 |
| 未复权实际日线 | 中性浅灰/白收盘线，或A股默认涨红跌绿K线 | 图例标“未复权·已收盘日线”；如采用K线，同时保留涨跌文字/符号 |
| 后复权研究历史 | 独立图层/图板中的蓝灰线与文字标注 | 不与未复权日线共用可混淆的价格轴；不能只靠颜色解释复权差异 |
| 未来时间窗口 | 蓝紫轮廓/淡填充，区分线型并标日期 | 不用涨跌红绿，不画成向下价格箭头；无可发布窗口时不画装饰区间 |

短期与阶段性可用不同线型、标签和轨道区分，不只靠颜色。网页“时间区间”不是概率云；不添加80%之类的标签，除非后端已提供且对应验证成立。

### 声音不承担业务信息

保留现有默认静音及环境声为程序合成的说明。若用户主动开声，入水可有一次克制的低通变化，返回海面按同一路径恢复；不因为获得信号、无信号或任务失败改变海浪音量，不做“警报式鲸鸣”。声音关闭后所有含义仍然完整。搜索和读数不需要每次按键发声。

## 6. 桌面、390px、低能力和减少动效的明确分级

| 级别 | 启动方式与视觉 | 保留的能力 | 禁止的退化 |
|---|---|---|---|
| 桌面标准 | poster先显示；选定desktop海面视频，探索后再加载入水/水下；现有质量器目标60fps | 完整可逆分镜、共享框转场（能力允许时）、键盘查询 | 不为等字体、解码或模型锁定输入；不预取全部回退帧 |
| 390px标准 | 使用mobile素材裁切；保留右侧太阳关系，标题40–52px、输入单列全宽；目标30fps | 首屏直接查股、原生滚动、简化的入水片段；轨道纵排 | 顶部不能像现在隐藏导航后一并丢掉个股入口；不能将桌面缩成密集小字 |
| 低性能/节省流量 | 用户选择静态或节省流量偏好时默认poster；其他设备先按现有质量器减效果与帧率，持续不达标再建议静态 | 相同文字、查询、说明和真实数据；可自主恢复动画 | 不仅降模糊画布却继续高负载；不以重新加载页面为切换条件 |
| 减少动效 | 不创建视频；固定poster或章节静帧，无镜头推进、折射、视差和连续形变 | 完整普通文档顺序、表单、图例、状态与正常导航 | 不只减慢动画；内容不能仍然opacity为0；不得要求用户点播放才能看正文 |

补充实现要求：

- 当前`saveData`只使`MOB`成立、选择较小媒体，不等于静态模式；后续需把节省流量作为独立策略，而不是继续完整播放较小视频。
- 增加始终可找到的“动画·开/关”控制。当前`motion-resume`只在自动播放受阻时出现，不等于用户随时能暂停运动。声音开关与动画开关分开。
- 桌面/移动都先降低装饰工作；主内容、焦点、图表文字保持CSS分辨率。不要新增一套粒子层给现有主循环再加负担。
- 390px首屏以查股任务为先，深度计收为小型章节标记或隐藏装饰数字，不再占用正文右侧大块宽度；这里的“深度”是叙事位置，不是研究深度或风险等级。
- 页面不可见、进入分析页、用户关闭动画时，释放或暂停相应视频与动画工作。任务轮询与查询逻辑不依赖装饰循环。
- 200%缩放、320px窄屏、390px软键盘、横屏都必须另验。现存390px合成个股截图不能证明新首页通过。
