# 临界点 2.0 · 白话使用指南（指数顶部风险）

> 本页只讲"怎么看、怎么用"。每个数字旁的 **证据等级** 标签才决定它能不能信：
> 开发段 = 只在 2000–2018 历史里成立；校准段部分通过·不稳健 = 2019–2021 勉强有效但换一个指数就翻；无证据 / 描述性 = 只是把现状说清楚，不是预测。
> 当前（本轮三段验证后）**没有任何一项是"样本外稳健通过"的概率预测**。产品不显示"见顶概率"，这是故意的。

## 1. 第一张卡：泡沫状态
- **DS 置信度**：把最近 6–12 个月（或 12–24 个月）切成上百个起点不同的窗口，各自拟合泡沫模型，看多少比例通过形态过滤。比例越高，说明"超指数加速 + 越来越密的振荡"这种泡沫形态越不依赖于你从哪天开始算。
- 看哪一列：以 **6–12 月档 · STANDARD / END** 为主。1–3 月档只作参考（开发段无证据）。`box` 是本项目自己的宽松过滤，参考用。
- **无合格拟合 / 0%**：现在不是泡沫形态，不代表不会跌。日常绝大多数时间都是这个状态。

## 2. 阈值分级（开发段 2000–2018 规则，不是样本外验证结论）
| 6–12 月档置信度 | 状态 | 开发段里报警后 120 个交易日内见顶的比例（END 集） | 怎么做（规则，非预测） |
|---|---|---|---|
| < 5% | 低 | — | 正常 |
| 5–20% | 中 | 0.77（随机报警 0.24） | 关注，查估值分位与体制带 |
| ≥ 20% | 高 | 0.87 | 开始分批，例如先减 1/3 |
| ≥ 50% | 极高 | 1.00（样本少） | 再减 1/3；剩余仓位用止损规则 |
- **解除**：6–12 月与 12–24 月两档连续两期都 < 5%。
- 必须知道的局限：这些比例几乎全部来自 2001、2007、2015 三次泡沫；2019–2021 校准段里 END 集**没有**复现（1/7 指数显著），box 集勉强（4/7），三段没有一个过滤集始终最强。所以阈值只能当"进入逃顶区的提醒"，不能当精确信号。

## 3. 第二张卡：临界时间 t_c 情景
- t_c 是模型里"失稳的临界时间"，**不是峰值日**。原版（FCO）也只用它的 20–80% 分位区间，判定该区间内是否出现"体制改变"（崩盘，或转为高波动横盘）。
- 看法：同一尺度内把合格拟合按 t_c 聚成几个情景，各给 20–80% 和 2.5–97.5% 分位日期。多个情景并存 = 不同起点的拟合对"什么时候结束"没有共识，不要取平均。
- 开发段数据：连续报警段的第一天到真正的顶，中位约 106 个交易日（四分位 58–180）。即报警通常会持续 3–8 个月，顶多在置信度冲高之后 1–2 个月出现。

## 4. 泡沫大小 / 持续时间（描述性）
- 泡沫大小 = 从最佳起点 t1 到 t_c 处**模型预测价格**的幅度（原版口径），实际涨幅并列显示。模型值含外推，**不是目标价**；崩盘幅度通常只是泡沫大小的一部分。
- 起点没通过过滤时，这个数字只是参考，页面会灰显。

## 5. 结论表里其他字段
- **估值分位 / 上月体制带**：并列展示，不与 LPPLS 联合算分（原版没有联合规则，我们也不加）。
- **预计回落区 / 回落时间 / 二波**：无有效预测，只给历史无条件分位作参考。
- **底部**：负泡沫、反泡沫、底部概率链三段验证全部未通过，**不预测起涨时间**，只给描述性状态。"便宜"不等于"要涨"。
- **个股**：个股层面的 LPPLS 排名无预测信息；个股页只显示所属指数的风险。

## 6. 三段验证怎么读
- 开发段 2000–2018：所有规则在这里选出来，所以这里的好成绩**不能**当证据。
- 校准段 2019–2021：所有概率模型未通过；置信度报警只有 box 6–12 月名义通过且不稳健。
- 最终测试 2022–2025.08：只跑一次、只报告；结果见 `reports/final_test_2022_2025.md`。
- 2026 起：每日信号封存入 `forward_log/`，每季度按同一判据复盘。这是唯一会改变证据等级的途径。

## 7. 一句话用法
把它当"泡沫形态体温计"：6–12 月档 STANDARD/END 置信度冲上 20% 以上、t_c 分位窗落在未来几个月内、估值分位也高——这时按规则分批减仓；其余时间它说的是"现在不是泡沫形态"，而不是"安全"。
