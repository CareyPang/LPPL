# 宽度状态解释规则（breadth_state_v1）

用途：市场页「宽度与资金」面板给每个交易日一个状态和若干叠加标记，只描述当日市场，不是买卖信号。
状态和标记之后的涨跌尚未检验；要升级为结论须先登记再检验。

## 数据

- 通达信盘后包（沪深京 A 股），2021-08-13 至 2026-11-26 共 1280 个交易日，冻结在 `data/market/breadth_state_seed.csv`；
  之后由 `research/data/breadth.py` 每日续接。
- 阈值只看各指标自身的分布确定，没有参考之后的涨跌。

| 指标 | 5% | 25% | 50% | 75% | 95% |
|---|---|---|---|---|---|
| 上涨占比 | 0.115 | 0.287 | 0.459 | 0.661 | 0.842 |
| 量比（当日成交额 ÷ 前 20 日均值） | 0.770 | 0.883 | 0.978 | 1.090 | 1.298 |
| 跌停家数 | 2 | 8 | 15 | 32 | 99 |
| 站上 20 日线比例 | 0.126 | 0.279 | 0.447 | 0.627 | 0.858 |

## 每日状态（互斥，按顺序判定）

| 状态 | 条件 |
|---|---|
| 恐慌出清 | 上涨占比 ≤ 0.12，跌停 ≥ 100 家，量比 ≥ 1.0 |
| 恐慌出清 · 超卖新低 | 恐慌出清，且上证收盘为 60 日新低、站上 20 日线比例 ≤ 0.13 |
| 恐慌出清 · 高位首跌 | 恐慌出清，且上证收盘不是 60 日新低 |
| 放量普跌 | 上涨占比 ≤ 1/3，量比 ≥ 1.09 |
| 缩量普跌 | 上涨占比 ≤ 1/3，量比 ≤ 0.88 |
| 普跌 | 上涨占比 ≤ 1/3，其余 |
| 放量普涨 | 上涨占比 ≥ 0.75，量比 ≥ 1.09 |
| 缩量普涨 | 上涨占比 ≥ 2/3，量比 ≤ 0.88 |
| 普涨 | 上涨占比 ≥ 2/3，其余 |
| 涨跌分化 | 其余 |

恐慌出清的 19 个交易日里，超卖新低 7 天、高位首跌 9 天、两者都不是 3 天（收 60 日新低但不到极端超卖，仍显示“恐慌出清”）。
这一拆分是在看过 2021–2026 这 19 天之后的走势后才定的（事后归纳），所以这段数据不能用来检验它；
拆分只作状态描述，之后的涨跌要在 2014–2021 的数据上按事先登记的条件检验。

## 叠加标记

| 标记 | 条件 |
|---|---|
| 顶背离 | 上证收盘为 60 日新高，上涨占比 < 0.5，站上 20 日线比例比前 20 日最高值低 0.10 以上 |
| 底背离 | 上证收盘为 60 日新低，站上 20 日线比例比前 60 日最低值高 0.05 以上 |
| 极端超卖 | 站上 20 日线比例 ≤ 0.13 |
| 极端过热 | 站上 20 日线比例 ≥ 0.86 |

## 关于 TRIN

A 股成交额口径 TRIN 与上涨占比的相关系数为 0.73：上涨占比 ≤ 0.12 的 71 个交易日里 TRIN 全部低于 1（中位 0.38）。
普跌日 TRIN 低是常态，所以恐慌出清不按 TRIN 判定。
