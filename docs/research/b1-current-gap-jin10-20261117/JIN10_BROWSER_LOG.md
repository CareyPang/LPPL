## 2. 房贷：输入→结果→返回→切还款法

完整地址：[房贷计算器](https://topic17z2k407.jin10.com/app_pages/mortgage-calculator.html)。桌面呈现居中的手机宽界面，顶部“按揭购房／商转公”。使用页面自带演示默认值：房价300万元、首付90万元30%、公积金80万元年利率2.10%、商业130万元年利率3.05%、30年。

1. 等额本息→开始计算→`#result`：月供8513.09元，总利息96.5万元，购房总支出396.5万元，360期表。
2. 首期本金3808.93、利息4704.17；第二期本金3817.34、利息4695.75。
3. 修改条件→原参数保留；切等额本金→计算。
4. 首期10537.50，总利息84.9万元，总支出384.9万元。表内第1期本金5833.33/利息4704.17；第2期总10524.43/本金5833.33/利息4691.10；第3期总10511.37/本金5833.33/利息4678.03。

独立Decimal复算见规格；指定理论字段吻合。观察到分项分别四舍五入造成0.01元不守恒：3808.93+4704.17=8513.10；5833.33+4678.03=10511.36。记录为展示/舍入一致性问题，不能称贷款算法全部错误。没有将默认利率当作用户当前可用报价。

## 3. 汇率：每行选择自己的报价业务

登录前曾遇登录提示并关闭；用户自行登录后重新进入。约430px宽弹窗，自定义数字键盘。

1. 输入100 CNY，显示USD15.0451、EUR13.7067、JPY2405.81、HKD118.04，各币种附银行/业务标识。
2. 展开USD选择器，三个列组为“货币／汇率源／结售”；来源含工商、交易商报价、中行、建行等；业务含购汇、结汇、购钞、结钞。
3. 工商USD从购汇改结汇并确认，USD变14.9669，其他行不变。

观察证明按行选择和重算交互存在。主屏未见报价asof，未证明每行更新时间一致，未核对业务视角和买卖方向，数字不作为可交易汇率。LPPL需要每行显示来源/报价类型/单位基数/时点，并允许普通键盘和粘贴。

## 4. 单位与贵金属价格：常数不能含糊

单位工具类型含重量、容量、长度、速度、温度。重量输入1金衡盎司ozt→31.103477g；切温度时旧值清空，华氏输入32→0.00°C。仅验证这两个例子。

目录“国内外金银价格换算”进入后标题为“国内外黄金价格换算”。主屏所见1USD=6.671CNY、1HKD=0.8504847763CNY，XAU3878.69USD/ozt；未见具体报价时点。

输入测试值100USD/ozt，得到21.4478人民币/克、21447.76人民币/千克、943.8950港元/两。前两者独立复算一致；后一值反推每两37.429000245g，与香港金衡两37.429g相容。这是数值推断，不是读取金十源代码。不能把“两”默认解释为50g，也不能因目录写银就声称银价流程已测。

## 5. 黄金白银汇率价差：实际是汇率变化贡献

1. 页面明示公式：`美元金价×(人民币汇率B−人民币汇率A)/31.1034768`。
2. 使用所见参考值P=3877.57USD/ozt，A=6.6635（2026-11-16），B=6.6636（标“实时”但没有具体时刻）。点击计算→+0.0125元/克、+0.00%。
3. 点“场景1”→进入计算历史，看到本次2026-11-17一条记录。界面自动记录了这次计算；本地/账户/服务器存储方式未建立，不能声称完全无写入。
4. 返回→下拉黄金美元价格/白银美元价格；选白银出现场景2，P47.682，A=B6.6636，结果清空；未执行第二次计算。

绝对差独立复算0.012466677…吻合。百分比分母页面未明确；按A折算价计算约0.001500713%，显示两位可成为0.00%，该分母仅INFERRED。

该工具不是国内升贴水，也不是金银比，更不是预测汇率。LPPL用不同metric_id区分，固定美元价的FX贡献应明确假设；若同时改变价格/汇率，交叉项另算。手工情景不能写进模型forecast账本。

## 6. 时差：墙钟重解释与同一瞬间的区别

首次连接超时，点击重试后加载。默认美东2026-11-16 22:24:37→北京2026-11-17 11:24:37，晚13小时。打开日期选择器，能选择年/月/日/时/分/秒；取消，没有测试夏令时临界日期。

区域项可见美东/美西/美中、夏威夷、海湾/阿拉伯/伊朗、欧洲等。切伊朗后，左侧保留约22:25:14墙钟读数而标题换伊朗，北京变次日02:55:14，差4小时30。算术一致；行为是重新解释输入墙钟时刻，不是让同一UTC瞬间换显示时区。更多入口未全部操作。

LPPL应显式区分两种操作，尤其不能在事件回放中静默改变真实瞬间。IANA时区和版本、DST空缺/重叠时刻另需测试。纯本地换算不应被无关服务器超时锁住。
