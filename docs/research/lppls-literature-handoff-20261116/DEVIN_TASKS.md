## T01 — 统一拟合口径（先完成，未通过不得跑对照）

### 必须固定的语义

1. 新预测支线输入为正价格的 `log_price`；原价、对数价、复权价的类型/字段分开，不允许重复取log。FS 求解只搜索 `(tc,m,omega)`，四个线性参数用 QR/SVD/lstsq；是否沿用已实现的求解器由基线 manifest 记录。
2. **完整周期** `cycles_full=omega/(2*pi)*log((tc-t1)/(tc-t2)) >= 1.5`；`tc>t2`。阈值始终1.5，不在本轮扫描1.0/2.0/2.5选择赢家。
3. future-only 支线不调用 `abs(tc-t)`、不以 clamp 修补非正τ。`tc<=t2`明确拒绝；legacy v2 内部临界点保留在自己的诊断表，不能计提前命中。`ALLOW_INSIDE` 不得通过进程全局状态污染另一任务。
4. search_bounds 与 filter_bounds 分开存。先从选定基线实际代码提取 m/omega/damping/R²/未来horizon；除了明确登记的单位/未来域修正，T03–T05保持它们和求解器固定。不把历史论文常数当新最优值。
5. `lookback L`、未来拟合horizon、评价H和标签确认E分字段。拟合时钟可以沿用有效bar，但必须保存到真实交易日的映射；评价统一交易所session。停牌/缺失保留日历位置，不把缺失删除后计算“五日”。
6. 窗口与attempt分两级计数：每个计划窗口恰有一个汇总状态和attempt列表；每个seed/重试有独立attempt_id及成功/无效/数值失败/pending状态。结构过滤拒绝另记，不与优化失败混算。有限值、边界解、rank/条件数诊断各有字段。不得令窗口数等于attempt数，也不得用0参数/空数组冒充成功或因NaN比较漏过过滤。
7. 缓存键包括数据哈希、asof、窗口、时钟映射、域、单位、边界、solver、版本/seed契约。内部tc旧缓存不得直接作为future-only最优解；新约束下需要重拟合时另登记计算，不叫“仅重新过滤”。
