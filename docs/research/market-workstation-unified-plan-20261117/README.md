## 2. 不再反复决策的产品约束

1. **当前浅色、非海洋首页。** 保留旧演示资产，不自动恢复海洋主线；先保证搜索和继续研究可用，装饰动画不阻塞入口。
2. **顶部时间区间是核心。** 不用未来跌幅达到 10% 定义本项目此次成功。局部顶与阶段顶分别评价，重点保留全部成熟阶段顶作为漏报分母，未成熟标签单列。
3. **完整周期 1.5 研究基线不变。** 这次 UI 与信息整合不改优化器、过滤门槛、聚类算法或标签定义；需要研究改变时独立版本与对照。
4. **提前 5 日是评分切片，不是候选显示门槛。** 0–4 个交易日候选仍显示；已过去 tc 单独标识，不能算新的提前预报。结构支持占比、tc 日期区间、实际预警表现分开展示。
5. **新闻、宏观、技术指标、AI 与 LPPL 拟合分离。** 信息层变化不能暗中改拟合输入或生成概率。来源许可状态不清的接口不启用自动采集转供；预测市场仍需既定书面许可条件，启用后再设计约六小时刷新。
6. **行情、当前计算、历史任务独立。** 导航、资讯阅读和菜单预览只读缓存；打开资产不自动启动 104 周历史任务。
7. **保留旧结果与提醒账本。** 首次记录不可被修订覆盖；缺失证据留空并解释，不按回测 as-of 回填“首次发布”。
8. **不为界面改造强制重写框架或替换图表库。** 先基于现有统一数据入口和 Canvas 核验，确有问题再做受控技术对照。腾讯云接口兼容可在本地验证，不购买或部署资源。

### U01｜资产、时间、结果版本统一契约

**依赖：** U00。**交付：** schema、旧字段兼容映射和路由往返样例。

| 对象 | 至少包含 | 规则 |
|---|---|---|
| ResearchContext | asset_id、exchange、asset_type、mode、asof、result_id、selected_cluster、selected_event、display_resolution、visible_range、context_id | 裸代码和名称只是别名；新资产与新证据模式产生明确上下文 |
| Quote | quote_asof、source、adjustment、currency、calendar_version、data_hash、delay、status | 行情延迟、缓存 stale 和旧分析日期分别表示 |
| Fit/Cluster | analysis_asof、input_hash、model_version、fit_config_hash、filter_version、cluster_version、tc_unit、raw_tc、mapped_dates | 显示日/周、1M/6M 与模型拟合窗口分开；日历未知不猜日期 |
| Visibility | computed_at、available_at、audience_scope、availability_evidence_id、first_public_visible_at、rendered_at（可选） | 计算完成不等于可用，更不等于用户看见；public 字段只适用于真实公开可见的记录 |
| Evidence | event_time、published_at、fetched_at、source_version、revision_id、hash、permission_status | 日期可能不同；无法验证原始发布时间时不得推定当时可知 |

模式明确为 `current`、`historical_reconstruction`、`published_replay`，不能都叫 replay。`available_at` 是可被指定受众成功读取的时间，需保留验证证据；后端写入、页面渲染、真实用户阅读分别记账，不相互替代。时间统一存储 UTC，并保留交易所时区、交易日和来源原始时区。

**验收：** 同一结果切日/周和视野后输入 hash、tc 原值不变；春节、国庆、周末、停牌样例不伪造交易日。SSE:000001 指数与其他同码资产不会混淆。状态字段缺失显示未知，不用当前时刻补历史。

### U02｜分层缓存、异步状态与增量依赖

**依赖：** U01。**交付：** 复用现有入口的资源状态图、缓存键、失效表、任务幂等与可观察日志。

行情 ready、当前分析 queued、历史 history_running、上次结果 stale 可以同时存在；分别管理资源状态。`context_id/request_seq` 防页面迟到响应，`job_id/idempotency_key` 管独立计算，两者不能混为一个全局 loading。

| 层 | 复用条件 | 必须失效的例子 |
|---|---|---|
| 原始/规范化行情 | 资产、源、复权、日历、数据版本一致 | 除权回补、源修订、历史补洞、交易日历更正 |
| 单窗原始拟合 | 完整窗口输入 hash、参数/优化器版本及 seed 一致 | 新一天滚动改变输入；不能把旧窗拟合当新窗结果 |
| 后过滤/聚类 | 原始拟合可用且新规则所需字段齐全 | 过滤或聚类版本变化；缺字段不能靠旧通过列表还原 |
| 评分 | 冻结提醒记录、标签/评分版本与样本一致 | 标签修订、评分规则变更，生成新评分而保留旧评分 |
| 资讯/市场快照 | 来源、日期、版本、授权和可得性满足 | 来源修订、当日快照未完整封存 |
| AI 文案 | 资产、模式、证据集合 hash、结果版本与权限一致 | 新证据/新模型结果、用户权限或历史 as-of 变化 |

**验收：** 冷请求、暖缓存、尾部行情追加、只改评分、复权修订五组记录下载范围、复用窗口和重算窗口。只改评分可复用兼容拟合，但必须保留所有必要的原始记录，不能从只存合格窗的缓存宣称完整重评。数据修订按依赖定位失效，任何“仅增量”均需证据。

前台打开资产立即呈现可用缓存，刷新独立；有既定权限时按既有策略创建当前任务，历史必须显式请求。重复请求共享同一任务；快速 A→B→A 不串图。失败保留日期明确的旧结果；关闭菜单/AI 不取消独立模型任务。后台刷新按来源额度、交易时段和页面可见性调度，不为每张卡启动独立轮询。

优先问题：解释当前区间、比较两个候选、为什么仍是观察、为什么没正式提醒、区间为何修订、有哪些相关公告。回答数字只来自确定性工具；引用绑定 evidence_id、源版本、报告期和发布时点，能定位原文或图表。

**验收：** 新闻或公告中的指令仅作为数据；AI 不执行任意代码、下单、改模型参数或发起未请求计算。旧 result_id 返回不可伪装解释当前结果；历史模式不能带未来聊天或结论。公开行情缓存与私有自选/会话分开，跨用户无串读。来源许可未建立的内容不可因 AI 能读取而自动转载。
