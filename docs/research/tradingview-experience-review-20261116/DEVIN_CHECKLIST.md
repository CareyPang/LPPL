# Devin 实施清单：TradingView体验对照后的增量改造

日期2026-11-16。状态：**PROPOSED / NOT_RUN**。本次只交报告，不表示用户已经授权执行以下全部代码改造。保持Draft协作，不合并、部署、发布或购买；模型完整周期1.5和旧结果不动。

## A. 先冻结语义，避免界面越漂亮越误导

- [ ] 为所有资产建立同一个ChartContext：symbol、exchange、timezone、calendar_version、quote_asof、analysis_asof、mode、visible_range、display_resolution、model_sampling、fit_window_ids、result_id、source_snapshot_hash、model_version。
- [ ] 保持现有`lppl-data.js`数据入口；复用current/history任务、缓存与stale，不让图表或AI各自直连数据源。
- [ ] 上方明确显示最新报价时点及分析截止日。旧分析价格不能被标为最新价；未知/未建立不能写0。
- [ ] 候选对象至少有cluster_id、原始tc起止、日期单位、映射日历版本、支持尺度、结构资格、状态、first_visible_at、revision_of和结果版本。若历史对象没有某字段，保持unknown，不补造。
- [ ] UI显示范围/日周聚合不修改模型采样、输入hash或拟合窗口，不发新拟合请求。
- [ ] 固定少量fixture：有主候选、多个候选、近端0–4日、无候选、旧数据、失败保留旧结果、首次空数据、历史补算。不要为了验收而全量重跑研究。

## B. 第一个可演示交付：一个图表完成一项研究

- [ ] 压缩主图上方空白，资产/日线/日期/图层合并成紧凑工具行；右栏可独立滚动。
- [ ] 主图K线+成交量；光标同日联动OHLC、成交量和事件。缺数不连接成已知行情。
- [ ] 资产搜索支持代码/中文/拼音，结果带交易所与类型，A股优先；键盘上下/Enter/Escape及触控都能用。
- [ ] 日/周显示与1M/6M/1Y显示范围分别控件；返回最新、复位、定位候选不藏在菜单深处。
- [ ] 右栏第一屏依序：候选日期/无候选状态、截止日与证据状态、支持尺度与分歧、定位图表。历史回撤/估值等移到单独历史背景区域。
- [ ] 同一个cluster_id点击卡片能定位区间，点击图上区间能打开同一证据；多簇互不覆盖，原首窗与修订窗分别保留。
- [ ] 近端合格候选不因lead<5删除；过去tc不移到未来。所有现有结构资格保持原规则。
- [ ] 用户看历史期间新报价到来不抢视野；界面提供显式“返回最新”。切资产后迟到请求不得写入新资产。

## C. 日期映射是第一批阻断测试

**源码事实：** 固定main的index.html未来dateAt/idxOf仅跳过周末；指数已画区间，个股K线与历史情景分画布。见[引擎核查](chart-engine-notes.md)。这是需要验证的代码风险，不是已经修复。

- [ ] 覆盖国庆/春节等官方休市、普通周末、停牌、跨年、未知未来日历；由可追溯交易所日历驱动，未知不猜。
- [ ] 原始tc使用自然日还是交易日先确认；显示层不静默改变模型输出。非交易日端点需要明确映射策略和原始日期说明。
- [ ] 未来日期槽仅有时间，不制造OHLC/成交量；“未来”与“历史缺数”视觉不同。
- [ ] 相同结果在日/周显示、缩放、容器宽度变化、390px后原始日期不变；周线tooltip保留原始起止日。
- [ ] 区间超出当前视野时能定位；若坐标无法映射，保留文字结果及原因，不静默消失。
- [ ] 多簇重叠不以颜色叠加冒充概率，底部与顶部的研究证据等级分别显示。

## D. 原生Canvas与LWC的小样本对照

- [ ] 先给现有Canvas加语义与日期fixture，再搭一个不替换线上页的LWC原型。
- [ ] 同数据对比缩放、触摸、光标、未来槽、多区间、事件点、成交量、长序列、容器缩放和异常数据。
- [ ] 记录实现工时、依赖体积、首图可用时间、交互长任务、内存及稳定性；不得只拿默认demo截图比较。
- [ ] 检查LWC版本与插件兼容性、许可与归属；正式采用前验证当前API。不把Advanced Charts私有包放进公开仓库。
- [ ] 选择依据：日期正确性与功能覆盖先过，再比较维护成本；保留原图回退。换库不替代后端数据、提醒与证据。

## E. AI与统一回放

- [ ] AI只读当前结构化证据；数值由确定性工具计算；可点击定位候选/事件/日期和原文。
- [ ] AI回答带上下文版本；资产或as-of变化后旧答明确标旧。会话缓存隔离用户与完整对话上下文。
- [ ] 默认解释已有结果，不自动启动104周历史；新计算需用户主动动作，显示独立任务状态。
- [ ] 回放真正截断未来行情，不能通过悬停/导出/缩放/AI访问隐藏未来。
- [ ] 公告published_at、first_seen_at、revision、系统存档与首次用户可见分开；不存在历史版本就显示不可重建。
- [ ] 实时侧栏若保留，明确“现在”，且不用于历史回答；当前聊天中的未来信息不进入历史上下文。
- [ ] 原始首次预测、修订、历史重放与事后标签分账。结构强度、tc区间、预警效果分开展示。

## F. 首页与工作站的连续体验

- [ ] 先在独立预览制作“时间展开→候选区间→真实K线”的单主视觉；不用旧海洋叙事自动替代当前浅色首页。
- [ ] 演示样本有明确身份，不能包装成刚发布预测；真实资产加载后明确切换数据身份。
- [ ] 标题/搜索/CTA第一屏可达，动画可跳过；无空白滚动区、无音频素材加载、无必须等待动画结束的输入限制。
- [ ] 回访能继续最近资产/视野；首页品牌表达和日常工作站分工，不让背景持续运动影响读数。
- [ ] 状态变化用短动效；十字光标、价格与日期不做缓动。reduced-motion下功能完整。

## G. 桌面、390px与无障碍

- [ ] 桌面1440/1920宽：图表与右栏合理分配，缩放浏览器后控件不遮挡；右栏自选/AI/证据互斥。
- [ ] 390px：资产与截止日、候选摘要、主图在前；右栏改底部抽屉或独立详情，至少44px触控目标。
- [ ] 触摸横向看图、页面纵向滚动和双指缩放不互相锁死；提供查看大图与显式返回。
- [ ] 键盘出现后输入/取消仍可达；抽屉焦点约束/退出/恢复正确；图表外有可读取的数据摘要或表格。
- [ ] 涨跌正负号、区间线型与文字状态完整，浅/深色和色觉缺陷模式可辨；对合成背景实际测对比度。
- [ ] 首访弱网、视频失败、脚本慢、行情失败、计算排队时仍能使用搜索/缓存/返回。分别报告冷启动、缓存命中、缓存过期三组。

建议性能目标先作为待验证预算：缓存内容可用目标约1秒、暖缓存切资产目标约500ms；公开页面Core Web Vitals按实测统计。受网络/设备影响的目标不是承诺，不能从本次远程操作推断实际耗时。不要用假百分比代替排队状态。

## H. 最后交付与阻断项

交付顺序A→B/C→D决策→E→F/G；E中只读问答可与F轻量样稿并行。每项PR记录expected/completed/failed/pending、固定数据与版本、截图和未验收环境。候选消失、未来日期漂移、历史信息混入、旧结果冒充新结果、近端候选被5日门隐藏均为阻断项。

不把新UI、新图表库、AI解释或更丰富资讯当作预测能力改善；模型对照继续使用独立研究方案和保留结果。
