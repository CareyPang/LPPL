# TradingView 借鉴方案的对抗性设计审查

日期：2026-11-16。性质：`PROPOSED` 实施审查与验收清单，未实现、未运行。浏览器观察由主任务提供：已实测导航、600519搜索、十字光标OHLC/成交量、滚轮缩放拖动、快捷6M范围自动由1D改为2h、图表设置；回放只打开控件，未成功验证历史截断。因此下文不把TradingView回放称为本轮验证成功。

## 一定不能照搬的六件事

| 风险与反对意见 | 实施约束 | 验收失败条件 |
|---|---|---|
| **把快捷显示范围连带改成不同分辨率**。6M自动从日线切2h可能方便通用图表，却会使LPPL用户误认为模型也改为小时线 | 分开 `visible_range`、`display_resolution`、`model_sampling`、`fit_window`。日线模型标识常驻；切范围默认只改视野。若自动切分辨率，显式提示并可关闭 | 点击6M导致模型重算、拟合输入hash变化，或页面仍标日线却显示小时数据 |
| **用漂亮未来背景替代准确日期映射**。右留白不代表有未来交易日刻度；不同周期会让tc边界漂移 | 区间绑定绝对日期和交易所日历；未来槽无OHLC；模型时间单位与展示映射有明确版本。日/周切换只改变图形密度，不改结果日期 | 同一result_id在缩放/周期切换后区间日期变动，或未来区出现伪造价格/成交量 |
| **把提前5日变成不可见门槛**。用户要找到顶部区间，不能为了满足早提醒指标丢掉近端合格候选 | 结构资格与lead分开。0–4日候选保留并标临近；5–9、≥10日作为评分切片。过去tc/迟到提醒单列；其他结构过滤不放宽 | 合格近端区间仅因lead<5被删除，或过去tc被挪到未来计分 |
| **回放图是历史，旁边资讯和AI却是今天** | 单一as-of约束价格、事件版本、模型版本与AI证据；实时侧栏独立标识且不参与解释；没有历史版本时显示不可重建 | 昨天发布的公告出现在上个月当时已知视图；当前修订替换旧版本；AI引用未来聊天/结果 |
| **桌面四边工具栏原样塞进390px** | 小屏以资产/行情/候选摘要/K线为主；AI、证据、列表用互斥抽屉。图表有页面滚动出口和查看详情模式 | 图表只剩窄条；键盘挡住唯一退出按钮；拖图导致页面无法上下滚；抽屉关闭丢资产/日期 |
| **把换图表库当成完成产品** | 先冻结数据/证据契约，以同一fixture比较现有层与替代库；布局、提醒、数据、回放账本由项目独立承担 | 引入新库后丢现有stale/修订/来源状态，或宣称库自带真实提前发布证据 |

## 时间轴与未来区间的最小fixture

- [ ] **显示与模型解耦**：固定一份日线结果，在1M/6M/1Y、自定义拖动、日线/周线显示间切换；模型输入、设置和结果hash均不变，无后台拟合请求。拟合窗口字段仍明确为原研究窗口。
- [ ] **边界和日历**：覆盖周末、交易所节假日、停牌和未知日历。tc按自然日还是交易日输出必须在契约中说明；不能静默将非交易日吸附到前一根K线。图上显示映射与原始区间都可查。
- [ ] **日周对齐**：同一个绝对日期在周线可以落入对应周，但tooltip必须保留原始起止日，不将整周视作新模型区间。
- [ ] **未来与缺数**：未来时间槽只有日期，不制造未来OHLC；未来候选区域使用与历史缺数不同的状态标识。无法映射时保留可读区间卡并说明原因，不能让卡与图悄悄不同。
- [ ] **多簇与修订**：至少两簇重叠、跨尺度支持不同、一个近端一个远端。选择卡片高亮对应cluster_id；隐藏某尺度不重新计算模型或更改原始支持数。原首窗、修订窗不可互相覆盖。
- [ ] **视野稳定**：用户正看历史时新行情到达，保留可视区；返回最新为显式动作。窗口缩放只改变表示，不能把“当前分析范围”误写成“当前拟合样本”。

## 历史回放不是一个播放按钮

- [ ] 验证到指定as-of后，图表真正截断，悬停、缩放、导出和数据窗口均不能暴露隐藏未来价格；单步必须沿对应市场日历推进。
- [ ] 一个游标同步行情、条件事件、公开信息和模型版本。若某来源只有当前快照，不显示假的历史卡，计入覆盖缺口。
- [ ] 盘后公开时刻、来源首次发布、本系统首次抓取、首次送达/用户可见分字段；回放“当时公开可知”和“本系统实存”分证据级别。
- [ ] 历史AI会话与未来聊天隔离；所有市场事实需获准证据支持。LLM凭先验知道后续行情也不能当历史预测。
- [ ] 真正提前发布、历史补算与事后标签分账。失败、未成熟、无信号、未知保留；后续修订不回写首窗成绩。
- [ ] 回放的播放/暂停/速度/跳转/退出语义统一。主任务本轮只打开TradingView回放控制台，完整行为仍 `NOT_ESTABLISHED`；后续报告不得写“已验证同步回放”。

## 桌面与390px取舍

**桌面优先**：固定顶栏、充分主图面积、右侧可切换的自选/AI/证据，不同时打开三列。工具用短标签和tooltip，常用命令可搜索；默认不复制几十种绘图工具。保存视图时同时保存模式、资产和范围，不以复制整个HTML保存状态。

**390px优先**：行情+结论先可用；候选摘要可横向选择，但页面主体不横向溢出。至少44px触控目标；抽屉有可见关闭按钮、焦点恢复；键盘弹出后输入与取消仍可达。图表横拖与页面纵向滚动各有明确手势，提供放大查看和返回；不要把普通页面的滚轮滚动永久劫持成缩放。

**色彩**：涨跌颜色与模型/交互颜色分离。区间用边界、低透明填充、标签及选中态；强度不是概率，不用饱和度暗示未经校准的“99%”。重叠区不能越叠越深就被用户理解为独立证据累乘。浅/深模式、红涨/绿涨偏好不改变语义，缺数与平盘必须不同。

**动效**：只为定位、抽屉和状态切换服务；尊重reduced-motion。模型结果更新不能以闪耀/放大营造预测变得更可信；回放中价格变化与装饰动画分离。

## 发布前硬门

上面的事实一致性、时点隔离、未来区间映射和近端候选可见性为阻断项；尚未建立时不能靠视觉截图验收通过。首轮选择少量固定案例测试，报告 `expected/completed/failed/pending`。性能另测首屏、交互帧耗时、内存、390px真机和大陆网络，不从官方营销语推断。

本审查不建议改动完整周期1.5或LPPL拟合器，也不以视觉改善推断模型预测能力改善。
