## 1. 先把四种问题分开

| 问题 | 本次可以回答什么 | 不能据此回答什么 |
|---|---|---|
| 优化器是否找到较低残差 | 同一人工输入和同一搜索域下的 SSE、耗时与调用数 | 股票预警是否有实际价值 |
| 人工模型中的 tc 能否恢复 | 已知生成参数的绝对误差、边界堆积、seed 稳定性 | 真实价格顶部日期误差 |
| 时间信号能否提前覆盖目标事件 | 本次未执行，需要事先定义事件及发布/执行时刻 | 不能用未来跌幅标签反填当时的模型输入 |
| 未来回撤、价格区域、抄底 | 本次未执行，需要独立目标、数据和基线 | 不能由一个 tc 或拟合密集区直接推出 |

**VERIFIED（方法边界）：**变量投影把非线性搜索留给 `(tc,m,omega)`，其余四个系数条件线性求解；这解决校准问题，不提供本项目事件概率或跌幅校准。[Filimonov–Sornette 原文](https://arxiv.org/abs/1108.0099)

## 2. 当前实现差异：搜索域、过滤和输出并不是一回事

个股入口强制 v2。v2 用 `max(abs(tc-t),1e-3)`，因此可拟合样本中已经发生的临界位置。绝对值延拓本身有公开文献来源，但它引入了对临界点两侧形状的假设；不是“刚刚提前预测到了已经过去的点”。[Gerlach–Demos–Sornette，附录B](https://arxiv.org/pdf/1804.06261)

**VERIFIED（源码）：**页面主要情景取 `box` 合格拟合。`box` 检查 `B<0`、`m∈[0.1,0.9]`、`omega∈[6,13]`、`ahead∈[0,90]`，不检查振荡数、阻尼或残差门槛。源头的搜索域允许过去 tc，不表示所有过去 tc 都会出现在这个 box 输出中；但 `ahead=0` 仍不满足提前5交易日，未来 tc 也不自动等于真实顶部。

**NOT_ESTABLISHED（建议）：**研究中分开保存 `future_only` 和 `inside_descriptive` 两类任务。前者再按首次可执行时刻、预测最大跨度和用户提前量目标评价；后者只作拟合诊断。不要先跑宽域、再把恰好未来的最佳解当作与未来域重新优化完全相同的结果——宽域的全局最低点可能是过去点，删除它以后并不会自动找回未来域的次优解。

## 3. “振荡数2.5”的单位差异已核实

当 `tc>t2` 时，余弦相位在窗口内的变化量为 `omega*ln((tc-t1)/(tc-t2))`，完整周期数为：

`N_cycles = omega/(2*pi) * ln((tc-t1)/(tc-t2))`。

**VERIFIED（数学及源码）：**`core.Fit.n_osc()` 和 `js_compat.py` 使用完整周期；`lppls_rules._derived()` 另存 `osc=omega/2*ln(...)`，然后令 `n_osc=osc/pi`。因而：

- `osc >= 2.5` 相当于 `N_cycles >= 0.795775`；
- `n_osc >= 2.5` 才是至少2.5个完整周期；
- 这两条规则相差 pi 倍，不是可互换的字段名字。

**VERIFIED（具体文献范围）：**Gerlach–Demos–Sornette 的表2/表4明确用 `omega/(2*pi)`，且只在 `abs(C/B)>=0.05` 时施加2.5周期条件。这支持该论文口径，不证明某个商业平台的所有过滤器均如此。[原文表2](https://arxiv.org/pdf/1804.06261#page=21)

**NOT_INSPECTED／NOT_ESTABLISHED：**本轮没有取得 FCO 服务器原始拟合、过滤代码或受保护的业务 JSON，不能把仓库内 `g_fco_*` 名称当作已证明的官方逐项复刻。`lit*` 引用的另一套历史文献记号也不能直接抹去：先保留原结果及公式，再新增带单位的版本作对照。

**NOT_ESTABLISHED（建议）：**统一新增诊断字段 `osc_cycles` 和 `osc_phase_half_radians`，每个过滤协议注明公式、单位、阈值及振幅条件；旧字段保持兼容。拟合本身先不改，使用同一批原始拟合分别计算两套过滤结果，统计每尺度拒绝原因、保留率、边界解和后续事件覆盖。2.5周期是可复现的文献基线，不是已经证实对A股最优的数值。弱振荡时即使免除振荡数条件，也不能因此把难以识别的 tc 宣传为精确预测。

**VERIFIED（影响方向的边界）：**在其他条件一致且tc位于未来时，2.5完整周期比`osc>=2.5`更严格，合格集合不会扩大；但情景中心、宽度和真正命中率怎样变化，不能仅由公式推断。当前`box`主情景不使用这两项，单改振荡数单位不会直接改变该主情景的入选窗口。

窗内 tc 的端点绝对值对数比不能被直接解释为跨越临界点的完整振荡总数：相位在点的两侧改变方向，且邻近点依赖 `MIN_DT` 截断。本轮不为这类描述拟合计算未来域的振荡数合格率。

## 4. 实际执行的公平性探针

**VERIFIED（本次执行）：**脚本 [`tools/lppl_synthetic_optimizer_probe.py`](../../tools/lppl_synthetic_optimizer_probe.py) 直接调用仓库 `de_lbfgsb` 和 `tcgrid_lm`，仅在本进程包装计数器，不修改生产实现。

- 两路共享原始输入、变量投影线性求解、搜索边界及每次最多 **6000 个参数点线性求解／残差求值**、**3秒**预算上限。
- DE：`rand1bin`，population multiplier 10，最多120代，随后现有独立 L-BFGS-B 精修。每case分别运行seed 0、1、2。
- 网格＋TRF：20×8×10参数网格，取5个tc剖面候选，另加3个随机起点；每case分别运行seed 0、1、2。现有 `tcgrid_lm` 的局部算法确为 `trf`，不是 LM。
- 实际objective调用、residual调用及批量网格点分别计数；数值Jacobian引起的残差调用也计入。网格批次耗时上限只在批次间检查，因此时间上限属于软上限。
- 退出搜索后，对返回参数另做一次条件线性求解核对SSE；这项相同的结果审计不计入搜索调用数和搜索计时。
- 两路拥有相同上限，**不是消耗了完全相同的工作量**；本次所有运行都在触及共同上限前返回。比较的仍是两套明确预算配置，不能称为两类算法的最优性能上界。
- 相同seed编号只表示各方法可复现，不表示两种算法使用同一组随机点；每条case只有一份固定噪声实现，三个seed不是三个独立行情样本。
- 单BLAS线程；Python3.12.10、NumPy2.5.4、SciPy1.18.1，具体BLAS与源码哈希保存在结果中。没有保证整台电脑的负载隔离，不能把此处秒数作为腾讯云吞吐、线上SLA或成本估计。

SciPy 文档说明 `least_squares.nfev` 不包括数值Jacobian近似调用；本次一条TRF结果报告2406，但探针实际计到4593。原项目两种方法的 `nfev` 不能未经转换直接当成同一种成本。[SciPy least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)

DE 全局代数、population和精修成本需要分别记录；SciPy 的DE最大调用公式不包含后续精修。TRF与LM也是不同求解器，不能以函数名 `lm` 宣称当前在用LM。[SciPy DE](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.differential_evolution.html)

|---|---:|---:|---|---|
| 125点、无噪声、未来tc | 0.217秒 | 0.097秒 | 均小于0.00004 | 均小于0.000000000001 |
| 250点、独立噪声、未来tc | 0.206秒 | 0.076秒 | 约0.666 | 约0.666 |
| 250点、弱振荡＋AR(1)噪声、未来tc | 0.280秒 | 0.127秒 | 均23.8，落在tc上边界 | 均23.8，落在tc上边界 |
| 250点、窗内tc描述序列 | 0.281秒 | 0.197秒 | 约0.0148／0.0148／0.0148 | 约15.0227／15.0227／0.0148 |

24次拟合环累计 **4.760秒**；此计时不包括解释器及库导入、输入生成、证据写盘、过滤诊断，也没有数据下载、全窗口扫描、历史重放、bootstrap或网页等待。这里的bar是人工序列下标，不能称为真实交易日提前命中。

**VERIFIED（数值观察）：**前三条未来域case两路得到近乎相同SSE，TRF在这些配置下更快。窗内描述case中，TRF两个seed停在较差解，SSE约0.06337；DE三个seed及TRF另一个seed达到约0.006133。弱振荡case两路稳定地找到同一个边界解，但它距离生成tc有23.8bar。稳定、低残差、优化器一致都不能独立证明tc可识别或具有预测能力。

**VERIFIED（过滤后另算）：**对三条未来域case，另用仓库 `core.TOP_RULE` 作确定性诊断：无噪声及独立噪声各方法均3/3保留；弱振荡case各方法均0/3，因omega范围不合格被拒绝，过滤后误差写为null。没有把被拒绝的失败样本从总体分母删除；这也不是生产 `box` 的结果。窗内case不适用这个未来域过滤。

**NOT_ESTABLISHED：**四条人工序列不足以宣布某种优化器总体更好。`returned`只说明函数有返回，不保证每个内部起点都收敛；当前TRF封装没有保留每个起点的终止状态，DE的原始终止信息已保留。没有执行严格的相同墙钟全预算搜索、噪声重复样本实验、硬件隔离多轮复测或真实预测比较。

## 5. 聚类必须检验“跨尺度支持”，而不仅仅求一个密集区

**VERIFIED（现有代码）：**`research/lppls/scenarios.py` 在标准化的 `(窗口长度,tc−t2)` 平面做KMeans，`n_init=10`；在2至4簇中选择Silhouette最高且至少0.5者，否则单簇；不足3个拟合或占合格拟合不到5%的簇不保留。按簇报告分位数，不跨簇平均。这已不是单次随机KMeans，但只是同一日的几何分组；十次初始化并不构成十次独立市场证据。

**NOT_ESTABLISHED（下一轮待检验规格）：**

1. 同一 `symbol/asof/t1/t2/domain` 只有一个窗口身份；多seed为该窗口内部优化诊断，只给一次窗口权重。记录最优解、近等价解和失败率，不能只留成功seed。
2. 将“找不同形状的情景”和“不同尺度的tc是否重合”分开。现有二维KMeans保留作基线；另定义按tc距离构成的候选区间，逐尺度计算支持量，避免二维距离仅因窗口长度差异把同一tc分开。
3. 预先固定尺度及归属。研究层现有短30–120、中100–240、长200–720 bar有重叠；跨尺度联合评分时要分摊重叠窗口权重，或新增互斥分组版本，不能把同窗在两组重复计票。月度产品标签与这些历史拟合窗口不是预测提前期限。
4. 每个尺度先按全部计划窗口归一，再聚合；同时显示尝试数、可算数、通过数、缺失原因。长尺度窗口多，不能仅凭原始数量压过短尺度。
5. 在每日固定截止点重算情景，衡量连续日期间区间重合、中心漂移、边界比例及支撑尺度数。不得把不同日期的tc相对偏移直接混为一组；先映射到同一交易日历。
6. 时间稳定性会消耗提前量。比较“当日就提醒”与“连续两/三次确认”的漏报、误报、提前量和警报天数，不能仅展示确认后更漂亮的区间。
7. 区间宽度≤10日只是一项目标；宽、多峰、边界挤压或支持不足时保留宽区间/多情景/拒答。禁止从一个宽簇事后裁最窄十日区间，再称预测成功。
8. 在相同警报预算下对比简单风险基线、原始box聚类、去重跨尺度、跨日稳定性增量。最后两项分别消融，不能一次改所有模块后归功于“聚类更强”。

**NOT_ESTABLISHED：**拟合支持比例不是实际顶部概率；相关窗口、同一市场冲击中的股票也不独立。真正概率须在未用于选规则的成熟记录中校准，且记录拒答与无事件样本。当前没有新证据证明“多尺度都集中就一定有更高命中率”。

## 6. 如何缩短等待而保留可核查的研究质量

本次工程已经实施“先行情/缓存、后当前分析、历史另请求”，它消除的是不必要阻塞。进一步减算力应分阶段研究，而不能先承诺准确度不降：

| 路线 | 计算策略 | 必须比较的代价 |
|---|---|---|
| 第一层 | 固定稀疏窗口覆盖各尺度，少量但固定的起点预算 | 与密集完整扫描的区间漂移、漏掉的情景和拒答变化 |
| 第二层 | 仅对近似多解、边界堆积或残差差距小的窗口增加预算 | 是否系统性偏向漂亮结果；预算升级规则应预先固定 |
| 第三层 | 扩展相关尺度窗口，执行独立seed或替代优化器核对 | 改善是更低SSE还是更可靠tc；不能把新增起点当新增票 |
| 离线层 | 夜间缓存、历史回放、噪声/重采样敏感性分析 | 对实时输出版本的滞后及算力成本 |

不应给每个首次查询都运行104周历史或每窗100次bootstrap。bootstrap也不自动产生已校准的顶部置信区间；应单独检查重采样假设、时间相关性、覆盖率和计算预算。

**NOT_ESTABLISHED（决策）：**本次合成结果支持继续比较“TRF为快速候选、DE作有限预算交叉诊断”的工程实验，但尚不足以更换生产优化器。先补齐真实调用数及各起点状态，再扩展人工噪声家族与无LPPL结构负例，最后在固定且允许的真实数据协议中检验增量。

## 7. 价格层与顶部／底部的衔接

**NOT_ESTABLISHED（研究拆分）：**时间层只输出满足证据约束的未来风险情景；价格层分别研究固定期限最大不利变动的条件分位、确认下跌后的价格区域、以及下跌后的进入/退出规则。三者有不同标签成熟时间和评价分母，不应装进一个所谓“LPPL目标价”。

顶部的正泡沫拟合与负泡沫/反泡沫拟合应独立命名和计分。对 `-log(P)` 拟合在代数上能反射方向，但涨跌停、停牌、负偏度和流动性不对称，不能把逃顶有效性自动转移为抄底有效性；峰后以起点锚定的衰减振荡又属于另一描述任务。

下一步顺序：统一诊断单位与预算日志 → 冻结合成实验扩展协议 → 固定时间事件及不确定性评价方式 → 检验跨尺度与跨日增量 → 独立开展价格层及抄底目标。用户未确认的60交易日规则仍保持候选状态。
