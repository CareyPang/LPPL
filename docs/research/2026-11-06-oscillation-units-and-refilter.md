## 1. 单位修复与门槛升级分开

对严格未来临界点 `t1 < t2 < tc`，令窗口跨度 `L=t2-t1=n-1`、模型前视距离 `h=tc-t2`，完整周期数是：

```text
N_cycles = omega / (2*pi) * log((tc-t1)/(tc-t2))
         = omega / (2*pi) * log1p(L/h)
```

**VERIFIED（数学、源码）：**余弦相位变化 2π 才构成一个完整周期。仓库旧 `osc=omega/2*log(...)` 是半相位统计量；在未来域、旧分母截断未生效时，旧值为 `pi*N_cycles`。因此旧 `osc>=2.5` 的相同决策门槛是 `N_cycles>=2.5/pi≈0.795775`，不是 2.5 周期。

| 字段 / 门槛 | 本次处理 | 是否改变旧结果 |
|---|---|---|
| `osc_cycles` | 新规范字段；仅严格未来域有效，单位为完整周期 | 新增诊断 |
| `osc_cycles_status` / `osc_units_version` | 明示非法输入、非未来临界点、单位版本 | 新增诊断 |
| `osc_legacy_half_phase` / `osc_legacy_cycles` | 精确保留旧公式及除 π 的换算值，包括 abs 和截断 | 否 |
| 原 `osc` / `n_osc` / `Fit.n_osc()` | 保持兼容，不重新解释历史文件 | 否 |
| `N>=1.5` / `N>=2.5` | 仅在新对照工具中筛选，不替换生产默认值 | 仅新实验 |

**VERIFIED（兼容设计）：**旧 `rules`、`grid_rules`、反泡沫规则继续按原数值比较，避免边界浮点换算也改变旧结果。比较 API 将单位转换不一致单列诊断。`tc<=t2` 不进入规范未来周期计数；历史 abs 延拓结果仍保留，不能算成新的提前预测。

**VERIFIED（入口差异）：**当前页面主情景的 `box` 原本不设振荡数门槛。因此“box 加 1.5/2.5”是增加过滤条件；不是修正一个显示单位就自动改善页面的预测。

“旧规则”必须带来源：仓库 `lit1/lit2` 和部分 `g_fco_*` 用旧半相位 2.5；`g_fco_early` 用旧半相位 1.5；`p_ds/p_strict` 已按完整周期设 2.5，`p_top` 为 1.5 周期；海力士原 `raw_clean` 为 1.25 周期。不能把这些统称为同一套旧 2.5 门槛。本次所有新工具都明确写出规则族、公式及单位。

## 2. 原文核对的更正

**VERIFIED（原文）：**Gerlach–Demos–Sornette 的表 2/4 使用 `omega/(2*pi)`，2.5 周期条件只在 `abs(C/B)>=0.05` 时施加；其余参数范围也有自己的规定。本次无振幅豁免的单因素实验不声称复现该论文整套规则。[原文表 2](https://arxiv.org/html/1804.06261#S4.T2)

**VERIFIED（原文及代数核对）：**Zhang–Zhang–Sornette 2016 表 3 的公开公式写作 `omega/2 * log(abs((tc-t_start)/(t_end-t_start)))`，分母是窗口长度，和仓库用的 `tc-t_end` 不同。按表中条件 1 的未来域上界 `h<=0.13L, omega<=13`，其字面统计量最高为 `6.5*log(1.13)=0.794415`，达不到同表的 2.5 门槛。这说明公开表内存在不一致，不能据此确认“DS/FCO 标准就是约 0.8 完整周期”。[原文表 3](https://pmc.ncbi.nlm.nih.gov/articles/PMC5091919/#pone.0165819.t003)

**NOT_ESTABLISHED：**原作者意图、是否排版错误、商业 FCO 服务器实际执行的公式及全部过滤细节未建立。此前笼统称“两个文献口径只差 π 倍”不够准确；可以确认的是**本仓库两个具体计算式**在指定域内的 π 倍关系。旧文献笔记与旧结果保留，由本报告补充更正。

## 3. 为什么更严格的周期门槛可能压缩提前距离

**VERIFIED（代数，不是预测）：**固定窗口长度与频率时，`N>=N_min` 等价于：

```text
0 < h <= L / expm1(2*pi*N_min/omega)
```

| 窗口点数 n | omega | 旧门槛等价 0.7958 周期：h 最大值 | 1.5 周期 | 2.5 周期 |
|---:|---:|---:|---:|---:|
| 60 | 6 | 45.35 | 15.48 | 4.64 |
| 60 | 9 | 79.42 | 31.90 | 12.48 |
| 120 | 9 | 160.18 | 64.34 | 25.17 |
| 250 | 9 | 335.17 | 134.62 | 52.67 |

只展示周期条件单独施加的上界；实际搜索域和其他门槛还会缩小允许范围。`h` 是拟合 `tc` 距收盘 as-of 的交易 bar 数，不是真实顶部提前量。例如 60 点、omega=6 的拟合若要求 2.5 周期，所有 `h>4.64` 的候选都会被机械排除；下一交易日才行动时可用距离还要少 1 bar。不能把过滤后的 tc 更集中、更近，解释为预测自动更准。
