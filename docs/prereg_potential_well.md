## 1. 检验 A：势阱价位对回撤低点的定位
- 事件：仓库现有共识顶（`run_top` main 变体，`consensus_tops`），顶后 120 日最大回撤 ≥ 8%。顶部日 t 的势阱只用 ≤ t 的数据。
- 量纲：所有距离除以 σ_t = 顶部日过去 60 日对数收益标准差 × √60。
- 统计量 D：回撤低点到最近下方势阱中心的距离 / σ_t，按事件取均值。命中 = 距离 ≤ 0.02（对数）。所有方法用同一个命中带，不用势阱自己的捕获带。
- 零对照 N1（跨顶部调换）：同一指数内，把另一个顶部的势阱偏移（先除以它自己的 σ，再乘本事件的 σ_t）换给本事件，势阱个数随之调换；2000 次。
- 对照 B1（同数量档位）：本事件有 K 个下方势阱，就取 K 个档位，放在“t 之前已到期的顶后回撤（σ 单位）”分布的 k/(K+1) 分位上。t 之前到期事件不足 20 个的顶部不参加检验 A。
- 补充（PIT）：“已到期”指同一指数内顶部 j 满足 j+120 < t 且其顶后 120 日回撤 ≥ 8%（与事件同一条件分布，含 2000 年以前的顶部）；后续顶部不进入。
- 补充（零势阱）：顶部日下方势阱数为 0 的事件不参加 D 的统计、不参加 N1 调换，单独报告占比；占比 > 50% 时检验 A 记为“样本不足，未通过”。
- 通过条件（全部满足）：
  1. 六指数合并，D 低于 N1，单侧 p ≤ 0.05（p = mean(null ≤ obs)，过滤 NaN）；
  2. D 低于 B1 的指数 ≥ 4/6；
  3. 剔除 2007、2008、2015 年的顶部后，D 仍同时低于 N1 均值和 B1。
- “跌破势垒后跌幅更大”不作为判据（定义循环）。

## 2. 检验 B：反手做多的增量消融（严格因果）
- 事件（不用事后顶部标签）：收盘价相对过去 120 日最高收盘价回撤首次 ≥ 8% 的那一天 e；同一高点只记一次，创出新高后重新计。
- 入场搜索：e 之后 120 个交易日内，首个满足该组条件的交易日发出信号，次日开盘买入，每个事件最多入场一次。持有 60 个交易日。止损：收盘破止损价，次日开盘卖出。
- 各组（逐项叠加）：

| 组 | 入场条件 | 止损 |
|---|---|---|
| R0 | 事件日 e 直接入场 | 无 |
| S1 | 价格落入势阱捕获带（基础势阱） | 无 |
| S2 | 同 S1 | 势垒止损；对照为 S1 + 固定 −8% 止损 |
| S3 | S1 + 套牢盘占比 ≤ 该指数截至当日的历史中位数 | 无 |
| S4 | S1 + 阻尼确认 | 无 |
| S5（主判据） | 原型 `reentry_signal`（势阱 + 阻尼 + 盈亏比 ≥ 1.8） | 势垒止损 |
| S6 | S5 + 套牢盘占比条件 | 势垒止损 |

  套牢盘占比原型没有给阈值，这里用“截至当日的历史中位数”，不引入可调参数。
- 指标：60 日收益均值、收益 5% 分位（P5）。同时报告入场覆盖率、止损率、中位等待天数。
- 随机基准：每组在相同事件的搜索窗口内随机取同样多的入场日，用同样的止损规则，2000 次。
- 单组通过条件（全部满足）：
  1. 收益均值 > 随机基准 95% 分位；
  2. P5 ≥ 随机基准 P5 的中位数；
  3. 入场覆盖率 ≥ 30% 的事件；
  4. 均值高于随机基准中位数的指数 ≥ 4/6；
  5. 剔除 2008、2015 年事件后，均值仍高于随机基准中位数。
- 补充（未入场口径）：主口径只统计已入场交易（各组均值、P5、均值差同一口径）；“未入场记 0”作为副口径并列报告，不参与判门。
- 入场与退出细节：搜索日为 e+1…e+120；买入价为信号次日开盘；无止损或未触发时在信号日后第 60 个交易日收盘卖出；势垒价缺失或不低于买入价时该笔不设止损；所有交易的卖出日不得晚于 2018-12-31，否则该日不可入场（随机基准同样限制）。
- 增量条件（固定对比表：S2 对 S1+固定 −8% 止损；S3 对 S1；S4 对 S1；S5 对 S1；S5 对 S4；S6 对 S5）：收益均值之差按“指数×年份”整块自助抽样 2000 次，95% 区间下界 > 0。
- 结论规则：
  - S5 单组通过，且对 S1 的增量区间下界 > 0 → “过门”，向用户汇报，是否进校准段由用户决定。
  - 否则登记“未通过”，归档，不调参、不跑校准段。
  - S1–S4、S6 只作消融说明，不单独作为上线依据（多重比较不另行校正，结果表中注明）。
