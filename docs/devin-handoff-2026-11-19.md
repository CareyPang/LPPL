## 可以怎样验收

在「我的研究」添加上证和贵州茅台。选中标的，在「封存记录与区间变化」查看前后原档或进入指定版本的图表。「指定交易日收盘前」按北京时间 15:00 筛选。普通行情入口标为最新。返回工作台可以恢复原自选搜索条件与封存截止日。

构建核对了 747 个资产标识、42 份指数封存及 2,410 份个股作业原档，标出 10 处缺口。原始文件以 Git 版本与 SHA-256 定位。浏览器另对解码后的完整 JSON 核对内容指纹。每只标的按需读取。指数封存时间、个股作业生成时间与浏览器阅读时间分别解释。**公开首发时刻仍未知。** 作业与区间变化不能据此计为用户当时已收到提醒。
