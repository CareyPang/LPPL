# 预登记：“国家队动向”席位与基差状态的历史检验（nt_futures_signal_v1）

状态：**已运行（2026-11-28），6 个事件全部未通过**。登记部分在计算任何“之后走势”之前提交（commit b79580d4），检验只跑了一次；结果见文末。

## 背景

用户提供的一份第三方日报把下面两条当作“国家队进场信号”，再看另外两路是否同向：

- R1 席位脉冲：中信期货 IF + IH 多单合计单日增加 ≥ 5,000 手。
- R2 基差突变修复：IC 主力合约基差由负转正。
- 另两路：前 20 会员净空是否收敛、指数是否大涨。

阈值和规则是别人定的，这里原样照搬，不调参。要回答的是：这些状态出现之后，沪深300 的走势和任选一天有没有区别。

## 数据

- 中金所每日持仓排名（`sj/ccpm/{YYYYMM}/{DD}/{IF|IH|IC|IM}_1.csv`）和每日行情（`sj/hqsj/rtj`），2015-04-16 至 2026-11-27，共 2825 个交易日，无缺日；IM 自 2022-07-22 起。
- 现货：沪深300、上证50、中证500、中证1000 收盘价（baostock）。
- 席位名以“中信期货”开头的行都算中信席位（历史上依次写作“中信期货”“中信期货(经纪)”“中信期货(代客)”）。
- 多单 / 空单 = 该品种所有上榜合约的持仓合计；单日变化 = 当日合计 − 上一交易日合计（与那份日报的 +18,015 手口径一致）。
- 基差 = 当日成交量最大的未到期合约收盘价 ÷ 现货收盘价 − 1。
- 前 20 净空 = 四个品种（IM 上市前为三个）所有上榜合约的空单合计 − 多单合计。
- 已看过的数据：只看过 2026-11-25 至 11-27 三天的读数，用来核对口径；没有看过任何一天之后的走势。

## 已知局限（事先写明）

- 5,000 手是绝对手数。2015-09 至 2019-04 股指期货受限仓，全市场持仓很小，R1 在那几年基本不会触发；结果按 2015–2018、2019–2022、2023–2026 分段列出。
- 只有上榜（各合约前 20 名）的持仓，席位掉出榜单会被记成持仓减少。
- 中信期货席位是代客持仓，包含所有通过它交易的客户，不能等同于国家队。

## 状态定义

| 代号 | 条件 |
|---|---|
| R1 | 中信 IF+IH 多单单日变化 ≥ +5,000 手 |
| R2 | IC 基差前一日 < 0 且当日 > 0 |
| R3 | 前 20 净空比前一日减少 |
| R4 | 沪深300 当日涨幅 ≥ 2% |
| X1 | 中信 IF+IH 多单单日变化 ≤ −5,000 手（反向） |

检验的事件：

| 代号 | 条件 | 说明 |
|---|---|---|
| **E1（主）** | R1 | 席位脉冲 |
| E2 | R2 | 基差转正 |
| E3 | R1 且 R2 | 日报所说的“信号触发” |
| E4 | R1、R2、R3、R4 同时成立 | 四路同向 |
| E5 | R1 且不满足 R3 | 席位脉冲但前 20 净空扩大（日报当天的情形） |
| E6 | X1 | 反向 |

## 统计量

- 信号日：2015-04-17 至 2026-08-28（之后 60 个交易日的窗口在数据末尾之前结束）。信号当日收盘价起算，标的为沪深300。
- 去重：取到一次事件后，之后 20 个交易日内的同类事件不再取。
- 之后 5 / 20 / 60 日涨跌的中位数、上涨比例；之后 20 日内最大回撤（最低收盘相对信号价）。
- 基准：信号日区间内任选一天。
- 随机对照：事件序列在区间内整体循环平移 2000 次（种子 20261128），重新去重，比较之后 20 日平均涨跌；双侧 p 值。

## 判定（事先写定）

一个事件要在页面上写成“之后走势偏强 / 偏弱”，必须同时满足：

1. 去重后事件数 ≥ 15。
2. 之后 20 日平均涨跌与基准的差，随机对照双侧 p < 0.05 / 6（6 个事件，Bonferroni）。
3. 2019–2022 和 2023–2026 两段里，差的方向相同，且每段事件数 ≥ 5。

不满足的事件，页面只能写当日读数和“历史上出现过 N 次，之后走势与任选一天没有可分辨的差别 / 样本不足”，不能写“进场信号”。

本检验只跑一次。口径或阈值要改，必须重新登记，并说明这段数据已经看过。

实现：`research/eval/nt_futures_signal.py`。

## 结果（2026-11-28 运行）

与登记的两处出入，都不涉及条件或判定：

- 信号日截止由 2026-08-28 改为 2026-08-27：2026-08-28 之后只有 59 个交易日，登记写明要完整的 60 日窗口。共 2764 个信号日。
- 脚本补了 `zip(strict=True)`（lint 要求），不影响结果。

基准（任选一天）：之后 20 日平均 +0.1%、中位 +0.1%、上涨比例 51%，20 日内最大回撤中位 −2.4%。

| E1 席位脉冲 | 32 | +1.0% | −0.0% | +2.0% | 47% | +2.0% | −1.7% | 0.0165 | 未通过（门槛 0.0083） |

读法：

- E1 的 20 日平均高出基准 1.9 个百分点，但中位数是 0、上涨比例 47%，平均数是被少数几次大涨拉高的；没过多重检验门槛。32 次里 26 次在 2023 年以后，2019–2022 只有 5 次。
- 四路同向（E4）在 2015-04 至 2026-08 一次都没有出现过，无法检验。
- 反向（E6，中信多单单日减少 5,000 手以上）之后并不偏弱，20 日上涨比例 62%。
- 结论：这些状态在页面上只能写当日读数和历史出现次数，不能写“国家队进场信号”。
