# 临界点 2.0 战略规划（2026-10-29 v1）——从产品终态倒推的完整路线

**北极星**：用户输入 A 股代码或指数，得到白话结论：现在是不是泡沫、风险几级、怎么分批减仓；泡沫破裂后跌到哪个区间、是否已止跌、什么价位分批买；二波大概能到哪、何时退出。每个结论都带证据等级，没有证据的地方明说"没有证据"。

**分工**：本规划覆盖我负责的部分——金融模型层（顶 / 底 / 体制判定）与价格层（顶后底后的区间与分批价位、执行规则）、它们的数据与评价、以及向 Web 应用输出的契约。前端产品设计由用户在 Open Design 完成，按契约字段渲染。

**三条不变的原则**（Round 1 教训）：
1. 预测只给**区间与概率等级**，不给日期和点位；"什么价位买卖"给的是分批**价位带**，带 n 与证据等级。
2. 任何进入产品的规则先预登记、再在从未用过的样本上评价；失败就标失败，不换标签重讲（`docs/dev_freeze.md`）。
3. 原版（FCO）有、且公式公开的功能才复现；公式未公开的不做"研究版"冒充。

### Round 3（2027-H2 起，视 Round 2 结果）
- 状态 × 信号两层：报警只在非熊市体制下计数；再入场只在体制结束后——用 Round 2 通过的模块组合，预登记后在前瞻日志上评价。
- 跨市场汇总标定 → A 股前瞻检验：阈值在全球样本上定，A 股只用前瞻日志验证。
- 模型细节（公开定义内）：t_c 区间改修正剖面似然（Filimonov 2016）；Combo 幂平均跨尺度；Trust 的预测价值评价；R7/R8 与 LPPLS 合成链。
- 不做：公式未公开的 bubbleScore / tcOffset / 密度曲线；Hawkes 临界、Hurst、CSD、Ising、估值择时、负泡沫重做（文献复查已排除）。

### 前瞻日志扩容（贯穿）
- 6 指数 → 约 30 标的（+10 中证行业、+4 外部指数、+港股 / 商品若干），每日封存；季度复盘自动跑 A1/A2 vs 随机。
- 预期：两年内报警事件数 ×5，2028 年中第一次有统计意义的样本外结论。这是产品从 `dev_only` 走向 `single_oos` 的**唯一**合法路径。

## 4. 价格层路线（我的核心交付：到顶 / 到底怎么判，之后什么价位买卖）
价格层不做预测模型（Q-DD、负泡沫、Sornette–Zhou 反泡沫都已证明不可行），而是**三件可验证的东西**：区间统计、确认规则、执行规则。

### 4.1 到顶：判定 + 卖出价位
- 判定 = T 卡分级（置信度阈值），不等 t_c。
- 卖出分批带（现行，开发段规则）：≥20% 减 1/3；≥50% 再减 1/3；剩余 1/3 持有至报警确认结束或自高点 −10%（2015 唯一改善案例，`dev_only`，不写指南）。
- Round 2 复核：在外部市场重跑 `exit_rules_dev`（事件级新标签），比较"直接减仓 / 止损 / 持到结束"；通过则把"剩余 1/3 的处理"写进指南。
- 顶后价格带（P1）：回撤情景表（按泡沫大小 / 持续 / 估值分桶，跨市场 n）+ 估值地板带（历次 PS 底部 PE/PB 分位换算点位）。**只给带与 n**。

### 4.2 到底：判定 + 买入价位
- 便宜层：回撤分位（相对历史无条件分布）+ 估值分位 → "够不够便宜"。
- 止跌层：LT 15% 停时确认，或 M1 体制结束持续 N 周 → "是否已止跌"。代价是底部过后 10–15% 才确认——这是避免抄半山腰的唯一诚实方法。
- 买入分批带（P2，待 Round 2 评价的执行规则）：第一批确认日；第二批回踩不破确认低点；第三批站上 60 日线。评价：确认后 120 日不创新低比例 vs 随机、组合 MDD vs 一次性买入。
- 不给底部日期；不给"目标价"。

### 4.3 二波：目标与退出
- 目标 = 崩盘后首轮反弹收复跌幅比例的经验分布（跨市场 n）。
- 退出 = 短档（1–3 月 / 3–6 月）报警 → 二波子集评价通过后作为提示；否则只给统计。
- 2009-08 是 A 股唯一完整案例，已证明短档当时有报警、被旧标签过滤。

### 4.4 价格层的交付物
`research/price_layer/`：回撤情景表、估值地板、收复比例三个描述性模块 + 止跌确认与买入分批两个执行规则评价脚本；契约字段 P1/P2/W/B；每个数字带 n 与 evidence。

## 8. 风险与应对
| 风险 | 应对 |

## 9. 成功标准（不是"准确率"口号）
1. 前瞻日志：到 2028-H1 累计 ≥50 个独立报警事件，A1/A2 相对随机对照显著（≥4 市场）。
2. 价格层：止跌确认后 120 日不创新低比例显著高于随机；分批买入组合 MDD 低于一次性买入。
3. 产品：每张卡的每个数字都能点开看到证据等级、n 与来源；没有证据的地方写"无证据"。
4. 治理：三份文献综述与预登记草案中的"不做"清单未被突破。
