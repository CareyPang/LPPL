# FCO 原站 vs 临界点 2.0：差距分析（2026-10-28）

依据：用户提供的 `FCO_PUBLIC_METHODS_REVIEW_2026-10-28.md`、交接包 v3（HANDOFF / FULL_FUNCTION_PLAN F01–F13 + S01–S14 / API_FIELD_REFERENCE 官方 OpenAPI 18 路径 22 模型 / ALGORITHM_RECONSTRUCTION_PLAN），对照本仓库契约（`research/eval/export_contract.py`）、`docs/fco_indicator_audit.md`、`docs/dev_freeze.md`。
证据用语沿用交接包：**原站确认**（OpenAPI 字段 / 画面演示）、**公开方法**（论文）、**本项目设计**。

## 0. 总判断
- 公开方法综述的结论与本项目一致：公开论文 + 代码足以做出同类工具，**不足以**保证与原站逐点一致，更不能继承其宣称的 89% 成功率。本项目已经比综述建议多走一步——做了三段验证并得到负面/脆弱结果，这是原站公开材料里没有的东西。
- 原站是**多资产工作台**（1,087 资产目录、排行、汇总、Movie、情景多选）；本项目是**单市场 A 股六指数 + 严格证据链**。差距主要在工作台功能广度与资产覆盖，不在单资产分析深度。
- "超越"可以明确落在三处：① 每个数字带证据等级与三段验证记录（原站无）；② 前瞻日志哈希封存 + 季度复盘（原站 FBE 2009–2010 后公开记录停止）；③ 失败状态显式化（无合格拟合≠0，原站 S04 也只是允许空行）。

## 2. 工作台层：原站有、本项目没有（全部是"本项目设计 = 工程"，不涉及证据）
- F01 泡沫排行、F02 汇总、F03 资产目录、F04 高级资产列表：需要**多资产批量扫描**。A 股可行范围：六指数 + 行业指数 + 沪深 300 成分（已有 PIT 成分与 100 只横截面扫描经验）。注意开发段已证明**个股 LPPLS 横截面排名无预测信息**——排行可以做，但必须标"描述性，开发段无预测信息"。
- F06 六尺度选择器、F07 权重滑块、F11 情景多选、F12 报告/教育、F13 主题设置：纯前端。**已补：F03 资产目录（workbench「资产目录」页，`research/pipeline/catalog.py` → `catalog.json`，316 标的：代码/名称/交易所/板块/所属指数，非 PIT）；F06 六尺度选择器 + 正/负方向切换（dashboard 置信度卡，`?scale=&dir=` 可分享；负方向只在含 `negative_bubble.confidence_standard` 的契约显示，日更契约显示「未计算」）；F11 情景多选（图例复选框隐藏/显示情景曲线、t_c 线并淡化情景卡）；F07 Combo 权重滑块（p 对数滑块 0.1–10 + 过滤集选择，前端按公开幂平均公式从六档置信度重算，与契约 p=0.1/1/10 参考值并列）；F12 教育页（`web/guide.html` 渲染 `docs/user_guide.md`，`report.py` 同步到 `mock/guide.md`）；F10 Movie 双面板独立日期（A 播放 / B 固定对照）；F13 主题（`web/theme.js`，深/浅色，localStorage 记忆，覆盖 dashboard / workbench / stock / guide；index / mobile 另有配色体系未纳入）。**
- 资产主数据（唯一 ID、交易所、币种、日历）：`astock-lite` 已有交易日历与成分接口；需建资产表。
- 算力：原站六尺度 × 1,087 资产每日；我们 1 指数 1 as-of 约 1 分钟（145 窗×10 起点），六尺度后约 2.5 分钟/资产/日 → 50 资产日更约 2 小时单机，可接受；历史回算须按 as-of 增量。

## 3. 本项目有、原站没有（即"超越"的实际内容）
1. **三段验证与证据等级**：每个字段带 dev/cal/test 结论（`docs/evidence_table.md` 收尾中）；原站只有 FBE 案例累积与 89% 口径不明的宣传。
2. **前瞻日志**：每日契约 JSON SHA-256 封存，季度按同一判据复盘——相当于把 FBE 做成常态。
3. **随机对照与多重比较**：A1/A2 对循环平移随机报警、Holm、LOCO、按年——综述第 4 节提到的 Grobys 2026 尺寸失真问题，本项目的随机对照口径（保持序列结构的循环平移）正是对应做法。
4. **失败状态显式**：no_qualified_fit / 数据源降级版本号 / 空结果不当作 0。
5. **PIT 成分与冻结数据版本**：原站用当前行情回算历史（F08 验收也承认）；本项目冻结 `data/frozen/v20261024` 并记录 data_version。
6. **用户可读规则**：阈值分级 + 分批规则 + 失效条件（`docs/user_guide.md`），原站不给操作建议。

## 4. 与"原版没有不加"原则的关系
- 本文第 1–2 节全部是原站**有**的功能，补齐不违反原则。
- 第 3 节是验证/工程层，不是新预测模块。
- 唯一需要用户裁决的：bubbleScore 研究版、tc 密度带宽、Combo 六尺度缺值规则——都是"原站有但公式未公开"，实现时必须命名为研究版并可替换。

## 5. 建议顺序（不改模型、不改评价规则）
1. 契约扩展：六尺度（新增三档标无证据）、负向置信度正式字段、tc 密度、情景曲线段、tcOffset。扫描成本：窗口集合从 145 扩到约 300，日更 1 指数约 2.5 分钟。
2. 前端：价格+指标交互图、情景多曲线叠加、tc 密度/数量双面板 + Movie 控件、六尺度/方向选择器、Combo 滑块。
3. 多资产：行业指数 + 沪深 300 成分日更与排行/汇总/高级列表（标描述性）。
4. 报告：由快照自动生成研究报告（含数据版本、参数、证据等级）。
5. 等会员证据到位后做"与原站一致性"成绩单（同日期同资产的指标误差），与"独立预测价值"成绩单（本项目已有）分开。

## 6. 不做
- 不宣称任何成功率；不把 ScenarioDto.probability 当崩盘概率；不把 tc 密度当校准预测；不把个股排行当选股信号；不在本轮改动评价判据。
