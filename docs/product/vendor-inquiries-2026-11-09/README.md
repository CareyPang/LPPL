## 建议的比较次序

以下为方案建议，不代表已采购或已批准采集：

1. 先明确现有免费/公开来源的适用条件。只要足以覆盖所选用途、字段和运行要求，同样可以采用；保留 a-stock-data 的接口思路。
2. 若公开网站用途不明确，询问免费、轻量、低频研究或单独展示授权，先比较最小可用权益，不默认搭配完整终端。
3. 若确有缺口，再比较正式 API 或混合方案，仅采购无法通过合适来源解决的部分；分别计算历史回补与持续成本。
4. 在获准范围内用相邻两日有限样本验证完整池、版本和晋级。两个样本日不能证明长期稳定或全历史完整；持续运行另设验收。
5. 取得字段、用途、额度和报价后再作决定。此次不发送、不购买、不申请试用、不改变来源开关、不部署、不合并、不发布。
