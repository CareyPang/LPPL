## 1. 产品决策（PROPOSED）

用户面向普通投资者，重点关注1–6个月上涨中的阶段性顶部区间，同时保留局部高点观察；至少提前5个交易日、较窄时间窗是研究目标，**不是已建立能力**。不以之后下跌10%作为本轮成功定义，不对跌幅保证。价格层与抄底研究另行验证。

信息产品解决三件事：今天市场怎样、与我的股票有什么关系、当时知道什么及后来发生什么。复盘功能不改变LPPL输入；不得把市场情绪、ETF份额或题材热度自动喂入模型，也不接入完整AI交易流程。

一级入口建议：我的工作站、市场复盘、ETF观察、筛选与提醒、全球与日历。海洋叙事保留在首页；工作区采用浅色、稳定的图表和数据布局，动效用于定位与反馈。

## 2. 开盘啦：借鉴工作流而非声称复刻内部算法

**VERIFIED（官方页面）**：现行复盘教程按盘面、题材/梯队、个股、区间统计、次日核验组织信息；题材库提供搜索、排序和题材分支。[复盘教程](https://www.kaipanla.com/article/42661)、[题材库教程](https://www.kaipanla.com/article/38490)。这些介绍不公开全部热度/强度算法，也不证明策略胜率。

| 功能 | 数据前提 | 建议实现与验收边界 |
|---|---|---|
| 市场概览 | 完整证券主表、收盘/前收、成交额、交易状态 | 涨跌平与未交易分别计数；范围、有效覆盖率可见 |
| 连板梯队 | 连续交易日收盘封板池 | 连续N板与N天M板分开；层级可展开 |
| 分层晋级 | T−1封板成员、T封板与可交易状态 | 固定前日成员，展示分子分母、停牌与未知数 |
| 炸板率 | 当日触板、最终封板集合 | 按股票去重；最终回封者不计最终炸板，次数另列 |
| 题材与原因 | 版本化成员、供应商归因、相关公告 | 来源归因与事实事件分栏；未知不由AI补造 |
| 行业/概念/地域 | 三套历史分类和同一截面 | 切换分类；概念多重归属不可直接加总当市场份额 |
| 龙虎榜 | 交易所披露、统计期/原因/席位 | 单日/多日分开，去除重复原因累加；席位不等于最终投资人 |
| 资金历史分位 | 同供应商及口径的足够历史 | 标为大单等分类估计；给有效样本数和统计区间 |
| 盘面时间线 | 源带时间的事件或授权细粒度行情 | 六时点只能表示采样差异，不能推定真实首次触板时刻 |
| 历史复盘 | 原始封存、修订及可得时间 | 默认当时已知；补录/修订另层显示 |

建议统计口径：

- 最终炸板率 = 当日触板但收盘未封住的唯一股票数 / 当日触板唯一股票数。
- 昨日涨停晋级率 = 昨日封板且今日封板数 / 昨日封板且今日可交易数。
- 昨涨停表现固定T−1成员，报告T收益均值、中位数、上涨占比及缺失；停牌/除权处理策略需固定。
- 不用统一9.8%硬阈值判全部股票涨停；按市场、板块、特殊状态及当日限价/规则版本判断。完整池缺失时不生成假精确百分比。
- 热度先使用涨停数、上涨占比、成交额份额和排名变化；自定义综合分需公开公式与版本，不标为预测概率。

## 3. 候选来源目录与接入条件

下面“有入口”只表示公开源码/资料存在。未在本轮请求真实行情端点，实时可达、完整性、历史深度及本项目使用条件须独立验收。

| 数据集 | 候选来源 | 关键补齐 |
|---|---|---|
| 行情/日线 | a-stock-data腾讯等适配思路 | 日期、成交量单位、复权、证券身份；原始与因子分离 |
| 四池 | 东财getTopicZTPool/getTopicZBPool/getTopicDTPool/getYesterdayZTPool | 分页/总数/日期/市场范围；失败不能等同空池 |
| 原因/历史事件归因 | 同花顺limit_up_pool与按日事件入口 | 第一页不是完整池；归因文字的发布时间不同于首次封板时刻 |
| 公告/财报/股东/解禁 | 巨潮、交易所、公司原文 | 分页、发布日期、报告期、修订、文件定位 |
| 龙虎榜 | 沪深交易所披露 | 原始原因/统计区间/席位身份；不冒充全市场机构交易 |
| 板块/资金 | 对应供应商分类统计 | 历史分类和方法版本；不能用今日成员回填历史 |
| ETF | 交易所、管理人、原始报告 | 份额、NAV、申赎规则、持有人证据分层 |

[a-stock-data](https://github.com/simonlin1212/a-stock-data)可以提供解析/接口思路；[Vibe-Research](https://github.com/simonlin1212/Vibe-Research)适合参考数据目录和证据结构；[TradingAgents-astock](https://github.com/simonlin1212/TradingAgents-astock)限解析思路，不导入其完整交易决策流程。上游代码许可不覆盖所有数据用途。本轮不声称完整审核了上述三个项目或取得其上游数据授权。

已核对的具体一般条款：[东财法律声明](https://about.eastmoney.com/home/legal)、[上交所法律声明](https://www.sse.com.cn/home/legal/)。它们有内容/行情使用范围限制；本项目应逐数据集登记自动访问、留存、派生、公开/收费展示、配额和证据。未知状态不等于一律禁止，也不能当已许可；可适用的免费开放条款不要求一定采购。

来源登记至少包含 `source_id/url, code_license, data_use_basis, allowed_scope, quota_basis, coverage, history_depth, published_at_semantics, parser_version, network_test_environment`。目标腾讯云地域、大陆实际运营商网络、浏览器路径分别测；网页工具成功不是大陆网络验收。

## 4. ETF：四类事实分别展示

推荐标题：**宽基ETF资金与机构披露**。不绘制缺乏身份数据的“每日国家队净买入”。

| 层 | 首选来源与可得字段 | 证据边界 |
|---|---|---|
| 日终份额 | [上交所ETF规模](https://www.sse.com.cn/market/funddata/volumn/etfvolumn/)、[深交所基金平台](https://fund.szse.cn/) | SSE明确清算后；深市历史接口、范围和可达性需实测；份额没有买方身份 |
| NAV/PCF | 基金管理人产品公告、[交易所基金档案示例](https://www.sse.com.cn/assortment/fund/list/etfinfo/basic/index.shtml?FUNDID=510300) | NAV属哪个日期要明确；PCF是篮子/规则，不是实际申购记录或持有人名单 |
| 具名机构持仓 | 管理人/交易所原始PDF或结构化披露 | period_end与published_at分列，逐报告判断具名字段；未披露不等于0 |
| 官方事件 | 机构原始公告或明确标注的权威原文转载 | 未给代码/金额不可补造；事件不是每日交易明细 |

单位统一后，建议估算 `ΔS × 同日NAV`；缺NAV时按未复权收盘价得到的代理估算单列，禁止静默混用。估算反映全ETF份额变化，不识别交易人，也不是银行现金流实录；实物申赎、拆分折算、份额调整需先处理。

前后份额非相邻交易日时，标from_date/to_date/gap_sessions的期间变化。合计显示共同日期、valid/expected；不完整YTD标观察起点和覆盖，不能叫全年全量累计。机构报告期末份额乘今日价格仅是假设持仓不变的参考估值。

[证监会2026年准则说明](https://www.csrc.gov.cn/csrc/c100028/c7619936/content.shtml)确认定期报告格式已修订；不据此声称所有基金取消具名披露，也不保证每份都具备。解析状态分 `disclosed/not_disclosed/not_found/parse_failed`。

技术验收建议样本：510300/510310/510330/159919，覆盖沪深，先两个相邻真实交易日；不是完整国家队池。观察池需保存纳入依据、有效日期及原始报告；不要用当前列表回放历史。

现有ETF代码的报告时间、缺失日差值、部分合计和同日覆盖问题见[审查B02–B04](../research/2026-11-13-cache-adversarial-review.md)。固定指数映射也需逐只核对，不能把全指代理写成ETF真实跟踪指数。

## 5. TradingView：图表库与网站服务分开

**VERIFIED（官方资料）**：Lightweight Charts为Apache 2.0图表库，数据自备且应保留NOTICE/署名；Advanced Charts自备Datafeed且有申请/使用条件；Widgets自带其数据但不是可导出的自有数据API。[库比较](https://www.tradingview.com/free-charting-libraries/)、[Lightweight Charts说明](https://github.com/tradingview/lightweight-charts)、[Widgets数据边界](https://www.tradingview.com/widget-docs/faq/data/)

Advanced Charts不包含官网Alerts、Bar Replay等服务。[官方FAQ](https://www.tradingview.com/charting-library-docs/latest/getting_started/Frequently-Asked-Questions/) 因此建议先用Lightweight Charts，回放、筛选、提醒由本项目独立实现；购买个人会员不等于行情转供或网站集成许可。

| 功能 | 第一版 | 后续 |
|---|---|---|
| 主图 | 日/周K、成交量、缩放、事件和LPPL区间 | 分钟线、多图、绘图保存 |
| 筛选 | 同一截面上的价格、成交额、市值、行业/题材 | 财务条件、保存规则、定时结果快照 |
| 热力图 | 面积/颜色/周期可见 | 历史快照比较，成员版本固定 |
| 回放 | 明确日期游标、逐交易日推进 | 多资产同步、笔记；禁止未来资料泄漏 |
| 提醒 | 更新/价格/既有模型状态通知 | 服务端关闭页面仍可运行、去重和投递记录 |
| 日历 | 公告、解禁、财报和官方宏观发布 | 自选关注；无许可共识预测不伪造“市场预期” |

## 6. 面板与性能

桌面复盘：顶部日期/回放模式/完整度；一行核心指标；热力图与题材排行；梯队与个股抽屉；ETF摘要与观察清单。点击题材联动列表和梯队，进入股票保留回放时刻。排序和公式可追溯，刷新不打乱用户手动排序。

个股：主图约2/3＋按需侧栏；下方行情/公告/模型提醒与修订时间轴。行情、已有结果、信息独立加载，某源失败不清空整页。ETF单页把每日估算和持有人报告分成页签，避免叠为同一机构资金曲线。

390px：主图全宽、侧栏转标签/抽屉、梯队分组列表、热力图默认板块级；不把三列桌面硬压缩。红绿表达涨跌，暖白/浅灰蓝底，金色选中；证据/新鲜度用文字和图标，不只用颜色。

数据状态和证据类别是两个维度：最新/过期/部分/失败，与官方披露/供应商估计/派生统计/历史重放/真实发布分别显示。页面美观不代表模型有效。

后台统一采集、增量快照、版本/ETag检查、后台标签暂停轮询、图表与长表按需渲染。日终封存后不必高频拉全量；ETF按源清算后发布时间更新。六时点是采样计划，不是供应商额度或实时逐笔承诺。冷暖性能分开测，详情见缓存方案。

## 7. 后续全球范围与验收边界

P2先做Treasury/NY Fed/BIS/ECB/BLS/EIA的源目录、频率/修订和显示契约；VIX、DXY、黄金、原油、人民币汇率逐源核对数据及展示条件。此文没有重新全量审核这些接口，标为NOT_INSPECTED，不据名称承诺实时免费接入。

P3新闻原则上只存获准的标题/来源/时间/链接/hash；不能认为“只存标题”自动免除所有使用条件。预测市场按用户既定约束取得适用书面许可后，才启用约六小时异步刷新；明确Polymarket/Kalshi隐含概率、时点/流动性/stale，不称官方FedWatch，不进入LPPL。

两日真实样本只证明一次晋级闭环；要另外覆盖节假日、停牌、缺页、修订及不同证券制度。长期分位要显示实际样本量；题材成员和报告可得时间不足时，不开放严格历史结论。

本轮没有验证真实大陆网络、生产数据许可、全面历史覆盖、真实手机、冷暖延迟和预测效果。具体任务与T01–T18验收见[Devin交接](2026-11-13-devin-handoff.md)。
