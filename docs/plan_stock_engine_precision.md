## 1. 阶段计划（每阶段一个 PR，PR 上留中文评论；每阶段有"淘汰即停"的门）

### Phase 0 把"精准"变成四个数（1 PR，约 2 天，纯测量不改模型）
- 定义并在开发段 + 前瞻日志上测基线：
  - **T-top**：报警日→PS 顶的提前量分布（中位/分位）、命中率、虚警率（沿用 A1/A2/lead_med）；
  - **P-top（逃顶价格）**：报警日收盘 / 顶价 − 1（"卖早了多少"）与 顶后 126 日最低价 / 报警日收盘 − 1（"躲掉多少"）的分布；
  - **T-bottom**：底部报警→PS 底提前量；**P-bottom**：报警日收盘 / 谷价 − 1。
  - 分指数、分尺度、分泡沫涨幅桶；指数 + 已有 100 只成分股样本。
- 产出 `reports/precision_baseline.md` + 四个指标进前瞻日志 schema（只记录）。门：无（这是尺子）。

### Phase 1 时间层拟合精度（2–3 PR，约 1–2 周 + 算力）
- **1a 优化器与起点**（合成 + 开发段）：`tcgrid_lm` vs 多起点 CMA-ES、Lagrange 正则化 t₁* 选择（Demos–Sornette 2017）、`MIN_DT` 与窗内 t_c 处理；指标 |Δt_c|/|Δm|/|Δω| 回收误差、撞边界率、SSE 配对对照（沿用 `_g2` 方法）。门：合成 |Δt_c| 中位改善 ≥20% 且开发段 SSE 不变差。
- **1b 多尺度聚合与 t_c 分位**：现在 Confidence = 合格窗口比例、t_c 分位 = 窗口等权。试 R²/残差加权、t₁* 加权、t_c 聚类（`tc_cluster_dev` 已有探索）；指标 = 分位窗覆盖率 vs 同宽朴素窗（§19.1 口径）。门：开发段覆盖率显著高于朴素窗（块 bootstrap 90% 下界 >0），否则记负面。
- **1c 合格判据换零对照**（需登记 §22）：把 `original_standard` 评价级的循环平移零分布下放到窗口级——窗口合格 = 过 box/STANDARD **且** 其拟合质量优于同窗循环平移样本的 95% 分位。这是 Q2 失败后唯一没试过且不依赖 PL/AR(1) 零模型的路。门：合成六类零假设 FPR 上界 ≤0.10 且合成泡沫检出 ≥0.30（沿用 §21.1 第 3 条格式）；开发段 A1 > A1_null 且 p_med ≤0.05 于 ≥4/7 指数。

### Phase 2 逃顶价格（1–2 PR，约 1 周）
- 目标变量：报警日起到 PS 顶的**剩余涨幅**与到顶的剩余天数（联合）。
- 两条候选路，各自登记、各自过门：
  - **2a LPPLS 理论上界 A**：对数价格在 t_c 处的渐近值 A（JLS 2000）作为"理论顶价"，测 OOS 偏差分布 exp(A)/P_top，若偏差稳定可作价格带（先在合成上验证 A 的回收精度，再开发段）；
  - **2b 条件分位**：剩余涨幅 ~ 分位回归(run-up、m、ω、B 幅度、t_c 距离、尺度一致性)，τ∈{0.2,0.5,0.8}，逐年扩展窗，pinball 比值 vs 无条件（沿用 Q-DD2 方法与门槛：τ=0.5 比值 90% 上界 <1）。
- 产品层：通过项以"报警后到顶的剩余涨幅区间"显示，不给目标价（`drawdown_price.value` 仍 null）。

### Phase 3 抄底时间与价格（2–3 PR，约 2 周）
- **3a 先诊断为什么 LPPLS 抄底差**（1 PR，只分析）：按 PS 底类型分层——恐慌 V 底（崩盘后 Omori 余震）vs 阴跌底（负泡沫，对数周期减速）。文献上负泡沫 LPPLS 只适用后者。分层报 A1/A2；若恐慌底占 A 股多数且 LPPLS 在该层 A1≈零分布，则**正式放弃 LPPLS 抄底**，记负面，不再投算力。
- **3b 底部时间**：在 B1→B2→B3 保留链上加候选：Omori 余震衰减率 p 的稳定性、新低比例广度、成交额枯竭持续天数、体制概率（H3 的 p_hi 作特征而非分组）；CPCV ΔBrier，主链门不变。
- **3c 底部价格**：谷价相对报警价的条件分位（同 2b 方法）；估值地板带作对照。门同 Q-DD2。
- 产品：抄底只给"底部时间窗概率 + 价格区间"，不给点位。

## 4. 执行结果（2026-11-12，PR #54；总表见 `reports/precision_program_summary.md`）
- Phase 0 基线：顶部时间信号几乎全部来自 2007/08、2014/15；剔除后命中≈随机（0.04–0.14）。t_c 聚类不优于随机。成分股 LPPLS 抄底低于零对照。→ 后续主指标一律报"剔两轮大顶"。
- Phase 1a：优化器不是瓶颈（窗外 t_c 六法一致）；`tcgrid_lm` 窗内低 m 漏找 23%，`de_lbfgsb` 100%——可修，须 §20 登记 `_g3`。
- Phase 1b：五种 t_c 分位窗聚合全部不优于朴素窗 → 负面。
- Phase 1c：§22 Q3 草案（PR #55）待确认，未执行。
- Phase 2：LPPLS 渐近值 A 与剩余涨幅无关；条件分位比值 ≥1 → 负面；逃顶价格无模型化路径。
- Phase 3a：恐慌底占多数且 LPPLS 召回≈0；阴跌底召回显著高于零对照 → 不整体放弃，只对阴跌型给信号。
- Phase 3b：阴跌/恐慌代理、新低广度、Omori 稳定性、−lnP 置信度进底部保留链 CPCV ΔBrier 均≈0 → 保留链不变。3c 由 Q-DD2 负面覆盖。
- Phase 4：`forward_log check/precision` + 周检工作流 + 注入测试全部通过；**发现前瞻日志自 2026-10-30 停更（无定时 seal）**。
