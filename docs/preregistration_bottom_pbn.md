## 3. 候选（固定，共 3 个结构 10 个配置）

记 `Vp = clip((pbn_pct − 0.60) / 0.30, 0, 1)`（只看破净率分位），`Vm = clip((max(erp_pct, pbn_pct) − 0.60) / 0.30, 0, 1)`（两项取高），`D20` 同 V2。

| 代号 | 定义 | 可选参数 |
|---|---|---|
| B0 | 现行底分 V2（基线） | 无 |
| P1 | `Vp ≥ v_min` 才计分；分数 = 100·(0.6·Vp + 0.4·D20) | `v_min ∈ {0.3, 0.7}`，`τ ∈ {50, 60}` |
| P2 | `Vm ≥ v_min` 才计分；分数 = 100·(0.6·Vm + 0.4·D20) | `v_min ∈ {0.3, 0.7}`，`τ ∈ {50, 60}` |
| P3 | 分数 = 100·Vp（只看破净率，不看回撤深度） | `τ ∈ {70, 90}`（即破净率分位 ≥0.81 / ≥0.87） |

缺 `pbn_pct`（P2 为两项都缺）的周记 0 分。不追加其他候选。

## 4. 开发段选择规则

1. 合格：覆盖率 10%–40%，开发段独立事件 ≥ 30。
2. 稳健：留一指数 L50 全部 > 0。
3. 合格且稳健的配置里取 L50 最大者；差距 < 0.02 时取更简单的结构（P3 > P1 > P2）。
4. 若没有配置满足 1、2，或最优配置 L50 不高于 B0 开发段 L50 + 0.03：**结论“无更优候选”**，归档，线上继续用 B0。
