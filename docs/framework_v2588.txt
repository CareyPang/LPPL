## 二、L0：数据治理层

这是整个框架的基础，任何上层拟合不得绕开。

### 2.1 Point-in-Time 原则

每个输入记录需要尽可能保留：

```
asset_id
venue
source
source_event_time
publication_time
first_available_at
ingested_at
vintage
revision_id
raw_content_hash
normalized_content_hash
adjustment_rule
trading_calendar_version
as_of
data_quality_status
```

核心约束为：

\\[ \mathcal D_t = \\{x_i:\operatorname{available\\\_at}(x_i)\le t\\}. \\]

在历史时点 \\(t\\)，只能使用该时点实际已经可以获得的信息。

后来修订的财务数据、宏观数据、股票复权信息和指数成分不能直接回填历史预测。

### 2.2 原始价格与复权价格

股票必须明确区分：

- 原始 OHLCV。
- 前复权或后复权序列。
- 分红、送转、拆并股、配股等公司行动。
- 供应商使用的调整因子及其历史可用性。

同一次拟合必须在一致的价格坐标中完成。历史指数收盘、ETF收盘、期货结算、盘中重建值也不能任意混用。

### 2.3 数据有效性与停止规则

出现下列问题时，需要保存可审计的质量状态：

- 历史样本长度不足。
- 必需的时间戳缺失。
- 交易日历不能对应。
- 复权或原始价格口径不一致。
- 数据存在无法解释的断点。
- 证券停牌、退市或进入特殊交易制度。
- 数据发布时点不符合 PIT 要求。

不允许为了让 LPPLS 拟合成功而自动缩短窗口、静默填补历史或选择最漂亮的一段。

## 三、Time Engine：V4.8-R2 LPPLS

这是原长期框架的时间预测核心。

### 3.1 LPPLS 数学模型

对于正价格资产，定义

\\[ y(t)=\log P_t. \\]

LPPLS 模型为

\\[ \boxed{ y(t)=A+B(t_c-t)^m +C_1(t_c-t)^m\cos[\omega\log(t_c-t)] +C_2(t_c-t)^m\sin[\omega\log(t_c-t)]. } \\]

其中 \\(t\<t_c\\)。

参数分为两组：

\\[ \theta=(t_c,m,\omega), \\]

\\[ \beta=(A,B,C_1,C_2). \\]

含义如下：

| 参数            | 解释                |
| ------------- | ----------------- |
| \\(t_c\\)     | LPPLS 模型的临界时间     |
| \\(m\\)       | 幂律指数              |
| \\(\omega\\)  | 对数周期角频率           |
| \\(A\\)       | 临界时间附近对数价格趋势的模型截距 |
| \\(B\\)       | 幂律趋势项系数           |
| \\(C_1,C_2\\) | 对数周期振荡系数          |

此模型与 Johansen–Ledoit–Sornette 的泡沫临界点模型，以及 Filimonov–Sornette 的低维稳定校准方案有关。

注意：\\(A\\)、\\(e^A\\)、\\(e^{-A}\\) 不得被直接当作未来目标价。

### 3.2 Top 和 Bottom

历史默认采用统一的转换坐标：

\\[ y\_{\rm top}(t)=\log P_t, \qquad y\_{\rm bottom}(t)=-\log P_t. \\]

顶部和底部都可以在变换后的坐标中使用相同的数学拟合程序，但方向标签、形态门和真实事件定义必须分别处理。

对于固定 \\(\theta\\)、同一个设计矩阵 \\(X\_\theta\\) 和无约束线性最小二乘：

\\[ \hat\beta(-y)=-\hat\beta(y), \\]

\\[ \operatorname{SSE}(\theta;-y) = \operatorname{SSE}(\theta;y). \\]

所以同一价格序列上的 Top/Bottom 无约束拟合并不是两份独立证据。

### 3.3 条件线性消元

给定 \\(\theta=(t_c,m,\omega)\\)，构造设计矩阵

\\[ X\_\theta= \begin{bmatrix} 1&\Delta_1^m&\Delta_1^m\cos(\omega\log\Delta_1)&\Delta_1^m\sin(\omega\log\Delta_1)\\\ \vdots&\vdots&\vdots&\vdots\\\ 1&\Delta_n^m&\Delta_n^m\cos(\omega\log\Delta_n)&\Delta_n^m\sin(\omega\log\Delta_n) \end{bmatrix}, \\]

其中

\\[ \Delta_i=t_c-t_i>0. \\]

使用稳定最小二乘求

\\[ \hat\beta(\theta) = \arg\min\_{\beta} \\|y-X\_\theta\beta\\|\_2^2, \\]

再定义

\\[ Q(\theta)= \\|y-X\_\theta\hat\beta(\theta)\\|\_2^2. \\]

这把原来的七参数优化转为三个非线性参数的优化。

数值实现应优先使用 QR/SVD 或可靠的 `lstsq` 路线，避免显式求 \\((X^\top X)^{-1}\\)。

### 3.4 历史优化器规范

旧正式工程基线要求：

1. SciPy 官方 `differential_evolution`。
2. 多 seed 完整优化。
3. 多历史窗口。
4. 多个 as-of 冻结时点。
5. DE 正式结束后，再独立使用 L-BFGS-B 精修。
6. 保存各阶段结果、终止原因、预算和局部候选。
7. 不发布不完整运行中的 partial best 作为已验证结果。

历史禁止以轻量自制 DE、固定 \\(t_c\\) 网格、低 seed 或仅成功的部分窗口冒充完整生产算法。

但最新研究需要区分：

- 科学基线复现要求：比较旧 LPPLS 时，必须忠实运行被冻结的旧方法。
- 新算法挑战者要求：允许研究 Filimonov–Sornette 的低维校准及其他优化方案，只要事前冻结规则、对照数值误差、预算和样本外效果。

因此，“永远只能使用 DE”不应被扩张为数学定理。

### 3.5 历史形态过滤条件

旧规范采用：

\\[ 0.1\<m<0.9, \\]

\\[ 6<\omega<13, \\]

\\[ B<0, \\]

\\[ D= \frac{m|B|} {\omega\sqrt{C_1^2+C_2^2}} \ge1, \\]

\\[ N\_{\mathrm{osc}}\ge2.5, \qquad R^2\ge0.90. \\]

这里必须严格区分：

- 参数搜索域；
- LPPLS 形态过滤域；
- 数值优化完成条件；
- 统计识别条件；
- 真实事件预测准确率。

上述历史门槛不是已证明跨 A 股有效的最优预测阈值。

特别是 \\(R^2\ge0.90\\) 只能作为历史拟合形态描述，不能作为真实未来日期准确性的充分条件。

如果 \\(C_1=C_2=0\\)，\\(\omega\\) 不可识别，但 \\(t_c\\) 是否仍可由纯幂律识别，需要依赖 \\(B,m\\)、样本跨度、噪声等条件具体判断。

| 尺度     | 历史有效观测长度                                                              |
| ------ | --------------------------------------------------------------------- |
| SHORT  | 60, 80, 100, 120, 150, 180, 200, 225                                  |
| MEDIUM | 250, 300, 350, 400, 450, 500, 550, 600, 650, 700                      |
| LONG   | 750, 800, 850, 900, 950, 1000, 1100, 1250, 1500, 1750, 2000, 2250     |
| ULTRA  | 2500, 3000, 3500, 4000, 4500, 5000, 5500, 6000, 6500, 7000，加符合条件的完整历史 |

合计：

\\[ 8+10+12+10=40 \\]

个固定窗口，另有一个符合数据长度条件的 `FULL_HISTORY` 逻辑窗口。

每个 as-of、方向均须保留逻辑清单。不能因两个窗口产生相似结果，就删除其存在记录或重复计算证据。

### 4.1 未来临界时间搜索

历史主时域：

\\[ 0\<t_c-t\_{\rm asof}\le90 \\]

个有效交易观测步，并要求实际使用有来源的自适应上限函数。

另有：

\\[ 120,\quad180,\quad252 \\]

作为独立的搜索边界诊断。

这三个数字不是额外的正式未来风险预测期限，也不能与40个回看长度混淆。

### 4.2 振荡可检出性

若历史窗口有 \\(N\\) 个等间隔交易观测，最后观测时刻为 \\(t_2\\)，令

\\[ d=t_c-t_2, \\]

则窗口内的模型对数周期数为

\\[ N\_{\rm osc} = \frac{\omega}{2\pi} \log\left(\frac{d+N-1}{d}\right). \\]

要求 \\(N\_{\rm osc}\ge2.5\\)，推出

\\[ \boxed{ d\le \frac{N-1} {\exp(5\pi/\omega)-1}. } \\]

当 \\(\omega=13\\)：

- 60观测窗口，\\(d\\) 上界约25.13步；
- 100观测窗口，\\(d\\) 上界约42.17步。

因此某个短窗口无法识别未来90日的临界时间，不代表未来90日没有风险。

必须同时报告产品完整覆盖率和LPPLS期限合资格覆盖率。

## 五、\\(t_c\\) 不确定性与时间簇

历史框架不仅输出单一 \\(\hat t_c\\)，还研究以下量：

- 非线性目标函数 \\(Q(\theta)\\)；
- 固定 \\(t_c\\) 后对其他 nuisance 参数重新优化的 profile cost；
- 多窗口候选簇；
- 多 seed 收敛到的不同盆地；
- as-of 推进时的簇漂移；
- 依赖保留的 block bootstrap；
- 不同回看长度下的参数稳定性；
- 临界时间边界堆积；
- 可能的多峰与弱识别。

对固定临界时间 \\(c\\)，真正的代价剖面应为

\\[ Q\_{\rm prof}(c) = \min\_{m,\omega} Q(c,m,\omega). \\]

不能只取某个固定 \\((m,\omega)\\) 网格点作为 profile 最小值。

还须区分四件事：

1. Profile cost 是优化代价。
2. 置信区间需要误差模型、统计近似及覆盖验证。
3. Posterior 需要明确似然与先验。
4. 真实事件概率必须经过独立的历史事件校准。

尤其不能把多个成功 seed、窗口投票或归一化 profile 权重直接称为“顶部发生概率70%”。

### 5.1 Time 的历史 T0—T4 证据等级

总体上可以按以下语义理解：

| 层级 | 含义                |
| -- | ----------------- |
| T0 | 不合资格、数据或结构证据不足    |
| T1 | 存在可研究的模型拟合形态      |
| T2 | 符合冻结条件的临界结构候选     |
| T3 | 参数及时间结构具有统计识别支持   |
| T4 | 真实事件预测已经完成样本外概率校准 |

T1/T2/T3不能冒充T4。

真实市场的窄日期置信输出，必须考虑窗口相关、优化选择和不同市场状态下的识别误差。

## 六、Price Engine：PPE-U2-R5.1 完整数学主线

这是框架最重要的第二分支。

它不是使用 LPPLS 的 \\(A\\) 参数推算目标价格，而是研究：

价格结构在哪里、价格状态如何变化、上下目标哪个先被触及、什么时候触及，以及在期限内完全不触及的概率。

### 6.1 历史价格几何

对正价格资产定义

\\[ x_i=\log\widetilde P_i, \\]

其中 \\(\widetilde P_i\\) 是经过数据口径一致性审查的价格代表值。

优先使用口径一致的 adjusted VWAP；若成交额、成交量或复权单位无法核验，可退回一致尺度的

\\[ \mathrm{HLC3}\_i=\frac{H_i+L_i+C_i}{3}. \\]

不能把 raw VWAP 与复权 OHLC 混合。

历史 Range-Aware KDE：

\\[ r_i^2=\frac{(\log H_i-\log L_i)^2}{12}, \\]

\\[ \sigma_i^2=h^2+\kappa^2r_i^2, \\]

\\[ \boxed{ \rho_s(x)= \frac{1}{Z_s} \sum_i\frac{w_i}{\sigma_i} \varphi\left(\frac{x-x_i}{\sigma_i}\right). } \\]

其中：

- \\(h\\)：核带宽；
- \\(\kappa\\)：日内价格范围影响因子；
- \\(w_i\\)：时间、成交量与数据质量权重；
- \\(Z_s\\)：归一化常数；
- \\(\varphi\\)：标准正态核。

历史设置涉及时间半衰期、成交量平方根加权、多带宽敏感性和 blocked bandwidth CV。

这些是候选设计，不是已证明普适的最优参数。

### 6.2 价格井与自由能

定义经验自由能：

\\[ F\_\rho(x)=-\log\rho(x). \\]

在这一表示下：

- 密度局部最大值对应经验自由能局部最小值；
- 价格井用来描述历史价格活动的集中区域；
- basin mass 描述经验密度分布的质量；
- persistence 描述结构对窗口、带宽、bootstrap 和 as-of 变化的稳定性。

但以下推论被禁止：

\\[ \text{历史高密度} \not\Rightarrow \text{未来必然支撑}, \\]

\\[ \text{经验自由能井} \not\Rightarrow \text{真实动力学势能井}. \\]

例如，对数价格与原始价格的密度满足

\\[ \rho_P(p)=\frac{\rho_X(\log p)}{p}. \\]

因此概率密度的众数一般不在非线性坐标变化下保持不变。价格井必须明确自己使用的是哪种坐标和测度。

### 6.3 从静态井到动态状态

PPE-U2 的重要升级是：

不只判断哪里存在井，而是研究井的出生、增强、迁移、衰减和消失。

核心状态包括：

- Mode Birth / Death；
- Basin Mass Transfer；
- Persistence Change；
- Barrier Collapse；
- Dual-Well Transition；
- Failed Break；
- Regime Reset；
- Metastable / Transport。

历史设计还研究局部恢复动力学：

\\[ dX_t=f(X_t,t)\\,dt+ \sqrt{2D(X_t,t)}\\,dW_t. \\]

这一模型下，经验密度模式、漂移零点、真实稳定状态未必相同。

例如在零概率流的平稳条件下，密度众数位置可满足

\\[ f(x)=D'(x), \\]

而不一定是 \\(f(x)=0\\)。

因此仅根据 KDE 地形，无法唯一恢复未来触及时间。

### 6.4 P-BASE：离散竞争首次触及

PPE-U2-R5.1 最重要的概率基础是具有无事件质量的联合首次触及模型。

给定冻结的上边界 \\(U\\)、下边界 \\(L\\) 和预测期限 \\(H\\)，定义：

\\[ \tau_U=\inf\\{t\ge1:P_t\ge U\\}, \\]

\\[ \tau_L=\inf\\{t\ge1:P_t\le L\\}. \\]

三个互斥结果为：

\\[ q_U(H)=P(\tau_U<\tau_L,\ \tau_U\le H), \\]

\\[ q_L(H)=P(\tau_L<\tau_U,\ \tau_L\le H), \\]

\\[ q\_{\mathrm{none}}(H) =P(\tau_U>H,\tau_L>H). \\]

在无同时触及歧义，且观测定义完备时，

\\[ \boxed{ q_U+q_L+q\_{\mathrm{none}}=1. } \\]

同bar上下双触、数据缺口或并列事件需要先有独立观测规则，不能强制塞进某个确定方向。

### 6.5 离散风险递推

令第 \\(j\\) 个离散时段，在此前尚未触及边界的条件下，

\\[ p_U(j)+p_L(j)+p_0(j)=1. \\]

其中 \\(p_0(j)\\) 是当期继续存活的条件概率。

初始化

\\[ S_0=1, \\]

递推

\\[ S_j=S\_{j-1}p_0(j). \\]

联合首次触及概率：

\\[ \boxed{ q_k(H)= \sum\_{j=1}^{H}S\_{j-1}p_k(j), \quad k\in\\{U,L\\}. } \\]

无触及概率：

\\[ q\_{\mathrm{none}}(H)=S_H. \\]

这是历史 R5.1 的核心数学合同之一。

特别注意： 只有完整观察了 \\(H\\)，且未触及任何边界，才可以明确计为 `HORIZON_NONHIT`。若数据在期限到达前结束，应进入真实删失或观测不完整状态。

### 6.6 Activity、Direction 与 Timing 分离

定义活动概率：

\\[ I_H=1-q\_{\mathrm{none}}(H). \\]

在 \\(I_H>0\\) 时：

\\[ P(U\text{ first}\mid\text{hit by }H) =\frac{q_U(H)}{I_H}. \\]

类似地，

\\[ P(L\text{ first}\mid\text{hit by }H) =\frac{q_L(H)}{I_H}. \\]

这使预测问题拆成三个不同部分：

1. Activity：期限内会不会触及。
2. Direction：一旦触及，哪个方向先触及。
3. Timing：首次触及何时发生。

这一区分尤其重要，因为历史 V5.1 证据显示，首次退出模型的提升主要集中在 Activity，而不是 Direction。

### 6.7 P-SM：半马尔可夫挑战者

历史框架考虑通过半马尔可夫模型引入状态停留年龄：

\\[ P(S\_{t+1}\mid S_t,A_t,Z_t), \\]

其中 \\(A_t\\) 是当前状态已持续的时间。

但研究已经明确：

普通 semi-Markov 等待时间不自动解决同一价格、不同进入方向具有不同未来转移概率的问题。

因此还考虑方向化里程碑：

\\[ M_k^+,\qquad M_k^-. \\]

这些模型作为可证伪 challenger 保留，而不是默认比离散竞争风险更准确。

### 6.8 R5.1 的观测与执行区分

必须分别标记：

| 状态                             | 正确解释             |
| ------------------------------ | ---------------- |
| HORIZON_NONHIT                 | 完整期限内没有首次触及      |
| DATASET_END_RIGHT_CENSORED     | 观察提前结束，结果未知      |
| INTERVAL_ORDER_AMBIGUOUS       | 同bar多边界触及，顺序未知   |
| LEFT_TRUNCATED_EXCURSION       | 事件进入过程在观察起点之前已开始 |
| UNKNOWN_ENTRY_AGE              | 状态已持续时长未知        |
| TARGET_OUT_OF_INTRADAY_SUPPORT | 目标价格超出可支持的盘中数据范围 |
| KINETIC_EXTRAPOLATION          | 当前动力学状态超出训练支持范围  |
| REGIME_RESET                   | 原价格动力学结构发生重置     |

还必须区分：

\\[ \text{数学触及} \neq \text{订单真实成交}. \\]

价格达到涨停或跌停、发生跳空、停牌及成交量不足时，策略不一定能以指定价格执行。

## 七、Severity：回撤严重度与金融系统压力

V2588 后续设计引入独立严重度模型，以回答：

- 未来是否出现10%、20%、30%及更大级别的回撤？
- 回撤形成速度如何？
- 回撤后多久恢复？
- 是否伴随融资出清、信用收缩或系统性金融压力？

必须区分三种不同幅度。

从当前价格计算的最大损失：

\\[ L\_{t,H}= \max\_{t\le u\le t+H} \left(1-\frac{P_u}{P_t}\right)\_+. \\]

未来窗口内的最大峰谷回撤：

\\[ D\_{t,H}= \max\_{t\le u\le v\le t+H} \left(1-\frac{P_v}{P_u}\right). \\]

已定义顶部之后的最大回撤：

\\[ D\_{\mathrm{peak},H} = \max\_{\tau\_{\rm peak}\le v\le\tau\_{\rm peak}+H} \left(1-\frac{P_v}{P\_{\tau\_{\rm peak}}}\right). \\]

例如：

\\[ 100\longrightarrow140\longrightarrow112. \\]

从100买入并持有到112，未必出现账户亏损；但140到112的峰谷回撤为20%。

因此不能把预测“未来窗口有20%回撤”直接解释成“现在买入会亏20%”。

同样，40%指数回撤也不能直接断定为2008年级别的系统性信用危机。市场下跌幅度与融资、银行、信用压力必须分开定义。

## 八、Event Engine：真实顶底事件桥接

这是 V5.0 针对“LPPLS形态预测不等于真正事件预测”提出的重要升级。

### 8.1 核心事件对象

需要分开：

\\[ t_c,\quad \tau\_{\rm peak},\quad \tau\_{\rm onset},\quad \tau\_{\rm confirm},\quad \tau\_{\rm label\ available}. \\]

这些日期可能互不相同。

特别是实际峰值日期可能只有经过未来一段价格路径才能事后确认。

### 8.2 事件概率和日期分布

令

\\[ p_H= P(\tau\le t+H\mid\mathcal F_t) \\]

为未来期限内真实事件发生的概率。

给定事件在期限内发生，再定义

\\[ g_t(u)= P(\tau=t+u \mid \tau\le t+H,\mathcal F_t). \\]

那么：

\\[ \boxed{ P(\tau=t+u\mid\mathcal F_t) =p_Hg_t(u) } \\]

并保留

\\[ P(\text{no event by }H\mid\mathcal F_t)=1-p_H. \\]

这样就不会因为模型输出了一个未来 \\(t_c\\)，而强制把真实事件概率全部压到未来某一天。

### 8.3 事件桥接不得反写时间引擎

Event Engine 可以消费冻结后的：

- LPPLS 临界时间分布与形态；
- 窗口簇稳定性；
- Price 首达信息；
- 市场波动和趋势；
- 宏观信用与融资数据。

但训练出来的事件结果不能反向替换历史 LPPLS 拟合参数。

同样，Price 不得根据 LPPL 的 \\(t_c\\) 改写原价格边界、核带宽或转移机制。

这是可审计的工程防火墙规则。

统计上是否应该直接联合建模，需要后续 OOS 比较。

## 九、Cross-Fitted Joint Calibration

历史统一架构考虑在 Time、Price 和辅助模块都冻结之后进行事件概率融合。

一个曾提出的结构是以 Price 概率为 offset：

\\[ \log \frac{P\_{\rm joint}(U)}{P\_{\rm joint}(\mathrm{none})} = \log \frac{q\_{\rm PPE}(U)}{q\_{\rm PPE}(\mathrm{none})} + g_U(T\_{\rm frozen},A\_{\rm frozen}), \\]

下方向类似：

\\[ \log \frac{P\_{\rm joint}(L)}{P\_{\rm joint}(\mathrm{none})} = \log \frac{q\_{\rm PPE}(L)}{q\_{\rm PPE}(\mathrm{none})} + g_L(T\_{\rm frozen},A\_{\rm frozen}). \\]

其中 \\(g_U=g_L=0\\) 时，应准确退回 Price baseline。

但这只是历史研究结构提案，并不意味着：

- 联合模型已经校准；
- Time 和 Price 独立；
- 联合后一定改善概率预测；
- 联合概率可以通过两个边际概率相乘得到。

正确联合关系是：

\\[ P(T\in W,D\ge d) = P(T\in W) P(D\ge d\mid T\in W). \\]

条件概率需要实际学习与验证。

## 十、Governor：风险信号和执行治理

历史默认状态包括：

| 状态         | 用途                   |
| ---------- | -------------------- |
| BAN        | 严重数据/权限/证据阻断，禁止使用预测  |
| WATCH      | 观察中，证据未达到发布行动要求      |
| WATCH_RISK | 风险条件上升，但尚未达到可靠确认     |
| PROBE      | 经过授权、预算受控的小规模观察性策略候选 |
| CONFIRM    | 已定义的更高等级证据状态         |

需要有明确的 hysteresis，避免状态在相邻时间点频繁跳变。

同时区分四条轴：

- Forecast：事前预测；
- Observed：事后已经观察到的市场变化；
- Systemic：系统性金融风险；
- Quality：数据和证据质量。

不得把事后价格破位的 CONFIRM 冒充事前预测成功。

当前尚未完成科学校准，因此不应把这些等级自动转换为仓位百分比或真实订单。

## 十一、最新 S4 三轮研究框架

这是长期框架之后最重要的研究更新。

### 11.1 最新科学判断

一手 JLS 理论说明，泡沫临界时间并不保证价格在该时刻必然崩盘；崩盘具有随机性，临界时间与实际崩盘时刻可以不同。

[image](https://www.google.com/s2/favicons?domain=https://arxiv.org\&sz=32)

arxiv.org



因此新研究将 LPPLS 降为需要与简单模型竞争的候选，而不是预设冠军。

它提出的最小实验为：

# A

BASE

事件基率、历史收益、波动、回撤

# B

POWER

A + 纯幂律特征

# C

LPPLS

B + 对数周期振荡特征

A → B 检验纯幂律是否有增量；B → C 检验 log-periodicity 是否有独立增量。

三个模型使用同样的：

- 数据和 as-of；
- 真实事件标签；
- 训练与校准规则；
- 预测概率接口；
- 样本外测试时间；
- 可比较的计算与调参预算。

### 11.2 第三轮建议的首个主要事件

第三轮研究报告建议首先测试正泡沫顶部事件，沿用历史 `top10_20_60` 的语义。

在未来20个交易 session 内寻找候选最高点：

\\[ u_t=\min\arg\max\_{1\le u\le20}P\_{t+u}. \\]

随后检查从这一峰值起，未来60个交易 session 是否出现至少10%的回撤。

定义二元事件：

\\[ Y_t= \mathbf1 \left[ \min\_{u_t\<v\le u_t+60} \frac{P\_{t+v}}{P\_{t+u_t}} \le0.90 \right]. \\]

完整标签成熟期限为80个交易 session。

模型输出的是：

\\[ p_t=P(Y_t=1\mid\mathcal F_t). \\]

需要强调： 这是第三轮提出的预注册候选事件定义，不是已经通过实证验收的最优顶部定义。真正冻结前仍需审查末端候选峰值、平顶、停牌、复权、重复 episode 等规则。

### 11.3 唯一主要科学比较

第三轮建议以：

\\[ \boxed{C\ \text{vs}\ B} \\]

为唯一主要科学比较。

主要评分为全有效预测 origin 上的 Brier Score：

\\[ BS=\frac1N\sum\_{i=1}^N(p_i-Y_i)^2. \\]

主要效应：

\\[ \Delta BS=BS_C-BS_B. \\]

只有

\\[ \Delta BS<0 \\]

才表示完整 LPPLS 在该样本上的平均 Brier 更好。但统计上是否稳定、改善是否具有实际意义，仍须考虑区块相关、置信区间、事前阈值及最终未见数据。

日期误差、区间覆盖、区间宽度、提前量、误报漏报、log loss、校准曲线等作为预定义辅助指标或约束。

### 11.4 时间隔离

第三轮研究建议：

| 数据时期       | 研究作用              |
| ---------- | ----------------- |
| 至2022年底    | TRAIN             |
| 2023—2024  | TUNE              |
| 2025       | CALIBRATION       |
| 2026年协议冻结前 | 已知资料／SHADOW       |
| 协议冻结后      | PROSPECTIVE FINAL |

此表是研究方案，不表示这些区间已经完成PIT数据验收。滚动训练时，各项历史标签必须已成熟，不能把尚未观察完的未来80日事件提前用于模型训练。

2016—2025年已经被历史研究查看，不能重新命名为完全未见的最终测试集。

### 11.5 参数层与事件层分开验收

在合成数据中，可以研究：

\\[ \hat t_c-t_c, \\]

\\[ \operatorname{RMSE}(\hat t_c), \\]

以及真实 \\(t_c\\) 是否被参数置信区间覆盖。

但在市场数据上，需要评价真实事件 \\(Y_t\\) 和 \\(p_t\\)。

不能直接用真实顶部日期来检验 LPPLS 的 \\(t_c\\) profile 置信区间覆盖率。

如果模型希望输出顶部日期分布，就必须单独学习参数到事件的映射，并完成独立的事件层校准。

### 11.6 最新研究尚未证明的事项

目前没有科学验收证明：

- LPPLS 比纯幂律提供稳定的真实 A 股事件预测增量；
- 多窗口选择真正提高日期预测准确率；
- profile 置信区间具有真实峰值日期的校准覆盖率；
- 反LPPLS底部模型具有与顶部相同的预测能力；
- Price 物理井模型提供超越简单波动和距离特征的增量；
- Time/Price联合模型优于简单分离模型；
- 可以稳定实现费用后净收益。

因此目前不能把新研究直接命名为已经验收的 V2588 V6 生产模型。
