# LPPLS 规则规格

版本：`lppls-spec-v1`，唯一实现见 `research/lppls/spec.py`。

## 常规窗口

| 项目 | 规则 |
| --- | --- |
| 搜索 | A 股日更/扫描与国际 `global_terminal`（27 个窗口）：`m∈[0.01,2.0]`、`ω∈[1,50]`、`t_c∈[t₂−0.2·dt,t₂+0.2·dt]`，允许窗内 `t_c`；完整扫描 10 个随机起点。 |
| 合格框（box） | `B<0`、`m∈[0.1,0.9]`、`ω∈[6,13]`、`ahead∈[0,90]` 个交易日，边界包含。 |
| 国际附加变体 | `box_cycles_1_5 = box ∧ ahead>0 ∧ n_osc≥1.5`，使用同一拟合池。 |

常规窗口是唯一经过 dev/cal/test 评价的规则。开发段中，长尺度警报后 120 个交易日内到顶比例为 87%，随机基线为 17%。

## 长窗口

窗口为 `(900,925,950,6500,6600,6700)`，种子为 `(11,29)`。`t_c` 只允许未来 `[1,90]` 个交易日；优化边界为 `m=[0.1,0.9]`、`ω=[6,13]`。通过条件包括优化成功、`B<0`、`m`/`ω` 严格在边界内、阻尼 `≥1`、`R²≥0.9`、秩 `≥4`、条件数合格、所有参数在内部，以及两个种子的 `t_c` 相差不超过 2 个交易日；另按周期数分别报告 `cycles_1_5` 与 `cycles_2_5`。

长窗必须使用未来 `t_c`：对 6600 日窗口使用 ±20% 会给出无意义的搜索范围。IXIC 的 925 日规则中，信号后 120 个交易日内回撤至少 20% 的比例为 60%，随机基线 95% 分位为 30%；`t_c` 日期本身并不优于随机日期。

## 展示与遗留项

风险只展示为日期范围，不展示精确顶部日期。v1/proto 是遗留研究变体（v1 = early registration；proto = old browser prototype domain；never backtested）；所有生产工作流显式设置 `LPPLS_BOX=v2`。目前指数优化器为 `tcgrid`、个股为 DE，这是已知差异，等待完整重扫后再处理。
