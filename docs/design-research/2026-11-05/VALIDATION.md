## 未执行，不能当作通过

- **NOT_RUN**：新金融模型、DE/TRF公平计时、任何真实行情重拟合、Q/C回测、前瞻预测、概率/区间校准、交易成本或净收益验证。
- **NOT_INSPECTED**：实体手机触屏/屏幕阅读器全流程、真实网络弱网、真实用户Core Web Vitals、各数据供应商可用性和授权范围。
- **NOT_INSPECTED**：生产Worker绑定/密钥权限、分支保护是否实际生效、线上stock_query与nightly任务、真实Pages发布后版本一致性；本轮不触发这些动作。
- **NOT_IMPLEMENTED**：正式数据适配器、统一生产页面、任务API变更、新后端研究模型。原型不得混入生产数据路径。
- **NOT_DEPLOYED**：网站改版。文档/原型推送与PR不等于Pages上线。
- GitHub现有CI的最终状态以PR Checks为准；语法检查、文献核验均不能替代它，也不能把CI绿灯解释成模型有效。

## 后续可执行的生产验收

- [ ] 桌面1440/1024、移动390/320：导航可用、关键证据可见，无页面横向溢出；长名称、长错误文本和200%缩放可读。
- [ ] 主题与色序切换同时影响CSS、Canvas/SVG、图例、导出；不因市场变化自动反转含义。
- [ ] 键盘与触屏可完成搜索、资产选择、日期回放、图层、解释、异步任务恢复；不依赖hover获取关键信息。
- [ ] Worker：无效代码/超预算/限流/无KV/派发失败/重复查询/结果404均有明确错误；CORS不当作身份认证；前端无令牌。
- [ ] stock_query：同一job_id贯穿当前与历史；current_ready先显示；历史失败保留当前；发布失败不称完成；旧任务不得覆盖新结果。
- [ ] stock_nightly：asof和版本一致；分片缺失/停牌/数据短显式计数；覆盖率分母正确；失败批次不伪装全量。
- [ ] Pages：锁定代码与结果清单；真实URL回读预期版本；取结果分支失败不静默发布缺数据；回滚恢复上一完整版本。
- [ ] 分支保护：读取并确认main必需检查、审查、写权限与发布环境；记录实际证据而非仅有YAML。
- [ ] 证据文案：失败、未评价、描述性、技术错误分别渲染；未知证据等级不默认放行数值；historical重算不叫当时发布。
- [ ] 时间/价格：窗口长度与预测期限有单位；tc参数区间不叫峰值概率；历史价格分位不叫底价；无合格拟合不等于无风险。
- [ ] 性能目标：LCP≤2.5s、INP≤200ms、CLS≤0.1为p75设计目标，分移动/桌面以实际用户数据验证；本轮没有这组实测成绩。
