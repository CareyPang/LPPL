## 1. 背景与已知信息

现行底分（`research/eval/bottom_dashboard.py`，下称 C0）= 估值 35% + 回撤深度 30% + 止跌/波动 20% + 右侧企稳 15%。
登记前已经看过的结果，全部来自**开发段**（6 个指数周度帧，2000–2018）：

- 绿柱（≥20 分）占 52% 的周，24 周后上涨比例 52%，全部周 51%。
- 分档：<50 分各档 24 周上涨 34%–48%，≥50 分 61%–62%。
- 分项三分位的 24 周上涨比例：估值 42/52/61，回撤 46/48/59，止跌 48/56/50，右侧 48/52/53。

另外已知（`reports/bottom_calibration.md`）：

- C0 的 “≥50 分” 档在测试段已经报告过（50 周胜率 0.686）。**测试段对 C0 不是未见数据**；对下面的新候选仍未打开。
- 校准段（2019–2021）是单边上涨，任意一周的 50 周胜率约 0.95，区分力很低。因此校准段在本登记里只作“不劣于”检查，不作为有效性证明。

## 2. 数据与切分

- 输入：7 个已发布指数历史文件的周度帧 `frames[].bottom_detail`（`dd_52w`、`erp_pct`、`pbn_pct`、`valuation`、`clearing`、`stabilize`、`right_side`），均为严格 PIT；未来收益用本地 qfq 日线缓存。
- 切分沿用帧上的 `split`：dev ≤ 2018-12，cal 2019-01–2021-12，test 2022-01–2025-08。`live` 帧不进任何样本。
- 样本域：`phase == "pullback"` 的周（距 52 周高点回撤 ≥12% 且无顶部聚类）。底分只在这个域里有意义。
- 缺估值（2005 年前）的周：需要估值的候选一律记 0 分，不做权重再分配。

## 3. 候选（固定，共 4 个结构）

记 `V = valuation`（0–1），`D20 = clip((-dd_52w − 0.20) / 0.20, 0, 1)`（回撤 20% 起算、40% 满分）。

| 代号 | 定义 | 可选参数 |
|---|---|---|
| C0 | 现行底分，绿柱门槛 50 | 无（基线） |
| C1 | `V ≥ v_min` 才计分；分数 = 100·(0.6·V + 0.4·D20) | `v_min ∈ {0.3, 0.5, 0.7}`，绿柱门槛 `τ ∈ {50, 60}` |
| C2 | 分数 = 100·(0.5·V + 0.5·D20)，无必要条件 | `τ ∈ {50, 60}` |
| C3 | 分数 = 100·V（只看估值） | `τ ∈ {50, 70}` |

C1–C3 都去掉止跌和右侧企稳两项。共 6 + 2 + 2 = 10 个配置，加基线 C0。不追加其他候选。

## 4. 指标

事件：某配置的“绿柱周”按 12 周冷却去重后的独立事件（与 `bottom_calibration.independent_positions` 相同）。

- **主指标 L50**：绿柱事件的 50 周后上涨比例 − 同段同指数全部 pullback 周的 50 周上涨比例（按指数等权平均）。
- 副指标 R24：绿柱事件后 24 周内再跌 10% 以上的比例 − 同域基准比例（越低越好）。
- 覆盖率：绿柱周 / pullback 周。
- 零对照：每个指数内把绿柱标记做循环平移（平移量 ≥26 周，2000 次，种子 20261126），得到 L50 的零分布和单侧 p 值。循环平移保留绿柱的自相关结构。

## 5. 开发段选择规则

1. 合格条件：覆盖率在 10%–40% 之间，且开发段独立事件 ≥ 30 个。
2. 稳健性：留一指数（6 次）L50 全部 > 0。
3. 在合格且稳健的配置里取 L50 最大者；差距 < 0.02 时取参数更少的结构（C3 > C2 > C1）。
4. 若没有配置同时满足 1、2，或最优配置的 L50 不高于 C0 的 L50 + 0.03：**结论为“无更优候选”**，归档，页面继续用 C0 + 门槛 50。不再试新候选。

## 6. 校准段检查（只跑一次，只跑第 5 步选出的那一个配置）

通过条件（全部满足）：

- 校准段 L50 ≥ C0 的 L50 − 0.05（不劣于）；
- 校准段 R24 ≤ C0 的 R24 + 0.05；
- 校准段独立事件 ≥ 5 个（不足则记“样本不足”，按未通过处理）。

未通过 → 归档，页面继续用 C0 + 门槛 50。

## 7. 测试段（最终验收，只跑一次）

仅当第 6 步通过才打开。通过条件：测试段 L50 > 0 且循环平移 p ≤ 0.10，且 L50 ≥ C0 的测试段 L50 − 0.05。
通过才替换线上底分，并在页面写明证据等级；未通过则归档，不再用测试段做任何调整。
