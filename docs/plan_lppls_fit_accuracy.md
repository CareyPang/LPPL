# LPPLS 拟合回归准确性专项计划（草案，2026-11-15；**只写未跑，等用户确认**）

用户方向："引擎现在应该聚焦在 lppls 拟合回归如何更准确上面"。本计划把"拟合更准"拆成可以单独检验的四层，每层的判据写在结果之前。前提不变：不把 t_c 当顶部日期；个股维持 `research_candidate`；不打开确认样本；`_g3` 不改生产默认（用户 2026-11-15 决定）。

## 0. 已知事实（作为起点，不重做）
- 数值层：现行 `tcgrid_lm` 在"t_c 落在窗口内 + 低 m"区域约 23% 窗口没找到最低 SSE；`_g3`（再跑 `de_lbfgsb` 取小者）能修掉，但报警日 Jaccard 中位 0.902、A1/A2 配对差 +0.007/0.000，命中率不变（§20.1、`reports/q3_dev.md`）。
- 结论：**找到更低 SSE ≠ 信号更准**。现在的瓶颈不是优化器，而是 (a) 同一窗口里 t_c 本身辨识不出来，(b) 残差不是独立同分布、拟合误差的比较口径不对，(c) 窗口起点 t1 是固定网格而不是数据决定的。

## 1. 四层与判据

### F1 数值正确性（不需要门，属于修 bug）
- 做法：抽 2,000 个开发段窗口，用密网格（t_c × m × ω 全枚举 + 线性消元 + 局部精修）作参照解，统计 `tcgrid_lm`、`de_lbfgsb`、`_g3` 的相对 SSE 差 >1e-6 比例、参数差，按 (t_c 在窗内/外, m 区间) 分层。
- 用途：给出每种优化器的"漏找地图"，以后任何改动先过这张表。算力约 2 CPU 小时。

### F2 t_c 辨识度（剖面似然区间）
- 做法：对每个合格窗口，固定 t_c 网格求剖面 SSE(t_c)，按 Filimonov–Sornette 线性化在 t_c 上取剖面；区间 = 剖面 SSE 不超过最小值 × (1 + c) 的 t_c 集合，c 由合成数据标定（不叫置信区间，叫"剖面范围"）。
- 合成门：LPPLS + AR(1)/GARCH 残差的合成泡沫上，剖面范围对真 t_c 的覆盖率在 80%–95% 之间；在六类零假设上，范围宽度中位 ≥ t_c 搜索域宽度的 50%（§25.2 更正）（即零假设下应显示"辨识不出"）。
- 开发段门：只保留"剖面范围宽度 < 60 交易日"的合格窗口后，A1/A2 不劣于现行，且剔除 2007/08/2014/15 后在 ≥4/6 指数优于循环平移零对照。不过门则只作描述字段"t_c 辨识度"。

### F3 残差模型（拟合误差口径）
- 做法：现行 OLS 假设 log 价格残差独立同分布；A 股窗口残差强自相关。候选：残差 AR(1) 的可行 GLS（每次线性消元前做 Prais–Winsten 变换），以及文献里的均值回复残差设定（Lin–Ren–Sornette 2014 系列；正文未核对，§25.3 本轮不纳入）。
- 合成门：同 F2 的合成泡沫上，t_c、m、ω 的中位绝对误差比 OLS 至少低 20%，零假设误报率不高于现行。
- 开发段门：同 F2。

### F4 窗口起点 t1 由数据决定（Lagrange 正则）
- 做法：Demos–Sornette 的 Lagrange 正则（已核对 arXiv:1707.07162 式 (10)–(11)，见 §25.4），替代固定窗口长度网格，每个 as-of 只给一个 t1。
- 合成门：合成泡沫上 t1 与真起点的中位误差 < 窗口长度的 20%；零假设上置信度分布不高于现行。
- 开发段门：同 F2。

## 2. 顺序与算力
F1（2 CPU 小时，先做）→ F2 合成（约 10 CPU 小时）→ F3 合成（约 10 CPU 小时）→ F4 合成（约 5 CPU 小时）→ 过合成门的才跑开发段（每项约 30 CPU 小时，走 Actions 分片）。全部失败也登记，不调参重跑。

## 3. 事先写的预期
- F1 会把 `_g3` 的漏找地图量化清楚，但不会改变命中率。
- F2 最有希望：它不改报警逻辑，只是把"t_c 辨识不出来"的窗口去掉；预计合成门能过，开发段能否在普通年份过零对照约三成把握。
- F3/F4 预计主要改善参数估计误差，对报警命中率的影响不确定。

## 4. 不做
- 不把任何一层的结果写成顶部日期或价格预测；不把剖面范围叫置信区间；不改生产优化器；不新增产品字段，除非过门且用户确认。
