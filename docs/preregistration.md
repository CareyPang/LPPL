- **扩充样本（个股）**：每个时间段使用该段开始前最后一个交易日的沪深 300 成分股：

  |---|---|---|

  | 校准段 | 2018-12-28 | 2019-01-01 至 2021-12-31 |

  股票只在**已上市满 5 年**之后才进入样本；退市或停牌后不再产生新的 as-of 样本。
- **数据来源（2026-10-24 实测）**：
  - 成分股快照：妙想 mx-data 能返回指定日期的 300 只成分股（2010-01-04、2018-12-28 都已验证）。AkShare 和中证官网接口只能给出最新名单。快照原始 JSON 计入数据版本。
  - 退市股日线：只有腾讯接口能拿到，例如 600087 有 1997–2014 年数据。但腾讯的前复权是加法复权，会出现负价格。因此个股统一取**不复权价加除权除息因子**，自己计算乘法复权价；复权因子取自 AkShare 新浪接口 `stock_zh_a_daily(adjust="hfq-factor")`：已实测 600087、600002、000527 三只退市股，都能取到，且因子全部为正。用 `stock_history_dividend_detail` 返回的除权除息日做交叉核对。取不到因子、或交叉核对不一致的股票整只剔除，并记录剔除名单。
- **新增门槛**：在测试段（2021-12-31）的成分股快照中抽样核对复权因子，覆盖率达到 95% 以上才冻结方案。
- 价格统一用**后复权**（以上市日为基准的乘法复权）对数收盘价。不用前复权：前复权价在时点 t 的数值依赖 t 之后的分红送转，违反 PIT。LPPLS 拟合的是对数价格形状，后复权和前复权只差一个常数，不影响拟合。
- 停牌日不补数据；窗口内停牌日超过 10% 的窗口不参与拟合。涨跌停日照常使用。
- 个股数据的 vintage 全部是 2026 年下载的，历史 as-of 时点一律标记 `pit_approx=True`；因为行情数据极少被修订，这里当作可接受的近似，并在报告中说明。

## 2. Point-in-Time 规则
- 在时点 t 计算特征时，只能使用 date ≤ t 的数据，且 vintage 不晚于 t。早于第一个 vintage 的部分标记 `pit_approx=True`，并在报告中单独统计。
- 波动率、ZigZag 阈值、分位数等**任何**归一化量，只能用 ≤ t 的数据计算。旧原型 `CP.evaluate` 用全样本阈值，新标签不得沿用这种做法。

## 3. 事件标签（主标签）
- **顶部标签：用 C 定位顶部，用 B 过滤大小**
  1. **C：ε-回撤分段**（参照 Gerlach、Demos 和 Sornette 2019，即 E4）。对每一组参数 (ε₀, w)，把价格序列切成交替的上涨段和下跌段：上涨段持续，直到从段内最高点回撤超过 ε = ε₀·σ_w；σ_w 是截至当日、过去 w 日的日对数收益标准差。上涨段终点记为候选顶。参数网格 ε₀ ∈ {0.1, 0.2, …, 5.0}（50 个值），w ∈ {10, 15, …, 60}（11 个值），共 550 组。E4 原文的网格是 50 × 11 = 550 组，ε₀ 的具体取值待对照原文核实。
  2. **共识顶**：某一日在 ±2 个交易日内，作为候选顶出现在 ≥ 50% 的参数组合中，就记为共识顶。50% 这个门槛是我们自己定的，不是文献值，敏感性分析中改用 30% 和 70% 各算一次。
  3. **B：分位数过滤**。共识顶之后的跌幅定义为：从该顶到其后 60 个交易日内的最低点。跌幅 ≥ d_t 才算事件，d_t = max(10%, Q₉₀)。Q₉₀ 是该标的在 t 之前 5 年内、所有共识顶之后跌幅的 90% 分位数，只用 ≤ t 的数据计算。
  4. **标签**：(t, t+20] 内出现一个合格事件的顶，则 Y_top(t) = 1。标签成熟期仍为 80 个交易日。
  5. **敏感性分析**（只报告，不参与决策）：d_t 换成 max(10%, 1.5·σ_t·√20)，以及固定 15%，各算一次。
- **as-of 时点**：所有候选都逐日计算。Trust 指标计算量太大，只在 7 个指数上每 5 个交易日计算一次，并且只与同一批指数、同一批时点上的其他候选单独比较，不进入全样本排名。
- **事件计数**：统计效力和报告中的"事件数"按**事件段**计，即连续为 1 的 t 合并为一次事件，而不是按天计。
- 标签需要 t 之后 80 个交易日的数据才能确定（下称"成熟期"）。成熟期未满的样本不进入任何训练或评分。
- **辅助连续标签**：t 之后 60 个交易日内的最大回撤。用于增加统计效力，只作为辅助评分。
- **底部标签**（三重障碍）在底部阶段另行登记，本版不包含。

## 5. 候选方法（名单固定，冻结后不再增加）
每个候选都输出一个或多个连续分数 s(t)。**阶梯是叠加式的**：第 k 级的模型 = 带 L2 正则的逻辑回归，输入是"此前所有保留级别的分数 + 本级分数"。所以"第 k 级胜过第 k−1 级"检验的是本级分数的**增量**。校准段只做 Platt 校准。随机种子固定为 0、1、2，三次结果都报告。
| 编号 | 候选 | 说明 |
|---|---|---|
| R0 | BASE | 开发段的事件基率 |
| R1 | VOL | 过去 20、60、120 日收益率和波动率（逻辑回归） |
| R2 | GSADF | Phillips–Shi–Yu（2015）的检验统计量 |
| R3 | POWER | 纯幂律多窗口：合格窗口所占比例 |
| R4a | P-DS | 原型 `FILTERS.ds` |
| R4b | P-STRICT | 原型 `FILTERS.strict` |
| R4c | P-TOP | 原型 `TOP_RULE`，加上 t_c 聚类和一致度 |
| R4d | LIT-DS | E7 表 3：搜索空间 m ∈ [0, 2]、ω ∈ [1, 50]、t_c ∈ [t₂−0.2dt, t₂+0.2dt]；条件 1：m ∈ [0.1, 0.9]、ω ∈ [6, 13]、t_c ∈ [t₂−0.15dt, t₂+0.13dt]、(ω/2)·ln ≥ 2.5、D ≥ 1.2、相对误差 ≤ 0.035；窗口 125–750 日，步长 5（126 个） |
| R4e | LIT-DS+Trust | R4d 的置信度加上 Trust 指标（条件 2，每个窗口 100 条替代序列） |
| R4f | LIT-MS | R4d 的过滤器，加 E4 的三尺度窗口（30–120、100–240、200–720 日） |
| R5 | +LOG-PERIODIC | 在最优 LPPLS 候选上，再加"LPPLS 与纯幂律的嵌套比较"作为特征（零分布用块 bootstrap 生成） |
| R5b | +LOMB | Lomb 过滤器，显著性门槛用模拟零分布确定（Zhou & Sornette 2002） |
| R6 | +资金面 | 融资余额、北向资金（需要另行准备 PIT 数据，数据到位前不登记） |
| R7 | +统计物理 | DFA、排列熵、AR(1)、方差、Kendall τ |
| OLD | 旧原型整体 | 对照组，不参加淘汰 |

调参只允许在第 9 节"附表"列出的网格内进行，每个候选最多 20 个配置。试过的配置总数要记录下来，用于多重比较校正。

## 6. 评分与淘汰规则
- **主评分**：Brier score。
- **辅助评分**：log loss、ECE（事件少于 50 个时用 5 个等频分箱）、可靠性曲线、误差图（漏报率对报警时间占比，与随机报警对比）、误报次数/年、提前量、t_c 区间命中率。
- **辅助评分补充**：Brier 技能分 BSS = 1 − Brier/Brier_BASE，以及 PR-AUC。事件稀少时 Brier 的绝对差很小，BSS 更易读；但决策仍只看 Brier 差值的区间。
- **阶梯规则**：第 k 级保留的条件，是开发段 CPCV 的 15 条路径上满足 ΔBrier(k − 前一保留级) < 0，**且**这个差值的块 bootstrap 90% 区间不含 0。bootstrap 按时间块重抽，块长 ≥ 80 个交易日（标签成熟期），所有标的同一时间块一起抽。同一级里的多个变体（如 R4a–R4f）只保留一个，按开发段 Brier 选；被比较的变体和配置总数计入多重比较。
- **最终测试**：所有保留下来的级别，加上 OLD、BASE，在最终测试段各跑一次。报告：
  - 每个模型相对 BASE 的 ΔBrier 及块 bootstrap 区间；
  - Hansen SPA 检验的 p 值（零假设：所有候选都不优于 BASE）；
  - 开发段 CSCV 估计的 PBO（回测过拟合概率）。
- **预先承认的结果**：如果没有任何候选在最终测试段以区间不含 0 的幅度胜过 BASE，结论就写"没有证据表明有效"，不得改用其他评分重新讲故事。

## 7. 冻结前必须完成的统计效力检查
- 统计每个切分段的事件段数（指数和个股分开列）。开发段事件段少于 30 个则方案不能冻结，必须扩大个股样本（例如改用中证 500 成分股）。
- 用开发段的事件率做模拟，估算 80% 统计效力下能检出的最小 ΔBrier，写入本文。

## 8. 合成数据阶段（阶段 3b）同时登记
- **生成器**：
  - LPPLS 真值，噪声分为 iid、AR(1)、GARCH 三种；振荡强弱、短窗口、边界参数各设若干档；
  - **零假设序列**：带漂移的随机游走、GARCH、AR(1)、只有纯幂律而没有振荡的序列、非正态（non-normal）伪临界过程（Troude 等 2024）。
- **评分项**：
  - t_c、m、ω 的回收误差；
  - t_c 区间覆盖率，比较修正 profile likelihood 和块 bootstrap 两种方法；
  - 每种置信度指标在零假设序列上的报警率；
  - Lomb 检验在每种零假设下的实际误报率。
- **优化器冻结规则**（只看优化器本身）：在失败率 ≤ 1% 的方法中，选"落入全局极小"比例最高的（判据：SSE 与各方法最优值之比 ≤ 1 + 1e−6）；并列时选 nfev 最少的。
- **t_c 区间方法冻结规则**（与优化器分开）：在合成数据上，选名义 90% 区间的实际覆盖率最接近 90%、且平均宽度更小的方法。

## 9. 对抗性检查（全部预先登记，结果全部报告）
- **安慰剂检验**：时间反转、块打乱、随机移动窗口起点。在这些序列上，信号的 ΔBrier 应该接近 0。
- **门槛扰动**：每个门槛 ±20%，看主结论是否翻转。
- **留一检验**：每次留出一次危机、一个市场或一个子时期。
- **独立复审**：打开最终测试段之前，由一个独立会话审查代码和本文。复审通过后记录代码的 commit hash，最终测试只能用这个 hash 的代码运行。

## 11. v1.1 修订记录（2026-10-24，阶段 4 开始后）
**原因**：阶段 4 实测冻结优化器（t_c 网格+LM）单窗口拟合 0.13–0.3 秒。按 v1.0"所有候选逐日计算"，LPPLS 类候选（R3、R4）在 7 个指数上需约 400 万次拟合、个股约 1.3 亿次，8 核机器上分别约 200 小时和不可行。用户选择方案 A。标签、切分、评分、淘汰规则、优化器均不变；本节修订**只影响 LPPLS 类候选的时点与窗口密度**：

| 项目 | v1.0 | v1.1 |
|---|---|---|
| LPPLS 类候选的 as-of 时点（指数） | 逐日 | 全局交易日历每 5 个交易日一个 |
| LPPLS 类候选的 as-of 时点（个股） | 逐日 | 全局交易日历每 20 个交易日一个，且只在所属快照段内 |
| 窗口集（指数） | 125–750 日步长 5（126 个） | 不变 |
| 窗口集（个股） | 126 个 | 125–750 日步长 25（26 个） |
| 非 LPPLS 候选（R0–R2、R7） | 逐日 | 不变（逐日） |

**比较规则补充**：LPPLS 类候选与其前一保留级别的 ΔBrier 比较，在**同一组稀疏时点**上配对进行（前一级别的逐日预测在这些时点上取值）；非 LPPLS 候选之间仍用逐日样本。

**实现细节与限制（如实记录）**：
1. 每个窗口只做一次 LPPLS 拟合，搜索域取 E7 的 m∈[0.01, 2]、ω∈[1, 50]、t_c∈(t₂, t₂+0.2·dt]，并做一次纯幂律拟合（同一 t_c、m 域）。R4a–R4c（原型 ds/strict/TOP）的过滤规则施加在这同一组拟合上，而不是用原型各自的搜索域和窗口集；这与原型的实际运行方式有差异，OLD 对照组仍按原型原样运行。
2. t_c < t₂ 的搜索域（E7 允许到 t₂−0.2·dt）未实现：当前设计矩阵要求 t_c > t。LIT-DS 条件 1 的 t_c 下界因此被截断为 t₂。此项若后续实现 |t_c − t| 设计矩阵再补，补做结果单独报告。
3. Trust 指标仍按 v1.0：仅 7 个指数、每 5 日。
4. 网格阶段改为批量 SVD 计算（`grid_profile`），与逐点 lstsq 结果逐项相同（测试覆盖），不构成方法改动。
