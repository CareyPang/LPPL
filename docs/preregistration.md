- **新增门槛**：在测试段（2021-12-31）的成分股快照中抽样核对复权因子，覆盖率达到 95% 以上才冻结方案。
- 统一用前复权的对数收盘价。

## 2. Point-in-Time 规则
- 在时点 t 计算特征时，只能使用 date ≤ t 的数据，且 vintage 不晚于 t。早于第一个 vintage 的部分标记 `pit_approx=True`，并在报告中单独统计。
- 波动率、ZigZag 阈值、分位数等**任何**归一化量，只能用 ≤ t 的数据计算。旧原型 `CP.evaluate` 用全样本阈值，新标签不得沿用这种做法。

## 3. 事件标签（主标签）
- **顶部标签** Y_top(t) = 1 的条件：设 P* = max(P_{t+1..t+20})，峰值日为 τ；在 (τ, τ+60] 内的最低价 ≤ P*·(1 − d_t)。其中 d_t = max(10%, 2.5·σ_t·√60)，σ_t 是截至 t 的 250 日日对数收益标准差。
- 标签需要 t 之后 80 个交易日的数据才能确定（下称"成熟期"）。成熟期未满的样本不进入任何训练或评分。
- **辅助连续标签**：t 之后 60 个交易日内的最大回撤。用于增加统计效力，只作为辅助评分。
- **底部标签**（三重障碍）在底部阶段另行登记，本版不包含。

## 4. 时间切分（按 as-of 时点 t）
| 段 | t 的范围 | 用途 |
|---|---|---|
| 开发段 | 2000-01-01 至 2018-12-31 | 训练和调参。只用 Purged K-Fold（K=6）和 CPCV（N=6，k=2），每折前后各清除 80 个交易日（purge + embargo） |

| 排除 | 2025-09-01 以后 | 已经看过的 2026-02-27、2026-04-30 两个案例落在这一段 |

## 5. 候选方法（名单固定，冻结后不再增加）
每个候选都输出一个连续分数 s(t)。分数统一换算成概率：先在开发段用带 L2 正则的逻辑回归 p = σ(a + b·s)，再在校准段做 Platt 校准。
| 编号 | 候选 | 说明 |
|---|---|---|
| R0 | BASE | 开发段的事件基率 |
| R1 | VOL | 过去 20、60、120 日收益率和波动率（逻辑回归） |
| R2 | GSADF | Phillips–Shi–Yu（2015）的检验统计量 |
| R3 | POWER | 纯幂律多窗口：合格窗口所占比例 |
| R4a | P-DS | 原型 `FILTERS.ds` |
| R4b | P-STRICT | 原型 `FILTERS.strict` |
| R4c | P-TOP | 原型 `TOP_RULE`，加上 t_c 聚类和一致度 |
| R4d | LIT-DS | E7 表 3：搜索空间 m ∈ [0, 2]、ω ∈ [1, 50]、t_c ∈ [t₂−0.2dt, t₂+0.2dt]；条件 1：m ∈ [0.1, 0.9]、ω ∈ [6, 13]、t_c ∈ [t₂−0.15dt, t₂+0.13dt]、(ω/2)·ln ≥ 2.5、D ≥ 1.2、相对误差 ≤ 0.035；窗口 125–750 日，步长 5（126 个） |
| R4e | LIT-DS+Trust | R4d 的置信度加上 Trust 指标（条件 2，每个窗口 100 条替代序列） |
| R4f | LIT-MS | R4d 的过滤器，加 E4 的三尺度窗口（30–120、100–240、200–720 日） |
| R5 | +LOG-PERIODIC | 在最优 LPPLS 候选上，再加"LPPLS 与纯幂律的嵌套比较"作为特征（零分布用块 bootstrap 生成） |
| R5b | +LOMB | Lomb 过滤器，显著性门槛用模拟零分布确定（Zhou & Sornette 2002） |
| R6 | +资金面 | 融资余额、北向资金（需要另行准备 PIT 数据，数据到位前不登记） |
| R7 | +统计物理 | DFA、排列熵、AR(1)、方差、Kendall τ |

## 6. 评分与淘汰规则
- **主评分**：Brier score。
- **辅助评分**：log loss、ECE（事件少于 50 个时用 5 个等频分箱）、可靠性曲线、误差图（漏报率对报警时间占比，与随机报警对比）、误报次数/年、提前量、t_c 区间命中率。
- **阶梯规则**：第 k 级保留的条件，是开发段 CPCV 上满足 ΔBrier(k − 前一保留级) < 0，**且**这个差值的块 bootstrap 90% 区间不含 0，**且**在校准段不变差。同一级里的多个变体（如 R4a–R4f）只保留一个，按开发段 Brier 选。
- **最终测试**：所有保留下来的级别，加上 OLD、BASE，在最终测试段各跑一次。报告：
  - 每个模型相对 BASE 的 ΔBrier 及块 bootstrap 区间；
  - Hansen SPA 检验的 p 值（零假设：所有候选都不优于 BASE）；
  - 开发段 CSCV 估计的 PBO（回测过拟合概率）。
- **预先承认的结果**：如果没有任何候选在最终测试段以区间不含 0 的幅度胜过 BASE，结论就写"没有证据表明有效"，不得改用其他评分重新讲故事。

## 8. 合成数据阶段（阶段 3b）同时登记
- **生成器**：
  - LPPLS 真值，噪声分为 iid、AR(1)、GARCH 三种；振荡强弱、短窗口、边界参数各设若干档；
  - **零假设序列**：带漂移的随机游走、GARCH、AR(1)、只有纯幂律而没有振荡的序列、非正态（non-normal）伪临界过程（Troude 等 2024）。
- **评分项**：
  - t_c、m、ω 的回收误差；
  - t_c 区间覆盖率，比较修正 profile likelihood 和块 bootstrap 两种方法；
  - 每种置信度指标在零假设序列上的报警率；
  - Lomb 检验在每种零假设下的实际误报率。
- **优化器冻结规则**：在失败率 ≤ 1% 的方法中，选 t_c 区间覆盖率最接近名义值的；如果并列，选 nfev 最少的。

## 9. 对抗性检查（全部预先登记，结果全部报告）
- **安慰剂检验**：时间反转、块打乱、随机移动窗口起点。在这些序列上，信号的 ΔBrier 应该接近 0。
- **门槛扰动**：每个门槛 ±20%，看主结论是否翻转。
- **留一检验**：每次留出一次危机、一个市场或一个子时期。
- **独立复审**：打开最终测试段之前，由一个独立会话审查代码和本文。
