V2588 框架深度评审与升级方案

评审对象：用户上传的《V2588 长期记忆金融框架完整版》（V3.0 / V4.8-R2 / PPE-U2-R5.1 / V5.0 / S4）· 对照基准：Sornette 团队一手文献 · 2026-10-23

这套框架的工程纪律已经达到机构水准，但预测内核有三处结构性缺口，所以目前还推不出“稳定预测顶底”。本文逐项说明哪些该保留，哪些要改，哪些应删除，并给出可以执行的升级路线。

1. 结论先行

五条核心判断

  1. 数据治理和证伪纪律是这套框架最有价值的部分，应当原样保留。包括 Point-in-Time 数据、t_c 不等于峰值日期、参数 A 不是目标价、竞争首达的三分法、保留负结果、和 BASE / POWER 竞争比较。这些在公开的 LPPLS 研究里都少见。
  2. 时间层还停留在“单窗口拟合 + 硬门槛”的范式。Sornette 团队 2015 年之后的标准做法是：多窗口置信度（DS LPPLS Confidence）、Lagrange 正则选窗、修正似然 profile（MPL），再加上下一节讲的嵌套模型检验。框架里的 R² ≥ 0.90 和 ω∈(6,13) 等门槛，比原版过滤器更窄、更脆弱。
  3. 价格层（PPE）在物理上自洽，但没有接入任何“状态变量”。它描述了价格在哪里停留过，却没有回答系统正在变得更不稳定还是更稳定。缺的是统计物理的第三支柱：临界慢化、标度指数、熵、自激强度。
  4. 事件桥接层（Event Bridge）是对的方向，却从未被真正运行过。附件记录的完成率是 0.104%，日期模型的数量是 0。V5.1 唯一跑完的事件实验，Brier 0.1015 输给了基率 0.0930。所以在这一层被证明有效之前，任何“预测顶底”的结论都没有依据。
  5. 华尔街顶尖机构的做法不是追求更准的点预测，而是三件事：多个弱而稳定的信号；严格的过拟合校正（CPCV、Deflated Sharpe、PBO）；把概率转换成仓位的风险预算。在这三件事上，框架还没有覆盖执行层。

3. 时间层：问题与升级

3.1 优化精度不是瓶颈

线性消元以后，目标函数只有 (t_c, m, ω) 三个维度。Filimonov–Sornette 已经证明，在 (t_c, m) 平面上它通常只剩少数几个局部极小值。因此 DE 跑完整的多 seed 预算，主要成本花在把一个本来就不确定的 t_c 估得“数值上更精确”。

但附件 12.4 的失败案例全部来自识别问题：NDX 的 bootstrap 区间几乎占满整个允许时域，XAU/XAG 的日期重复率高却结构不合格。这些都不是优化器没收敛。建议：保留 DE 加精修作为数值基线，另外用一个简单的检验固定规则：同一窗口跑 5 个 seed，t_c 差异小于 1 个交易日的窗口比例达到 95% 以上，就认为优化已经足够。剩下的算力投到样本外验证上。

3.2 用嵌套检验回答“对数周期是否真实存在”

LPPLS 和纯幂律是嵌套模型（令 C₁=C₂=0 即可得到纯幂律）。在同一个窗口、同一个 t_c 搜索域下，可以计算

F = [(SSE_pow − SSE_lppls) / 2] / [SSE_lppls / (n − 7)]

这个检验每个窗口都能直接算，是 S4 方案中“B → C”比较在单窗口层面的版本。原型已经实现。注意两点：日线残差有自相关，F 分布假设的 p 值偏乐观；正式版应改用残差块 bootstrap 来构造零分布。

3.3 从门槛判断改为连续指标

硬门槛会让信号在门槛附近频繁翻转。建议输出三个连续量，再交给事件层去学习它们和真实事件的关系：

  • DS 置信度：通过原版过滤器的窗口比例，在 0 到 1 之间。
  • Trust：对最优窗口的残差做 bootstrap，通过过滤器的比例。
  • t_c 聚集度：合格窗口的 t_c 四分位距除以中位距今。数值越小，说明不同窗口指向同一个临界区。

3.4 窗口设计

四尺度 40 窗口中的 ULTRA 档（2500–7000 日）跨越了 A 股多次制度变化（股权分置改革、涨跌停调整、注册制）。在这么长的样本上要求同一个幂律过程成立，不符合 LPPLS 的局部假设。建议：主信号用 60–750 日的密集窗口（原型用 16 个，正式版建议 40 个以上）；超长窗口只用来描述长期状态，不进入事件模型。

4. 价格层：问题与升级

4.1 PPE 要保留的部分

Range-Aware KDE（把日内振幅计入核宽）、F = −ln ρ 的自由能表示、明确说明“经验井不等于动力学势能井”、竞争首达的四种结局（包括同 bar 歧义和右删失），这些在物理和统计上都是正确的。

4.2 PPE 的核心缺口：从静态地形到动力学

经验密度只给出一个“地形”，并不决定在地形上怎么运动。附件 6.3 也承认：只看 KDE 地形，无法唯一恢复未来的触达时间。升级方向是直接估计 Langevin 方程的漂移项和扩散项：

dX = f(X) dt + √(2D(X)) dW f(x) ≈ E[ΔX | X=x] / Δt （Kramers–Moyal 一阶系数） D(x) ≈ E[(ΔX)² | X=x] / (2Δt) （二阶系数）

估出 f 和 D 以后，有效势能是 U(x) = −∫ f/D dx + ln D，首达时间可以通过求解后向 Fokker–Planck 方程得到，或直接用 f、D 做模拟，不再依赖平稳 bootstrap。这样价格层就真正变成“动力学”模型。代价是 f 和 D 在稀疏价格区域估计噪声很大，需要核平滑和带宽交叉验证。

4.3 首达基线必须足够强

附件 12.2 显示：首达模型的 Brier 改善全部来自“是否触达”，方向判断反而略差（0.2420 → 0.2447）。这说明 PPE 的方向信息目前不比波动率加距离的基线更好。原型同时输出平稳块 bootstrap 和 iid bootstrap 两套概率；正式验收时还应加入 GARCH 或 HAR-RV 的波动率基线，PPE 必须胜过这个基线才能作为增量。

6. 事件层与概率校准

这是整个框架里最需要先做完的一层，因为它决定所有模型“好不好”。建议这样执行：

  1. 标签：沿用 top10_20_60，同时加入对称的 bot10_20_60。另外加入一个波动率调整版：回撤阈值用 2.5σ√60 代替固定的 10%，避免高波动股票的标签过多。
  2. 特征：时间层的 DS 置信度、Trust、t_c 聚集度、中位 t_c 距今；价格层的首达活动概率、所在井的深度；统计物理层的 α、熵、AR(1) 和方差的 τ。所有特征都在 as-of 时点计算。
  3. 模型阶梯：BASE（基率）→ BASE+波动 → +幂律 → +LPPLS → +物理状态。每一级都必须在样本外胜过上一级，否则那一层的特征就从模型里删掉。
  4. 模型形式：先用带 L2 正则的逻辑回归，不用复杂模型。在单只股票、几百个高度重叠的样本上，梯度提升树一定过拟合。
  5. 校准：在单独的校准期做 isotonic 或 Platt 校准，然后报告可靠性曲线和 ECE（期望校准误差）。
  6. 横截面：单只股票的顶部事件只有几个，统计效力极低。正式版必须在全 A 股（至少沪深 300 加中证 500 成分）上训练一个横截面模型，这是机构做法和个人研究的根本差别。

8. 从概率到仓位

即使事件概率已经校准，“在顶部卖出、在底部买入”也不是最优用法。机构的做法是：

  • 分数 Kelly：仓位 f = κ·(p·b − (1−p)) / b，κ 通常取 0.25 到 0.5，用来抵消概率本身的估计误差。
  • 波动目标：仓位乘以 σ_target / σ_realized，在高波动区（往往就是临界区）自动减仓。
  • 非对称处理：顶部信号用来降低风险敞口，比用来做空更可靠（A 股融券约束也很多）；底部信号只用来分批建仓，不用来一次性满仓。
  • Governor 状态和仓位上限一一对应：WATCH 时 0 新增仓位，PROBE 时不超过 1/4 目标仓位，CONFIRM 只有在事件层校准通过以后才启用。

9. 关于“高额收益”的现实边界

坦白说明以下几点，避免投入方向出错：

  • 公开文献中，LPPLS 最好的样本外结果是：作为泡沫存在的预警有用，作为崩盘日期预测弱，作为交易择时信号的费后收益不稳定。Sornette 团队 FCO 的公开报告也只把它定位为“诊断工具”。
  • 附件中唯一跑完的事件实验，已经输给了基率。在完成第 6、7 节的验证之前，任何收益预期都没有依据。
  • 在单只股票上，一次泡沫只给一个独立样本。“预测准确”至少需要几十个独立事件才能在统计上区分运气和能力，所以必须做横截面。
  • 更现实的目标是：在临界区降低回撤，在非临界区保持持有。这种风险控制型收益改善更容易被验证，也更能稳定存在。

11. 原型中已实现的部分

  • 时间层：线性消元（改进 Gram–Schmidt QR）；DE 加 Nelder–Mead 精修（浏览器端替代 L-BFGS-B）；16 个窗口的顶部和底部拟合；DS 和严格两套过滤器；Lagrange 选窗；残差块 bootstrap 估计 t_c 分布；纯幂律嵌套 F 检验。
  • 价格层：Range-Aware KDE（HLC3，时间半衰期 120 日，成交量平方根加权）；自由能井的质量、深度和三档带宽持续度；竞争首达分四种结局，平稳块 bootstrap 与 iid 双基线；上下边界可以手动调整。
  • 统计物理：DFA-1 标度指数、排列熵、AR(1) 与方差，以及它们的 Kendall τ 趋势。
  • 验证：滚动 as-of；只用已成熟的标签做前推逻辑回归；BASE、+LPPLS、+LPPLS+物理三级 Brier 对比；A 股规则交易回测。
  • 与正式规范的差距：优化预算远小于规范；没有 PIT 复权回放；没有 MPL；Brier 只有点估计，没有区块置信区间；只做单只股票，没有横截面。这些都列在 P1、P2 中。

12. 2026 上证复现与精度提升

“临界点 2.0”（桌面版 / 手机版）把顶部和底部拆成两套独立引擎，界面只输出见顶时间、逃顶动作、抄底区间和二波目标。下面是用两个历史截止日做的严格回放：只使用截止日及之前的数据，规则事先固定，没有针对这两个日期调参。

12.1 为什么顶底要分开

  • 顶部：用 LPPLS 做多尺度扫描（38 个窗口，30–700 日，并锚定截止日前最近两个 ZigZag 低点）。合格条件为 B<0、0.1≤m≤0.95、4≤ω≤15、距今 1–115 日、振荡数≥1.5、阻尼≥0.3、R²≥0.8。合格窗口的 t_c 用核密度聚类；至少 4 个尺度、一致度≥6% 才输出“见顶窗口”。
  • 底部：不再对 −ln P 做 LPPLS 拟合。正如用户所说，那样常常抄在半山腰。现在改为 6 项共振检查：跌幅到位、时间到位、止跌企稳为必要项，另有恐慌释放、落入价格井、反泡沫结构三项；必要项全满足且总分≥4 才买第一批。跌幅和时间的参照来自该标的过去 24 次同级别回撤（ZigZag 阈值 1.6σ√20）的分位数。
  • 二波：底部确认后分三批建仓，收复一半跌幅后加满；目标价参照历史反弹比例。

12.4 如何继续提高精度和收益（按预期收益排序）

  1. 补上非泡沫型顶部，提高覆盖率。覆盖率低是最大短板，像 5/13 这样的短周期顶部需要别的信号：融资余额与成交额的二阶导数（杠杆加速）、Hawkes 分支比（需要分钟线）、换手率分位数、上涨家数的背离。任一信号触发都只做减仓，不做清仓。
  2. 二波加退出机制。两次回放都在二波中途回吐利润。建议在二波目标价附近减半，并对剩余仓位使用 1.5σ√3 的移动止盈；目标价改为历史反弹比例的分位区间，不再用单点。
  3. 横截面训练。单只指数十年只有 7–8 次预警，统计效力不足。在中证 800 成分股上做相同扫描，事件数会增加两个数量级，才能可靠估计阈值（一致度、窗口距离）和校准曲线。
  4. 滚动再标定。每月用截至当时的数据，在 CPCV 下重估 alertConf、m/ω 范围和 ZigZag 阈值，并用 Deflated Sharpe 校正试验次数。禁止用全样本调参。
  5. 底部换成动力学模型。用 Kramers–Moyal 方法估计回撤段的漂移 f(x) 和扩散 D(x)；当 f 由负转正、D 开始回落时，才算“动力学止跌”。它可以替代目前的“止跌企稳”项，从而减少 2015 年 7 月那样的第一批过早买入。
  6. 仓位用分数 Kelly 加波动目标。把一致度映射成校准后的见顶概率 p，减仓比例取 κ·p（κ=0.5），再乘以 σ_target/σ。这样比固定“减一半”更平滑，也减少假警报的成本。
